Модули в C++ — это механизм организации кода, введённый в стандарте **C++20**, который служит современной альтернативой заголовочным файлам (`#include`).

## Зачем они нужны

Традиционные заголовочные файлы имеют проблемы: текстовая подстановка через `#include` замедляет компиляцию, требует защиты от повторного включения (`#pragma once` или include guards) и приводит к «утечке» макросов и деталей реализации.

## Базовый синтаксис

**Объявление и определение модуля** (`math.ixx` или `math.cppm`):

```cpp
export module math;   // объявление модуля

export int add(int a, int b) {   // export делает функцию доступной
    return a + b;
}

int helper() {   // без export — виден только внутри модуля
    return 42;
}
```

**Использование модуля:**

```cpp
import math;   // вместо #include

int main() {
    return add(2, 3);
}
```

## Ключевые слова

- `export module имя;` — объявляет модуль
- `export` — экспортирует сущность наружу
- `import имя;` — импортирует модуль
- `module;` — начинает глобальный фрагмент модуля (для старых `#include`)

## Основные преимущества

**Скорость компиляции** — модуль компилируется один раз, его не нужно парсить заново при каждом включении. **Изоляция** — макросы и приватные имена не утекают наружу. **Отсутствие include guards** — порядок импорта не важен, нет дублирования. **Чёткие границы** — явно видно, что является публичным API.

## Состояние поддержки

Поддержка зависит от компилятора и системы сборки. На 2025 год она реализована в MSVC, GCC и Clang, но всё ещё может требовать дополнительной настройки (особенно в CMake). Стандартную библиотеку можно импортировать как `import std;` (C++23).
