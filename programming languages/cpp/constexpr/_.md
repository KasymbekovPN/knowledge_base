[[_cpp|<=]]

Ключевое слово `constexpr` в C++ означает **"вычисляется во время компиляции"**.

Оно используется для:
- Объявления константных выражений,
- Функций, которые могут выполняться во время компиляции,
- Переменных, значение которых известно на этапе компиляции.

> ✅ Это мощный инструмент для **метапрограммирования**, **оптимизации** и **безопасности типов**.

### Преимущества `constexpr`

| Плюс                | Объяснение                                                              |
| ------------------- | ----------------------------------------------------------------------- |
| Оптимизация         | Значения вычисляются на этапе компиляции — нулевая стоимость в рантайме |
| Безопасность        | Ошибки обнаруживаются на этапе компиляции                               |
| Поддержка `const`   | Улучшает читаемость и безопасность кода                                 |
| Работает в шаблонах | Критически важно для метапрограммирования                               |

### `const` vs `constexpr`

| `const`                                          | `constexpr`                               |
| ------------------------------------------------ | ----------------------------------------- |
| Объект не может быть изменён после инициализации | Значение **известно на этапе компиляции** |
| Может быть установлено в рантайме                | Должно быть вычислено во время компиляции |

### Что нельзя делать в `constexpr`

До C++11/14/17 были ограничения, но сейчас разрешено почти всё, кроме:

- Ввод-вывод (`std::cout`, `printf`)
- Динамическое выделение памяти (`new`, `malloc`) — **до C++20**
- Вызов не-`constexpr` функций

### Лучшая практика

| Совет                                                     | Почему                                    |
| --------------------------------------------------------- | ----------------------------------------- |
| Используйте `constexpr` для математических констант       | `pi`, `e`, размеры буферов                |
| Помечайте простые функции как `constexpr`                 | Они могут использоваться в шаблонах       |
| Используйте `constexpr` в классах при возможности         | Для создания объектов на этапе компиляции |
| Комбинируйте с `noexcept`                                 | Для максимальной оптимизации              |
| Избегайте сложных вычислений в `constexpr`, если не нужно | Может замедлить компиляцию                |
