Концепты (__C++20__) — это **ограничения (constraints)** на шаблонные параметры, которые проверяются **на этапе компиляции**.

✅ До C++20 требования к шаблонам реализовывались через:
- `std::enable_if`
- SFINAE
- `static_assert`

❌ Это приводило к:
- Сложным сообщениям об ошибках,
- Запутанному коду,
- Дублированию проверок.

## 🔧 Синтаксис концептов

### 1. Базовое определение
```cpp
template<typename T>
concept Название = Условие;
```

### 2. Использование в шаблонах
```cpp
template<Название T>
void func(T x) { ... }
```

### 3. Через `requires` (более гибкий синтаксис)
```cpp
template<typename T>
requires Integral<T>
T add(T a, T b) { ... }
```

## ⚠️ Важные моменты

| Особенность | Пояснение |
|------------|-----------|
| Требуется C++20 | Флаг компиляции: `-std=c++20` |
| Не заменяет полностью SFINAE | Для очень сложных случаев всё ещё нужно |
| Проверяется **до** вывода типов | Ошибки понятнее |
| Можно комбинировать концепты | `requires (A<T> && B<T>)` |
| Нельзя частично специализировать концепты | Только полная специализация |

## 🚫 Чего НЕ могут делать концепты

| Ограничение | Почему |
|------------|--------|
| Не могут заменить `if constexpr` | Концепты работают только на этапе компиляции шаблона |
| Не могут проверять значения (только типы) | Для значений — `if constexpr` |
| Не работают с partial specialization напрямую | Нужны обходные пути |
