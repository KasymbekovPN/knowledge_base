[[programming languages/cpp/attributes/_|<=]]

`__attribute__((const))` (`[[gnu::const]]`) — более строгая версия `pure`: функция не только не имеет побочных эффектов, но и результат зависит **исключительно** от переданных по значению аргументов — никакого чтения глобальных переменных, памяти по указателям, разыменования, обращения к `errno`, статическим полям и т.п. Такая функция ведёт себя как чистая математическая функция. Компилятор может не просто выносить повторные вызовы за пределы циклов, а полноценно кэшировать/мемоизировать результат и даже вычислять его во время компиляции при constant folding, а также переупорядочивать или устранять вызовы совсем.

```cpp
#include <format>  
#include <iostream>  
  
namespace {  
  
    __attribute__((const))  
    int square(const int x) {  
        return x * x;  
    }
    
    __attribute__((const))  
    int add(const int a, const int b) {  
        return a + b;  
    }  
}  
  
int main() {  
    std::cout << std::format("square: {}\n", square(42));  
    std::cout << std::format("add: {}\n", add(42, 42));  
    std::cout << std::format("add: {}\n", add(1, 1));  
  
    return 0;  
}
```

Что **нельзя** делать в `const`-функции (в отличие от `pure`):

```cpp
int global = 10;

__attribute__((const))
int badConst(int x) {
    return x + global;   // ОШИБКА семантики: читает глобальную память — это pure, не const!
}

__attribute__((const))
int badConst2(const int* p) {
    return *p;            // тоже нарушение — разыменование указателя, чтение памяти
}
```

Пометка таких функций как `const` — UB: компилятор может закэшировать первый вызов и никогда не пересчитать результат заново, даже если `global` изменится между вызовами.

Правило выбора: `const` — только для функций вида "чистая функция от значений аргументов" (математика, битовые операции, преобразования без разыменования указателей); `pure` — когда функция читает _данные_, доступные через указатели/глобальные переменные, но ничего не модифицирует; если функция вообще может иметь побочные эффекты или её результат зависит от изменяемого внешнего состояния — ни то, ни другое использовать нельзя.
