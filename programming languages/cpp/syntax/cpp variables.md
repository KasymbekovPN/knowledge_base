Для хранения данных в программе в языке __C++__ используются переменные. Фактически переменная представляет именованный участок памяти. Переменная имеет тип, имя и значение. Тип определяет, какие именно данные может хранить переменная.

Перед использованием любую переменную надо определить. Синтаксис определения переменной выглядит следующим образом:

```
var_type var_name;
```

### Именование переменных

Имя переменной последовательность алфавитных-цифровых символов и знака подчеркивания `_`. При этом имя переменной должно начинаться с алфавитного символа или `_`.

Кроме того, в качестве имени переменной нельзя использовать ключевые слова языке __C++__, например, _for_ или _if_. 

Не рекомендуется:
- имена, начинающиеся с двух подчеркиваний
- имена, начинающиеся с `_` + заглавный символ
- имена в глобальной области (вне функции _main_), которые начинаются с подчеркивания

Т.к. данный паттерн наименования повышает вероятность конфликта имен с именами, которые генерируются компилятором или определены в подключаемых стандартным модулях __C++__.

### Определение переменной

Пример простейшего определения переменной
```cpp
int age;
```

Здесь определена переменная __age__, которая имеет тип _int_. Определение переменной так же представляет собой инструкцию.

Приведенной ниже определение переменных __не вызовет__ проблем т.к. определены переменных с различными именами.
```cpp
int age;
int Age;
```

В одной области видимости нельзя определять больше одной переменной с одним и тем же именем.
```cpp
int age;
int age; // <= Error on compilation
```

### Инициализация

После определения переменной можно присвоить некоторое значение. Присвоение переменной начального значения называется инициализацией. В __C++__ есть три вида инициализации:
- Нотация присваивания (assignment notation)
- Функциональная нотация (functional notation)
- Инициализация в фигурных скобках (braced initialization)

#### Нотация присваивания
```cpp
#include <iostream>

int main(){
	int age = 28; // <= definition + initialization
	// ...
}
```

#### Инициализация в фигурных скобках
```cpp
#include <iostream>

int main(){
	int age {28}; // <= definition + initialization
	// ...
}
```

#### Функциональная нотация
```cpp
#include <iostream>

int main(){
	int age (28); // <= definition + initialization
	// ...
}
```

### Сравнение нотаций

В большинстве случаев все три варианта инициализации эквивалентны. Однако инициализация в фигурных скобках немного безопаснее, когда применяется сужающее преобразование. В общем случае ожидается, что переменной передается значение, которое соответствует ее типу. Если же это не так, то компилятор попытается преобразовать присваиваемое значение в тип переменной. Сужающее преобразование изменяет значение одного типа на тип с более ограниченным диапазоном значений. Таким образом, преобразование может привести к потере информации. Возьмем следующий пример:
```cpp
#include <iostream>

int main()
{
	int age1 (23.5);
    int age2 = 24.5;

    std::cout<<"Age1 = " << age1 << "\n";
    std::cout<<"Age2 = " << age2 << "\n";
}
```

Здесь переменным _age1_ и _age2_, которые представляют тип __int__, то есть целое число, присваивается дробное значение - _23.5_ и _24.5_ соответственно.

```
Age1 = 23
Age2 = 24
```

В случае с инициализацией через __{}__ несовпадение типов приведет к ошибке компиляции.
```cpp
#include <iostream>

int main(){
	int age {21.1}; // <= compile error
	// ...
}
```

```
.\main.cpp:15:15: error: type 'double' cannot be narrowed to 'int' in initializer list [-Wc++11-narrowing]                 15 |     int age11{21.1};
```

### Инициализация нулем

При инициализации в фигурных скобках можно опустить значение, в этом случае переменная будет инициализирована дефолтным значением
```cpp
int counter {}; // < it likes int counter {0};
```

### Инициализация по умолчанию

Если переменную не инициализировать, то происходит ее инициализация по умолчанию. 
```cpp
#include <iostream>

int gl_var;

int main() {
	int scope_var;
	std::cout << "gl_val: " << gl_var << "\n";
	std::cout << "scope_val: " << scope_var << "\n";

	return ;0;
}
```

Переменная _gl_var_ определяется вне функции, и поэтому она получит значение по умолчанию - __0__.

С переменной _scope_val_ дела обстоят сложнее, её значение будет неопределенным и многое будет зависеть от компилятора. Например, clang и G++ присвоят дефолтное значение, в Visual Studio отсутствие значение олшибку компиляции.
