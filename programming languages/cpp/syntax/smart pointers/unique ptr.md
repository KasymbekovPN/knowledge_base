[[__cpp syntax smart ptr__|<==]]

Указатель `unique_ptr<T>` представляет указатель на тип _T_, который является уникальным в том смысле, что что может быть только один объект `unique_ptr`, который содержит один и тот же адрес. 

То есть не может одновременно быть двух или более объектов `unique_ptr<T>`, которые указывают один и тот же адрес памяти. Если же мы попробуем определить два одновременно существующих указателя, которые указывают на один и тот же адрес, компилятор не скопирует код.

И когда _unique_ptr_ уничтожается, уничтожается и значение, на которое он указывает. Соответственно данный тип указателей полезен, когда нужен указатель на объект, на который __НЕ__ будет других указателей и который будет удален после удаления указателя.

```cpp
#include <iostream>
#include <memory>

using std::cout;
using std::endl;

int main(int argc, char const *argv[]) {
    std::unique_ptr<int> no_init_ptr {};
    cout << "no_init_ptr <= " << no_init_ptr << endl;

    std::unique_ptr<int> ptr {std::make_unique<int>(42)};
    cout << "Address <= " << ptr.get() << endl;
    cout << "Value <= " << *ptr << endl;

    *ptr = 101;
    cout << "Value <= " << *ptr << endl;

    ptr.reset(new int{-111});
    cout << "Value <= " << *ptr << endl;

    ptr.reset();
    if (!ptr) {
        cout << "ptr is free" << endl;
    }

    cout << "Done" << endl;

    return 0;
}
```

```
no_init_ptr <= 0000000000000000
Address <= 0000016F945FAE50
Value <= 42
Value <= 101
Value <= -111
ptr is free
Done
```

По умолчанию `unique_ptr<T>` инициализируется значением nullptr.

Чтобы выделить память и создать в ней объект, на который будет указывать указатель, применяется функция `std::make_unique<T>`. В качестве параметра в нее передается объект, на который будет указывать указатель.

До принятия стандарта __C++14__ применялась другая форма создания указателя
```cpp
std::unique_ptr<type> ptr_name {new type(value)};
```

Для получения стандартного указателя из `std::unique_ptr` применяется функция _get_.

Стоит отметить, что начиная со стандарта __C++20__ получить адрес из smart-указателя мы можем напрямую без функции _get_.

Если потребуется освободить память, на которую указывает указатель, то можно применить функцию _reset_. После этого указатель получает значение _nullptr_.

Так же через _reset_ можно задать новый объект.
```cpp
ptr.reset(new type{value});
```
