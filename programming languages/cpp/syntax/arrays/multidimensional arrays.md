Каждый массив имеет такую характеристику как размерность. Количество размерностей соответствует числу пар квадратных скобок.

Одномерный массив:
```cpp
int numbers[SIZE];
```

Двумерный массив:
```cpp
int matrix[N][K];
```

В первом случае массив _numbers_ имеет одну размерность. При этом не важно, сколько элементов содержит этот массив. В любом случае его можно представить в виде ряда элемента значений - в виде строки или столбца.

Но кроме одномерных массивов в __C++__ есть и многомерные. Элементы таких массивов сами в свою очередь являются массивами, в которых также элементы могут быть массивами. Как правило, распространены двухмерные и трехмерные массивы.

Массив _matrix_ имеет две размерности. Двухмерный массив еще можно представить в виде таблицы, где первая размерность представляет количество строк, а вторая размерность - количество столбцов.

Инициализированный по умолчанию двумерный массив выглядит так:
```cpp
int matrix[N][K]{};
```

Также можно инициализировать все элементы индивидуальными значениями.
```cpp
const int N {2};
const int K {2};
int matrix[N][K]{
	{0, 1},
	{2, 3}
};
```
