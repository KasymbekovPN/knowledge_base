[[__cpp syntax operations__|<=]]

Условные выражения представляют собой некоторое условие и возвращают значение типа _bool_, то есть значение _true_ (если условие истинно), либо значение _false_ (если условие ложно). К условным выражениям относятся:
- [[comparison operations|операции сравнения]]
- [[conditional logical operations|логические операции]]
