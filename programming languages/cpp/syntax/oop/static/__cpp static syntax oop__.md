[[__cpp syntax oop__|<==]]

Кроме переменных и методов, которые относятся непосредственно к объекту, __C++__ позволяет определять переменные и методы, которые относятся непосредственно к классу или иначе говоря статические члены класса. Статические переменные и методы относят в целом ко всему классу. Для их определения используется ключевое слово _static_.
