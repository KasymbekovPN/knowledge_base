[[__cpp syntax oop virtual methods__|<=]]

__Виртуальные функции__ имеют свою цены - объекты классов с виртуальными функциями требуют немного больше памяти и немного больше времени для выполнения. Поскольку при создании объекта полиморфного класса (который имеет виртуальные функции) в объекте создается __специальный указатель__. 

Этот указатель используется для вызова любой виртуальной функции в объекте. Специальный указатель указывает на __таблицу указателей функций__, которая создается для класса. Эта таблица, называемая __виртуальной таблицей__ или __vtable__, содержит по одной записи для каждой виртуальной функции в классе.

Когда функция вызывается через указатель на объект базового класса, происходит следующая последовательность событий:

- Указатель на __vtable__ в объекте используется для поиска адреса __vtable__ для класса.
- Затем в таблице идет поиск указателя на вызываемую __виртуальную функцию__.
- Через найденный указатель функции в __vtable__ вызывается сама функция. 

В итоге вызов __виртуальной функции__ происходит немного медленнее, чем прямой вызов невиртуальной функции, поэтому каждое объявление и вызов виртуальной функции несет некоторые накладные расходы.
