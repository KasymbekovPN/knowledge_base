**CRTP (Curiously Recurring Template Pattern)** — это мощная идиома C++, при которой **базовый класс является шаблоном, принимающим свой производный класс как параметр**.

> 💡 Это позволяет реализовать **статический полиморфизм** (аналог виртуальных функций, но без накладных расходов).

# Основная структура

```cpp
template<typename Derived>
struct Base {
    void interface() {
        // Calling of method form derived class
        static_cast<Derived*>(this)->implementation();
    }

    void shared_logic() {
        // Common logic
        interface(); // Call derived implementation
    }
};

struct Derived : Base<Derived> {
    void implementation() {
        // Custom implementation
    }
};
```

> ✅ `Base` знает о `Derived` на этапе компиляции → нет таблицы виртуальных функций!

## 🆚 CRTP vs Виртуальные функции

| Характеристика | CRTP | Виртуальные функции |
|----------------|-----|--------------------|
| Производительность | ⚡ Выше (inlining) | Ниже (косвенный вызов) |
| Память | Меньше (нет vtable) | Больше |
| Гибкость | Ниже (статическая привязка) | Выше (динамическая) |
| RTTI / `dynamic_cast` | ❌ Нет | ✅ Да |
| Использование | Шаблоны, библиотеки | ООП, GUI, плагины |

## 📌 Когда использовать CRTP?

| Ситуация | Почему |
|----------|--------|
| Пишете библиотеку высокой производительности | Eigen, Boost используют CRTP |
| Хотите "виртуальное" поведение без накладных расходов | Статический полиморфизм |
| Нужно расширить функциональность класса | Mix-in через наследование |
| Реализуете паттерн "Mixin" или "Policy-based design" | Loki, Boost.Parameter |


## ✅ Лучшая практика

| Совет | Почему |
|------|--------|
| Используйте `static_cast<Derived*>` осторожно | Убедитесь, что `this` действительно указывает на `Derived` |
| Добавьте `assert(...)` в отладке | Чтобы проверить иерархию |
| Не злоупотребляйте CRTP | Может усложнить чтение кода |
| Документируйте использование CRTP | Чтобы другие понимали идею |
| Комбинируйте с концептами (C++20) | Для проверки интерфейса |

## ⚠️ Важные особенности

| Особенность | Объяснение |
|-------------|------------|
| Работает на этапе компиляции | Нет runtime-накладок |
| Не требует `virtual` | Вызовы inlined |
| Требует знания типа `Derived` заранее | Нельзя хранить `Base<auto>` |
| Не подходит для динамической загрузки | Например, через `dlopen()` |
| Может увеличить размер кода | Из-за инстанцирования шаблонов |
