[[RAII|<=]]

`std::scoped_lock` — это **RAII-обёртка для захвата одного или нескольких мьютексов**, появившаяся в **C++17**.  
Она безопасно блокирует все указанные мьютексы при создании и освобождает их при уничтожении, **гарантируя отсутствие deadlock'ов** благодаря алгоритму *lock multiple mutexes*.

> ✅ Это современная замена `std::lock_guard` для случая с **несколькими мьютексами**.

> ✅ `std::scoped_lock` использует `std::lock(mtx_a, mtx_b)` под капотом — это гарантирует, что:
> - Порядок захвата не приведёт к deadlock'у,
> - Все мьютексы будут захвачены или ни один (atomically).

✅ **Используйте `std::scoped_lock` по умолчанию**, особенно если есть шанс расширить до нескольких мьютексов.
## ⚠️ Важные моменты

| Особенность | Объяснение |
|-------------|------------|
| Доступен с C++17 | Не будет работать в старых стандартах |
| Нельзя использовать без мьютексов | Требуется хотя бы один |
| Нельзя явно разблокировать | Только через выход из области видимости |
| Автоматически предотвращает deadlock при нескольких мьютексах | Благодаря `std::lock()` |
| Лучше, чем несколько `std::lock_guard` | Гарантирует атомарность захвата |

## 🆚 `std::scoped_lock` vs `std::lock_guard`

| Функция | `std::lock_guard` | `std::scoped_lock` |
|--------|-------------------|--------------------|
| Поддержка одного мьютекса | ✅ Да | ✅ Да |
| Поддержка нескольких мьютексов | ❌ Нет | ✅ Да |
| Предотвращение deadlock'а | ❌ При ручном порядке — может быть | ✅ Да, всегда |
| Производительность | ⚡ Чуть выше | Очень близко |
| Современность | C++11 | C++17 |

## 🆚 `std::scoped_lock` vs `std::unique_lock`

| Функция | `std::scoped_lock` | `std::unique_lock` |
|--------|--------------------|--------------------|
| Может быть разблокирован вручную | ❌ Нет | ✅ Да |
| Поддерживает отложенную блокировку | ❌ Нет | ✅ Да (`defer_lock`) |
| Можно передавать между функциями | ❌ Нет | ✅ Да |
| Поддержка `condition_variable` | ❌ Нет | ✅ Да |
| Лучше для простых случаев | ✅ Да | Для сложных |

```cpp
#include <iostream>
#include <mutex>

using namespace std;

int main() {
    mutex mtx_a;
    int value_a {13};

    mutex mtx_b;
    int value_b {42};

    scoped_lock lock (mtx_a, mtx_b);
    cout << value_a << ", " << value_b << endl;

    return 0;
}
```

```
13, 42
```
