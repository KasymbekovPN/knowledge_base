**Scope Guard** — это идиома, при которой **действие автоматически выполняется при выходе из области видимости (scope)**.  
Она использует принцип **RAII** (Resource Acquisition Is Initialization) для обеспечения исключений-безопасного выполнения очистки, логирования, разблокировки и других действий.

> ✅ Примеры:
> - Автоматическое закрытие файла,
> - Разблокировка мьютекса,
> - Логирование начала и завершения функции.

### Основная идея

Создаётся объект, который:
1. Выполняет какое-то действие в конструкторе (опционально),
2. Гарантированно выполняет "обратное" или "финальное" действие в деструкторе.

### Важные моменты

| Особенность                              | Объяснение                             |
| ---------------------------------------- | -------------------------------------- |
| Работает через деструктор                | Гарантировано вызывается при выходе    |
| Поддерживает исключения                  | Stack unwinding → всё равно вызывается |
| Не требует ручного вызова                | Никакого `try`/`finally`!              |
| Можно перемещать (если реализовать move) | Полезно при передаче                   |
| Избегайте тяжёлых действий в деструкторе | Особенно в контейнерах                 |
### Когда использовать?

| Ситуация                                     | Почему                      |
| -------------------------------------------- | --------------------------- |
| Хотите выполнить код при выходе из функции   | Логирование, профилирование |
| Управляете ресурсами без стандартной обёртки | Файлы, хэндлы, сокеты       |
| Реализуете сложную логику отката             | Транзакции, временные файлы |
| Пишете библиотечный код                      | Безопасность и чистота      |

### Лучшая практика

| Совет                                                              | Почему                                    |
| ------------------------------------------------------------------ | ----------------------------------------- |
| Используйте `std::function<void()>` или шаблон для универсальности | Поддерживает лямбды, указатели на функции |
| Перемещайте, а не копируйте                                        | `noexcept` move конструктор               |
| Не бросайте исключения в деструкторе                               | Это может привести к `std::terminate()`   |
| Называйте переменную осмысленно: `cleanup`, `guard`, `timer`       | Читаемость                                |
| Для простых случаев используйте стандартные RAII-обёртки           | Например, `lock_guard`                    |
