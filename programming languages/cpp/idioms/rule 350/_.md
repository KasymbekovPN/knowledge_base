Это **фундаментальные правила управления ресурсами** в C++. Они помогают избежать утечек памяти, двойного удаления и других ошибок при работе с динамическими ресурсами.

## 📊 Сводка: Когда что использовать?

| Ситуация                                      | Решение                                                                        |
| --------------------------------------------- | ------------------------------------------------------------------------------ |
| Управляете ресурсом вручную (`new`, `fopen`)  | Реализуйте **Rule of Five**                                                    |
| Пишете библиотечный класс с особым поведением | **Rule of Five**                                                               |
| Хотите безопасность и простоту                | **Rule of Zero** — используйте `std::vector`, `std::string`, `std::unique_ptr` |
| Наследуете от базового класса                 | Убедитесь, что базовый следует правилам                                        |

## ✅ Лучшая практика

| Совет                                           | Почему                                    |
| ----------------------------------------------- | ----------------------------------------- |
| По возможности следуйте **Rule of Zero**        | Меньше кода, меньше ошибок                |
| Используйте `= default` для тривиальных случаев | Например: `~MyClass() = default;`         |
| Помечайте move-операции как `noexcept`          | Улучшает производительность в контейнерах |
| Избегайте `new`/`delete` напрямую               | Используйте RAII и умные указатели        |
| Тестируйте с `valgrind` или AddressSanitizer    | Находит утечки и double-free              |
