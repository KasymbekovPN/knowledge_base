[[programming languages/cpp/idioms/_|<=]]

**Pimpl (Pointer to implementation)** — это идиома C++, при которой **реализация класса скрывается за указателем**, чтобы:
- Скрыть приватные данные,
- Ускорить перекомпиляцию,
- Обеспечить ABI-стабильность.

> ✅ Это особенно полезно в библиотеках, где важно не нарушать двоичную совместимость.

# Основная идея

Вместо того чтобы держать все поля и зависимости в заголовочном файле:

```cpp
// widget.h
class Widget {
    std::string name;
    std::vector<int> data;
    BigHeavyClass helper; // ← если изменится — всё пересобирается!
public:
    void do_something();
};
```

→ Переносим реализацию внутрь `.cpp` файла через `pImpl`.

`widget.h`
```cpp
#pragma once
#include <memory>

struct Impl;

class Widget {
private:
    class Impl;
    std::unique_ptr<Impl> p_impl;

public:
    Widget();
    ~Widget();
    Widget(Widget&&);
    Widget& operator=(Widget&&);

    void do_somethong();
    int get_value() const;
};
```

`widget.cpp`
```cpp
#include "widget.h"

#include <iostream>
#include <vector>

class Widget::Impl {

public:
    std::string name {"default"};
    int value {42};

    void process() const {
        std::cout
            << "Processing: "
            << name
            << std::endl;
    };
};

Widget::Widget(): p_impl(std::make_unique<Widget::Impl>()) {}

Widget::~Widget() = default;

Widget::Widget(Widget&&) = default;

Widget& Widget::operator=(Widget&&) = default;

void Widget::do_somethong() {
    p_impl->process();
}

int Widget::get_value() const {
    return p_impl->value;
}
```

`main.cpp`
```cpp
#include "widget.h"

int main(int argc, char const *argv[]) {
    Widget w;
    w.do_somethong();

    return 0;
}
```
