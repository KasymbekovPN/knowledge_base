[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::is_sorted_until` из заголовочного файла `<algorithm>` используется для **поиска первой позиции, где нарушается порядок сортировки**.

> ✅ Она возвращает итератор на **первый элемент, который нарушает упорядоченность**.  
Если весь диапазон отсортирован — возвращает `last`.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
ForwardIterator is_sorted_until(ForwardIterator first, ForwardIterator last);

template<class ForwardIterator, class Compare>
ForwardIterator is_sorted_until(ForwardIterator first, ForwardIterator last, Compare comp);
```

- Возвращает: итератор на первый элемент, нарушающий порядок
- Если весь диапазон отсортирован — возвращает `last`
- Работает за O(n)

### Важные моменты

| Особенность                               | Объяснение                      |
| ----------------------------------------- | ------------------------------- |
| Работает за O(n)                          | Проверяет элементы по одному    |
| Не изменяет данные                        | Только читает                   |
| Может принимать лямбды, функторы, функции | Для гибкого сравнения           |
| Пустой диапазон считается отсортированным | `is_sorted_until(...)` → `last` |
| Равные элементы не нарушают порядок       | `{1, 2, 2, 3}` — отсортирован   |

### Лучшая практика

| Совет                                                                    | Почему                        |
| ------------------------------------------------------------------------ | ----------------------------- |
| Используйте `std::is_sorted_until`, если нужно найти ошибку в сортировке | Для отладки                   |
| Комбинируйте с `std::distance`, чтобы получить индекс                    | Полезно для вывода            |
| Используйте лямбды для сложных условий                                   | Например, по полю структуры   |
| Проверяйте ввод перед `std::binary_search`                               | Иначе — UB                    |
| Избегайте `std::is_sorted_until` в больших циклах без оптимизации        | Это O(n), может быть медленно |
