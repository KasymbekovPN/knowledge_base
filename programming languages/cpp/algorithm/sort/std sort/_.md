[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::sort` из заголовочного файла `<algorithm>` используется для **сортировки элементов в диапазоне** по возрастанию (по умолчанию) или по пользовательскому критерию.

> ✅ Это одна из самых часто используемых функций STL.  
Она работает с любыми контейнерами, поддерживающими **рандомизированные итераторы**: `std::vector`, `std::array`, массивы, `std::deque`.

### Синтаксис

```cpp
#include <algorithm>

template<class RandomAccessIterator>
void sort(RandomAccessIterator first, RandomAccessIterator last);

template<class RandomAccessIterator, class Compare>
void sort(RandomAccessIterator first, RandomAccessIterator last, Compare comp);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `comp` — бинарный предикат сравнения: `comp(a, b)` должен возвращать `true`, если `a` должен стоять перед `b`
- Функция **не возвращает значение**, она сортирует "на месте"

### Важные моменты

| Особенность                               | Объяснение                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------------- |
| Работает за O(n log n)                    | На среднем случае; реализация обычно на основе introsort (гибрид quicksort/heap sort) |
| Не сохраняет порядок равных элементов     | Используйте `std::stable_sort`, если нужно                                            |
| Требует рандомизированных итераторов      | Не подходит для `std::list` (есть свой метод `.sort()`)                               |
| Может принимать лямбды, функторы, функции | Очень гибкий выбор условия                                                            |
| Изменяет исходный контейнер               | Не создаёт копию                                                                      |

### Лучшая практика

| Совет                                                                | Почему                                       |
| -------------------------------------------------------------------- | -------------------------------------------- |
| Используйте `std::sort` для быстрой сортировки                       | Оптимизирован и протестирован                |
| Используйте лямбды для краткости                                     | Особенно для временных условий               |
| Если важен порядок равных элементов — используйте `std::stable_sort` | Например, при сортировке по нескольким полям |
| Избегайте `std::sort` на очень больших данных без профилирования     | Иногда лучше специализированные алгоритмы    |
| Проверяйте результат через `std::is_sorted`                          | Для тестирования и отладки                   |
