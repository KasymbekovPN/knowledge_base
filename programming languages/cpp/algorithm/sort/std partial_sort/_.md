[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::partial_sort` из заголовочного файла `<algorithm>` используется для **частичной сортировки диапазона**: она упорядочивает первые `N` элементов, остальные остаются в неопределённом порядке.

> ✅ Это полезно, когда вам нужно найти **топ-N наименьших (или наибольших)** элементов без полной сортировки всего контейнера — более эффективно, чем `std::sort`.

### Синтаксис

```cpp
#include <algorithm>

template<class RandomAccessIterator>
void partial_sort(RandomAccessIterator first,
                  RandomAccessIterator middle,
                  RandomAccessIterator last);

template<class RandomAccessIterator, class Compare>
void partial_sort(RandomAccessIterator first,
                  RandomAccessIterator middle,
                  RandomAccessIterator last,
                  Compare comp);
```

- `[first, last)` — весь диапазон
- `[first, middle)` — часть, которая будет отсортирована
- `middle` — итератор, указывающий на границу: после вызова первые `middle - first` элементов будут наименьшими и отсортированы
- `comp` — бинарный предикат сравнения

### Важные моменты

| Особенность                               | Объяснение                                                 |
| ----------------------------------------- | ---------------------------------------------------------- |
| Не сортирует весь массив                  | Только первую часть `[first, middle)`                      |
| Работает быстрее `std::sort`, если N мало | O(n log k), где k = size of sorted part                    |
| Сохраняет только порядок в первой части   | Остальное — неупорядочено                                  |
| Требует рандомизированных итераторов      | Подходит для `std::vector`, `std::array`, обычных массивов |
| Изменяет исходный контейнер               | Нельзя использовать с `std::list` напрямую                 |

### Лучшая практика

| Совет                                                                                  | Почему                        |
| -------------------------------------------------------------------------------------- | ----------------------------- |
| Используйте `std::partial_sort`, если N мало по сравнению с общим размером             | Эффективнее `std::sort`       |
| Используйте `std::nth_element`, если нужен только N-й элемент                          | Ещё быстрее                   |
| Используйте `std::partial_sort_copy`, если хотите сохранить оригинал                   | Без изменения исходных данных |
| Проверяйте, что `middle <= last`                                                       | Иначе — UB                    |
| Комбинируйте с `std::back_inserter` и `std::partial_sort_copy`, если цель динамическая | Удобно и безопасно            |
