[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::stable_sort` из заголовочного файла `<algorithm>` используется для **сортировки элементов диапазона с сохранением относительного порядка равных элементов**.

> ✅ Это ключевое отличие от `std::sort`:  
> Если два элемента считаются "равными", то их исходный порядок **не меняется**.

### Синтаксис

```cpp
#include <algorithm>

template<class RandomAccessIterator>
void stable_sort(RandomAccessIterator first, RandomAccessIterator last);

template<class RandomAccessIterator, class Compare>
void stable_sort(RandomAccessIterator first, RandomAccessIterator last, Compare comp);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `comp` — бинарный предикат сравнения
- Функция **не возвращает значение**, она сортирует "на месте"

### Важные моменты

| Особенность                                   | Объяснение                                         |
| --------------------------------------------- | -------------------------------------------------- |
| Сохраняет порядок равных элементов            | Главное преимущество перед `std::sort`             |
| Работает за O(n log n)                        | В среднем случае                                   |
| Может работать за O(n log² n) в худшем случае | Если не хватает памяти                             |
| Требует рандомизированных итераторов          | Подходит для `std::vector`, `std::array`, массивов |
| Использует дополнительную память              | Для временных копий                                |

### Лучшая практика

| Совет                                                                       | Почему                                  |
| --------------------------------------------------------------------------- | --------------------------------------- |
| Используйте `std::stable_sort`, если важен порядок равных элементов         | Например, при многоуровневой сортировке |
| Используйте `std::sort`, если производительность критична                   | Он немного быстрее                      |
| Комбинируйте `std::stable_sort` с лямбдами                                  | Для гибкой логики                       |
| Избегайте `std::stable_sort` на очень больших данных без достаточной памяти | Может замедлиться                       |
| Проверяйте результат через `std::is_sorted`                                 | Для тестирования                        |
