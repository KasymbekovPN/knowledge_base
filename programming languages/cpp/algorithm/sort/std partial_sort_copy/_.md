[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::partial_sort_copy` из заголовочного файла `<algorithm>` используется для **копирования и частичной сортировки элементов из одного диапазона в другой**.

> ✅ В отличие от `std::partial_sort`, которая модифицирует исходный контейнер,  
> `std::partial_sort_copy` **создаёт отсортированную копию наименьших (или наибольших) элементов**, не изменяя оригинал.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: по возрастанию (через operator<)
template<class InputIterator, class RandomAccessIterator>
RandomAccessIterator partial_sort_copy(InputIterator first, InputIterator last,
                                      RandomAccessIterator result_first,
                                      RandomAccessIterator result_last);

// Версия 2: с пользовательским компаратором
template<class InputIterator, class RandomAccessIterator, class Compare>
RandomAccessIterator partial_sort_copy(InputIterator first, InputIterator last,
                                      RandomAccessIterator result_first,
                                      RandomAccessIterator result_last,
                                      Compare comp);
```

- `first`, `last` — исходный диапазон
- `result_first`, `result_last` — целевой диапазон (должен быть уже выделен!)
- `comp` — бинарный предикат сравнения
- Возвращает: итератор на конец отсортированной части в `result`

### Важные моменты

| Особенность                                                | Объяснение                                                  |
| ---------------------------------------------------------- | ----------------------------------------------------------- |
| Не изменяет исходный диапазон                              | Только читает                                               |
| Целевой контейнер должен быть **уже выделен**              | `std::partial_sort_copy` не использует `std::back_inserter` |
| Работает за O(n log k), где k = размер целевого диапазона  | Быстрее полной сортировки при малых k                       |
| Может принимать лямбды, функции, функторы                  | Для гибкого сравнения                                       |
| Подходит для `std::vector`, `std::array`, обычных массивов | Но не для `std::list` напрямую                              |

### Лучшая практика

| Совет                                                                | Почему                                      |
| -------------------------------------------------------------------- | ------------------------------------------- |
| Выделяйте память в `dest` заранее                                    | `partial_sort_copy` не расширяет контейнеры |
| Используйте `std::vector::resize()` или массивы                      | Чтобы избежать UB                           |
| Используйте `std::partial_sort_copy`, если хотите сохранить оригинал | Без изменений                               |
| Комбинируйте с `std::distance` для получения количества элементов    | Полезно при анализе                         |
| Избегайте `std::partial_sort_copy` в больших циклах без оптимизации  | Это O(n log k), может быть медленным        |

### `std::partial_sort_copy` и `std::back_inserter` не работает!

```cpp
// ❌ Это НЕ СРАБОТАЕТ:
std::vector<int> dest;
std::partial_sort_copy(src.begin(), src.end(),
                       std::back_inserter(dest), // ❌ Ошибка!
                       std::back_inserter(dest) + 3);
```

> ❌ `std::partial_sort_copy` **не работает с `std::back_inserter`**, потому что ему нужен **рандомизированный итератор**.

✅ Правильный способ:

```cpp
std::vector<int> dest(3); // выделяем заранее
std::partial_sort_copy(src.begin(), src.end(), dest.begin(), dest.end());
```
