[[programming languages/cpp/algorithm/sort/_|<=]]

Функция `std::is_sorted` из заголовочного файла `<algorithm>` используется для **проверки, отсортирован ли диапазон по возрастанию** (по умолчанию) или по пользовательскому критерию.

> ✅ Это удобно:
> - При отладке,
> - Проверке результатов сортировки,
> - В алгоритмах, где требуется отсортированный ввод (например, `std::binary_search`).

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
bool is_sorted(ForwardIterator first, ForwardIterator last);

template<class ForwardIterator, class Compare>
bool is_sorted(ForwardIterator first, ForwardIterator last, Compare comp);
```

- Возвращает `true`, если диапазон отсортирован,
- `false` — если нет,
- Работает с любыми итераторами, поддерживающими сравнение: `std::vector`, `std::list`, `std::array`, обычные массивы.

### Важные моменты

| Особенность                               | Объяснение                                 |
| ----------------------------------------- | ------------------------------------------ |
| Работает за O(n)                          | Проверяет соседние элементы                |
| Не изменяет данные                        | Только читает                              |
| Может принимать лямбды, функторы, функции | Для гибкого сравнения                      |
| Пустой диапазон считается отсортированным | `is_sorted(v.begin(), v.begin())` → `true` |
| Равные элементы допускаются               | `{1, 2, 2, 3}` — отсортирован              |

### Лучшая практика

| Совет                                                          | Почему                        |
| -------------------------------------------------------------- | ----------------------------- |
| Используйте `std::is_sorted`, если нужно проверить порядок     | Быстро и читаемо              |
| Комбинируйте с `std::is_sorted_until`, если нужно найти ошибку | Для отладки                   |
| Используйте лямбды для сложных условий                         | Например, по полю структуры   |
| Проверяйте ввод перед `std::binary_search`                     | Иначе — UB                    |
| Избегайте `std::is_sorted` в больших циклах без оптимизации    | Это O(n), может быть медленно |
