Функция `std::lexicographical_compare` из заголовочного файла `<algorithm>` используется для **лексикографического сравнения двух диапазонов** — то есть, как если бы они были словами в словаре.

> ✅ Это основа для сравнения строк, контейнеров и последовательностей:
> - `std::string`, `std::vector`, массивы и т.д.
> - Используется в `std::set`, `std::map`, `std::sort` по умолчанию

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator1, class InputIterator2>
bool lexicographical_compare(InputIterator1 first1, InputIterator1 last1,
                             InputIterator2 first2, InputIterator2 last2);

template<class InputIterator1, class InputIterator2, class Compare>
bool lexicographical_compare(InputIterator1 first1, InputIterator1 last1,
                             InputIterator2 first2, InputIterator2 last2,
                             Compare comp);
```

- Возвращает `true`, если **первый диапазон "меньше" второго** лексикографически
- Возвращает `false`, если первый >= второго

### Важные моменты

| Особенность | Объяснение |
|-------------|------------|
| Работает за O(n) | Останавливается при первом отличии |
| Не изменяет данные | Только читает |
| Может принимать лямбды, функции, функторы | Для гибкого сравнения |
| Если один диапазон — префикс другого, то он "меньше" | `"abc" < "abcd"` |
| Возвращает `false`, если диапазоны равны | Потому что `a < b` → `false` |
### Лучшая практика

| Совет                                                                         | Почему                                                    |
| ----------------------------------------------------------------------------- | --------------------------------------------------------- |
| Используйте `std::lexicographical_compare`, если нужно сравнить два диапазона | Более универсально, чем `strcmp`                          |
| Используйте лямбды для неточного сравнения                                    | Например, `double` с допуском, регистронезависимые строки |
| Комбинируйте с `std::mismatch`, чтобы найти отличие                           | Полезно для отладки                                       |
| Избегайте `std::lexicographical_compare` в больших циклах без оптимизации     | Это O(n), может быть медленно                             |
| Помните: короткий диапазон — "меньше", если он префикс                        | `"a" < "aa"`                                              |
