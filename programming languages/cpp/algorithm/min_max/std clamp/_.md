[[programming languages/cpp/algorithm/min_max/_|<=]]

Функция `std::clamp` __C++17+__ из заголовочного файла `<algorithm>` используется для **ограничения значения диапазоном `[lo, hi]`**. 

> Это удобная и безопасная замена ручному:
```cpp
value = std::max(lo, std::min(hi, value));
```

### Синтаксис

```cpp
#include <algorithm>

template<class T, class Compare>
constexpr const T& clamp(const T& v, const T& lo, const T& hi, Compare comp);

template<class T>
constexpr const T& clamp(const T& v, const T& lo, const T& hi);
```

- `v` — значение, которое нужно ограничить
- `lo`, `hi` — нижняя и верхняя границы (должны удовлетворять `lo <= hi`)
- `comp` — пользовательский компаратор (опционально)
- Возвращает: значение, "зажатое" между `lo` и `hi`
- Работает с любыми типами, поддерживающими сравнение

### Важные моменты

| Особенность                                                   | Объяснение                                              |
| ------------------------------------------------------------- | ------------------------------------------------------- |
| Добавлена в C++17                                             | Требуется соответствующий стандарт                      |
| Требует `lo <= hi`                                            | Иначе — неопределённое поведение                        |
| Возвращает **ссылку** на один из трёх аргументов              | Не копирует                                             |
| Работает с любыми типами, где есть `operator<` или компаратор | `int`, `double`, `std::string`, пользовательские классы |
| `constexpr` — может использоваться в compile-time             |                                                         |

### Лучшая практика

| Совет                                                                    | Почему                             |
| ------------------------------------------------------------------------ | ---------------------------------- |
| Используйте `std::clamp` вместо `min(max(...))`                          | Читаемее и безопаснее              |
| Убедитесь, что `lo <= hi`                                                | Иначе — UB                         |
| Используйте `std::clamp` с `constexpr`                                   | Для вычислений на этапе компиляции |
| Проверяйте типы: `std::clamp(5, 0.0, 10.0)` может вызвать предупреждение | Лучше использовать один тип        |
| Комбинируйте с `std::abs`, `std::round` и др.                            | Для сложной обработки              |
