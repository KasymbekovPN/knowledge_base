[[programming languages/cpp/algorithm/min_max/_|<=]]

Функция `std::minmax` из заголовочного файла `<algorithm>` используется для **одновременного получения минимального и максимального из двух значений**.

> ✅ Это удобная функция, которая:
> - Возвращает `std::pair<min, max>`,
> - Избегает двойного сравнения,
> - Поддерживает пользовательские компараторы,
> - Работает с любыми типами, поддерживающими сравнение.

### Синтаксис

```cpp
#include <algorithm>

template<class T>
std::pair<const T&, const T&> minmax(const T& a, const T& b);

template<class T, class Compare>
std::pair<const T&, const T&> minmax(const T& a, const T& b, Compare comp);

template<class T, class Compare = std::less<T>>
std::pair<T, T> minmax(std::initializer_list<T> ilist, Compare comp = Compare{});
```

- Возвращает `std::pair`, где:
  - `.first` — минимальное значение,
  - `.second` — максимальное значение.
- Если значения равны — `.first` будет ссылкой на `a`, `.second` — на `b`.

### Важные моменты

| Особенность                                                     | Объяснение                                              |
| --------------------------------------------------------------- | ------------------------------------------------------- |
| Возвращает `std::pair<const T&, const T&>`                      | Не копирует, а даёт ссылки                              |
| Если `a == b`, то `.first = a`, `.second = b`                   | Гарантированно                                          |
| Работает с любыми типами, где есть `operator<` или компаратор   | `int`, `double`, `std::string`, пользовательские классы |
| Для трёх и более значений — используйте `std::initializer_list` | `std::minmax({a, b, c})`                                |
| Не изменяет аргументы                                           | Только читает                                           |

### Лучшая практика

| Совет                                                                            | Почему                      |
| -------------------------------------------------------------------------------- | --------------------------- |
| Используйте `std::minmax` вместо двух вызовов `std::min` и `std::max`            | Эффективнее и чище          |
| Используйте structured binding (C++17)                                           | Чистый и понятный код       |
| Проверяйте типы: `std::minmax(1, 2.5)` может вызвать предупреждение              | Лучше использовать один тип |
| Используйте `std::minmax` с `initializer_list`, если нужно выбрать из нескольких | Читаемо и эффективно        |
| Комбинируйте с `std::clamp`, `std::distance` и др.                               | Полезно при анализе данных  |
