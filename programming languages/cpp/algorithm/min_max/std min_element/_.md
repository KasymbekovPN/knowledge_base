[[programming languages/cpp/algorithm/min_max/_|<=]]

Функция `std::min_element` из заголовочного файла `<algorithm>` используется для **поиска итератора на наименьший элемент** в диапазоне.

> ✅ Это мощный инструмент:
> - Работает с любыми контейнерами STL,
> - Поддерживает пользовательские компараторы,
> - Не изменяет данные,
> - Идеально подходит для поиска минимума в `std::vector`, `std::array`, `std::list`, массивах и т.д.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
ForwardIterator min_element(ForwardIterator first, ForwardIterator last);

template<class ForwardIterator, class Compare>
ForwardIterator min_element(ForwardIterator first, ForwardIterator last, Compare comp);
```

- Возвращает итератор на **наименьший элемент**
- Если диапазон пуст — возвращает `last`
- Если несколько элементов равны минимуму — возвращает итератор на **первый** из них

### Важные моменты

| Особенность                               | Объяснение                        |
| ----------------------------------------- | --------------------------------- |
| Работает за O(n)                          | Проверяет каждый элемент один раз |
| Не изменяет данные                        | Только читает                     |
| Может принимать лямбды, функции, функторы | Для гибкого сравнения             |
| Возвращает **первый** минимальный элемент | Если их несколько                 |
| Если диапазон пуст — возвращает `last`    | Проверяйте перед разыменованием   |

### Лучшая практика

| Совет                                                         | Почему                                            |
| ------------------------------------------------------------- | ------------------------------------------------- |
| Всегда проверяйте, что `it != end()` перед разыменованием     | Чтобы избежать UB                                 |
| Используйте `std::distance`, чтобы получить индекс            | Полезно при работе с `std::vector`, `std::string` |
| Используйте лямбды для гибкого сравнения                      | Например, по полю структуры                       |
| Избегайте `std::min_element` в больших циклах без оптимизации | Это O(n), может быть медленным                    |
| Комбинируйте с `std::remove`, `std::erase` и т.д.             | Для изменения контейнера                          |
