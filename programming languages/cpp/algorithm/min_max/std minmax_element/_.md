[[programming languages/cpp/algorithm/min_max/_|<=]]

Функция `std::minmax_element` из заголовочного файла `<algorithm>` используется для **поиска итераторов на минимальный и максимальный элементы** в диапазоне **за один проход**.

> ✅ Это эффективная альтернатива вызову `std::min_element` и `std::max_element` по отдельности — работает быстрее, особенно на больших данных.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
std::pair<ForwardIterator, ForwardIterator>
minmax_element(ForwardIterator first, ForwardIterator last);

template<class ForwardIterator, class Compare>
std::pair<ForwardIterator, ForwardIterator>
minmax_element(ForwardIterator first, ForwardIterator last, Compare comp);
```

- Возвращает `std::pair`:
  - `.first` — итератор на **минимальный** элемент,
  - `.second` — итератор на **максимальный** элемент.
- Если диапазон пуст — возвращает `{last, last}`.
- Работает за **O(3n/2)** сравнений (оптимально).

### Важные моменты

| Особенность                                                            | Объяснение                                 |
| ---------------------------------------------------------------------- | ------------------------------------------ |
| Работает за **один проход**                                            | Быстрее, чем `min_element` + `max_element` |
| Возвращает `std::pair<It, It>`                                         | `.first` — min, `.second` — max            |
| Если несколько мин/макс — возвращает **первый min**, **последний max** | Гарантированное поведение                  |
| Требует, чтобы `comp` был строгим слабым упорядочением                 | Как и другие алгоритмы                     |
| Не изменяет данные                                                     | Только читает                              |

### Лучшая практика

| Совет                                                            | Почему                                                          |
| ---------------------------------------------------------------- | --------------------------------------------------------------- |
| Используйте `std::minmax_element`, если нужно и min, и max       | Эффективнее двух вызовов                                        |
| Проверяйте, что диапазон не пуст                                 | `if (result.first == last)`                                     |
| Используйте structured binding (C++17)                           | Чистый и понятный код                                           |
| Используйте `std::distance` для получения индексов               | Полезно при анализе                                             |
| Избегайте `std::minmax_element` в больших циклах без оптимизации | Это O(n), но может быть медленно при многократном использовании |
