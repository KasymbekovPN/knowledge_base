[[programming languages/cpp/algorithm/min_max/_|<=]]

Функция `std::min` из заголовочного файла `<algorithm>` используется для **нахождения минимального из двух значений**.

> ✅ Это простая, но мощная функция, которая:
> - Работает с любыми типами, поддерживающими `operator<`,
> - Поддерживает пользовательские компараторы,
> - Может использоваться с лямбдами и функторами,
> - Является частью STL и оптимизирована компилятором.


### Синтаксис

```cpp
#include <algorithm>

template<class T>
const T& min(const T& a, const T& b);

template<class T, class Compare>
const T& min(const T& a, const T& b, Compare comp);

template<class T, class Compare = std::less<T>>
T min(std::initializer_list<T> ilist, Compare comp = Compare{});
```

- Возвращает **ссылку** на наименьшее значение
- Если значения равны — возвращает первое (`a`)

### Важные моменты

| Особенность                                                     | Объяснение                  |
| --------------------------------------------------------------- | --------------------------- |
| Возвращает **ссылку** на один из аргументов                     | Не копирует                 |
| Если `a == b`, возвращает `a`                                   | Гарантированно первое       |
| Работает с любыми типами, где есть `operator<`                  | Или пользовательский `comp` |
| Для трёх и более значений — используйте `std::initializer_list` | `std::min({a, b, c})`       |
| Не изменяет аргументы                                           | Только читает               |

### Лучшая практика

| Совет                                                                         | Почему                                 |
| ----------------------------------------------------------------------------- | -------------------------------------- |
| Используйте `std::min` вместо `#define min`                                   | Избегайте коллизий с WinAPI и т.д.     |
| Используйте `std::clamp`, если нужно ограничить значение                      | Например, `clamp(x, 0, 100)`           |
| Проверяйте типы: `std::min(1, 2.5)` может вызвать предупреждение              | Лучше использовать один тип            |
| Используйте `std::min` с `initializer_list`, если нужно выбрать из нескольких | Чистый и понятный код                  |
| Комбинируйте с `std::max` для `clamp`                                         | `std::max(low, std::min(high, value))` |
