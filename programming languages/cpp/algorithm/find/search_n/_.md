Функция `std::search_n` из заголовочного файла `<algorithm>` используется для **поиска последовательности, состоящей из N повторений одного и того же элемента**.

> ✅ Это удобно:
> - При поиске **повторяющихся значений**,
> - Например, найти 3 подряд идущих пробела, 5 нулей, или что-то подобное.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: поиск N повторений заданного значения
template<class ForwardIterator, class Size, class T>
ForwardIterator search_n(ForwardIterator first, ForwardIterator last,
                          Size count, const T& value);

// Версия 2: с пользовательским предикатом (C++11+)
template<class ForwardIterator, class Size, class T, class BinaryPredicate>
ForwardIterator search_n(ForwardIterator first, ForwardIterator last,
                          Size count, const T& value,
                          BinaryPredicate pred);
```

- Возвращает итератор на начало найденной последовательности.
- Если не найдено — возвращает `last`.

### Важные моменты

| Особенность | Объяснение |
|-------------|------------|
| Ищет **ровно N подряд идущих элементов** | Не менее, не более |
| Может работать с любыми итерируемыми структурами | `std::vector`, `std::string`, массивами и т.д. |
| Работает за O(n) | Проверяет каждый элемент |
| Можно использовать с лямбдами и функторами | Для гибкого сравнения |
| Не изменяет данные | Только читает |

### Когда использовать `std::search_n`?

| Ситуация                                          | Почему                                    |
| ------------------------------------------------- | ----------------------------------------- |
| Нужно найти N повторений одного значения          | Например, серию нулей, пробелов, символов |
| Хотите использовать STL вместо циклов             | Чистый и безопасный код                   |
| Нужно неточное сравнение                          | С лямбдой или функтором                   |
| Контейнер не отсортирован                         | Подходит для любого порядка               |
| Хотите сохранить индекс в оригинальном контейнере | `search_n` возвращает итератор            |

### Лучшая практика

| Совет                                                  | Почему                                                 |
| ------------------------------------------------------ | ------------------------------------------------------ |
| Используйте `std::search_n` для поиска повторений      | Например, серии нулей, пробелов, символов              |
| Используйте лямбду или функтор для неточного сравнения | Например, `double` с допуском                          |
| Проверяйте результат на `!= end()`                     | Чтобы избежать разыменования невалидного итератора     |
| Избегайте `search_n` в больших данных без оптимизации  | Это O(n), может быть медленным при многократном вызове |
| Комбинируйте с другими алгоритмами                     | Например, `std::copy`, `std::remove_if`                |
