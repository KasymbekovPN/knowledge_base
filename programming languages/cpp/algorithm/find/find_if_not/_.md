[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::find_if_not` — это часть библиотеки `<algorithm>` и появилась в **C++11**.  
Она используется для поиска первого элемента в диапазоне, который **не удовлетворяет** заданному условию (предикату).

Это противоположность `std::find_if`, которая находит первый элемент, **удовлетворяющий** предикату.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIt, class UnaryPredicate>
InputIt find_if_not(InputIt first, InputIt last, UnaryPredicate p);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `p` — унарный предикат, возвращающий `bool`
- Возвращает: итератор на **первый элемент**, для которого `p(element) == false`  
  или `last`, если все элементы удовлетворяют условию

### Важные моменты

| Особенность                               | Объяснение                                         |
| ----------------------------------------- | -------------------------------------------------- |
| Работает за O(n)                          | Линейный перебор                                   |
| Не требует сортировки                     | Подходит для любого контейнера                     |
| Всегда проверяйте результат на `!= end()` | Чтобы избежать разыменования невалидного итератора |
| Предикат должен быть унарным              | Принимает один аргумент — элемент диапазона        |

### Когда использовать?

| Ситуация                                        | Почему `std::find_if_not` подходит                              |
| ----------------------------------------------- | --------------------------------------------------------------- |
| Нужно найти элемент, не удовлетворяющий условию | Например, нечётное число, пустая строка, значение вне диапазона |
| Условие сложно выразить через `!condition`      | Например, лямбда или функтор                                    |
| Контейнер не отсортирован                       | Подходит любой порядок данных                                   |
| Нужно изменить/удалить найденный элемент        | Возвращает итератор                                             |
### Лучшая практика

| Совет                                                    | Почему                                        |
| -------------------------------------------------------- | --------------------------------------------- |
| Используйте `std::find_if_not` вместо циклов             | Более читаемо и безопасно                     |
| Используйте с лямбдами для краткости                     | Например, `[](int x){ return x > 10; }`       |
| Проверяйте результат перед использованием                | Чтобы не было ошибок доступа                  |
| Для поиска всех элементов используйте цикл или `copy_if` | `std::find_if_not` ищет только первый элемент |
| Комбинируйте с другими STL алгоритмами                   | Например, `erase` после `find_if_not`         |
