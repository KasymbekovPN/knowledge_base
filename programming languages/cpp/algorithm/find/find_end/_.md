[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::find_end` из заголовочного файла `<algorithm>` используется для **поиска последнего вхождения подпоследовательности** внутри заданного диапазона.

> 💡 Она противоположна функции `std::search`, которая ищет **первое вхождение**, а `std::find_end` — **последнее**.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: сравнение через operator==
template<class ForwardIterator1, class ForwardIterator2>
ForwardIterator1 find_end(ForwardIterator1 first1, ForwardIterator1 last1,
                          ForwardIterator2 first2, ForwardIterator2 last2);

// Версия 2: с пользовательским предикатом (C++11+)
template<class ForwardIterator1, class ForwardIterator2, class BinaryPredicate>
ForwardIterator1 find_end(ForwardIterator1 first1, ForwardIterator1 last1,
                          ForwardIterator2 first2, ForwardIterator2 last2,
                          BinaryPredicate pred);
```

- Возвращает итератор на **начало найденной подпоследовательности**
- Если не найдено — возвращает `last1`
- Работает с любыми контейнерами или массивами

### Важные моменты

| Особенность                                                 | Объяснение                                         |
| ----------------------------------------------------------- | -------------------------------------------------- |
| Ищет **последнее** вхождение подпоследовательности          | В отличие от `std::search`                         |
| Не требует отсортированности                                | Подходит для любого порядка                        |
| Может работать с любыми итераторами                         | `std::vector`, `std::list`, `std::string`, массивы |
| Первый диапазон (`haystack`) должен быть достаточно большим | Чтобы вместить `needle`                            |
| Начиная с C++11 можно использовать custom predicate         | Для неточного сравнения                            |

### Когда использовать `std::find_end`?

| Ситуация                                                            | Почему                                |
| ------------------------------------------------------------------- | ------------------------------------- |
| Нужно найти **последнее вхождение** подстроки/подпоследовательности | Например, в поиске слов, тегов, чисел |
| Требуется гибкость сравнения                                        | Через лямбду или функтор              |
| Работа с `std::string`, `std::vector`, массивами                    | Поддерживается полностью              |
| Поиск в текстовых данных                                            | Например, HTML, JSON, логах           |
### Лучшая практика

| Совет                                                                   | Почему                                                  |
| ----------------------------------------------------------------------- | ------------------------------------------------------- |
| Проверяйте результат на `!= end()`                                      | Чтобы избежать разыменования невалидного итератора      |
| Используйте `std::string::rfind`, если работаете со строками            | Более простой и эффективный метод                       |
| Используйте `std::equal_to` или кастомный `pred` при неточном сравнении | Например, без учёта регистра                            |
| Используйте `std::distance` для получения индекса                       | Полезно для работы с `std::string`, `std::vector` и др. |
| Избегайте использования на больших данных без оптимизации               | Это O(n*m) алгоритм                                     |
