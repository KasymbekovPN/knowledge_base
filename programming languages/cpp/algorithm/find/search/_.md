Функция `std::search` из заголовочного файла `<algorithm>` используется для **поиска первой подпоследовательности**, которая совпадает с заданной последовательностью.

Она особенно полезна при:
- Поиске подстроки в строке,
- Поиске шаблона в массиве или контейнере,
- Работе с бинарными данными, логами, протоколами и т.д.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: поиск через operator==
template<class ForwardIterator1, class ForwardIterator2>
ForwardIterator1 search(ForwardIterator1 first1, ForwardIterator1 last1,
                         ForwardIterator2 first2, ForwardIterator2 last2);

// Версия 2: с пользовательским предикатом (C++11+)
template<class ForwardIterator1, class ForwardIterator2, class BinaryPredicate>
ForwardIterator1 search(ForwardIterator1 first1, ForwardIterator1 last1,
                         ForwardIterator2 first2, ForwardIterator2 last2,
                         BinaryPredicate pred);
```

- Возвращает итератор на **первое вхождение** подпоследовательности.
- Если не найдено — возвращает `last1`.

### Важные моменты

| Особенность                                  | Объяснение                                           |
| -------------------------------------------- | ---------------------------------------------------- |
| Ищет первую подпоследовательность            | В отличие от `std::find_end`, который ищет последнюю |
| Работает за O(n * m)                         | Где n — длина haystack, m — длина needle             |
| Не изменяет данные                           | Только читает                                        |
| Может принимать лямбды, функторы или функции | Для неточного сравнения                              |
| Требуется, чтобы `first2 <= last2`           | Иначе — неопределённое поведение                     |

### Когда использовать `std::search`?

| Ситуация                                         | Почему                                  |
| ------------------------------------------------ | --------------------------------------- |
| Нужно найти подстроку/подпоследовательность      | Например, `std::string`, `std::vector`  |
| Хотите гибкое сравнение                          | С лямбдой или функтором                 |
| Контейнер не отсортирован                        | Подходит для любого порядка             |
| Нужно сохранить индекс в оригинальном контейнере | `std::search` возвращает итератор       |
| Хотите работать с STL алгоритмами                | Например, `std::copy`, `std::remove_if` |

### Лучшая практика

| Совет                                                              | Почему                                             |
| ------------------------------------------------------------------ | -------------------------------------------------- |
| Используйте `std::search`, если нужно найти подпоследовательность  | Например, в строках, числах, структурах            |
| Используйте лямбду или функтор для неточного сравнения             | Например, регистронезависимый поиск в строках      |
| Проверяйте результат на `!= end()`                                 | Чтобы избежать разыменования невалидного итератора |
| Избегайте `std::search` на больших данных без оптимизации          | Это O(n*m), может быть медленным                   |
| Используйте `std::string::find`, если работаете только со строками | Более эффективно в этом случае                     |
