[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::find_if` из заголовочного файла `<algorithm>` используется для **поиска первого элемента в диапазоне, удовлетворяющего заданному условию (предикату)**.

Она особенно полезна, когда:
- Вы ищете не конкретное значение, а **элемент по сложному условию**,
- У вас **неотсортированный контейнер**,
- Нужно использовать **лямбду или функтор**, чтобы определить условие поиска.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIt, class UnaryPredicate>
InputIt find_if(InputIt first, InputIt last, UnaryPredicate p);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `p` — унарный предикат (функция, лямбда или функтор), возвращающий `bool`
- Возвращает: итератор на первый элемент, для которого `p(element) == true`,  
  или `last`, если такой элемент не найден

### Важные моменты

| Особенность                               | Объяснение                                         |
| ----------------------------------------- | -------------------------------------------------- |
| Работает за O(n)                          | Перебирает элементы подряд                         |
| Не требует отсортированности              | Подходит для любого порядка данных                 |
| Может принимать лямбды, функции, функторы | Очень гибкий выбор условия                         |
| Всегда проверяйте результат (`!= end()`)  | Чтобы избежать разыменования невалидного итератора |

### Лучшая практика

| Совет                                                                 | Почему                             |
| --------------------------------------------------------------------- | ---------------------------------- |
| Используйте `std::find_if` вместо ручных циклов                       | Читаемость, безопасность           |
| Храните результат в `auto`                                            | Избегайте ошибок с типом итератора |
| Проверяйте `!= end()` перед разыменованием                            | Избегайте segmentation fault       |
| Используйте лямбды для краткости                                      | Особенно для временных условий     |
| Используйте функторы или `std::function` для повторного использования | Если условие часто встречается     |
