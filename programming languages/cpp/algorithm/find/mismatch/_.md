[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::mismatch` из заголовочного файла `<algorithm>` используется для **поиска первой позиции**, где два диапазона **не совпадают**.

Это полезно:
- Для сравнения двух последовательностей,
- При реализации пользовательских алгоритмов сравнения,
- Для поиска различий между массивами, строками или контейнерами.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: стандартное сравнение через operator==
template<class InputIterator1, class InputIterator2>
std::pair<InputIterator1, InputIterator2> mismatch(
    InputIterator1 first1, InputIterator1 last1,
    InputIterator2 first2);

// Версия 2: с пользовательским предикатом (C++14+)
template<class InputIterator1, class InputIterator2, class BinaryPredicate>
std::pair<InputIterator1, InputIterator2> mismatch(
    InputIterator1 first1, InputIterator1 last1,
    InputIterator2 first2, BinaryPredicate pred);
```

- Возвращает пару итераторов: `{it1, it2}`, указывающих на **первое несовпадающее место**
- Если все элементы совпадают — возвращает `{last1, first2 + N}`

### Важные моменты

| Особенность                         | Объяснение                                                 |
| ----------------------------------- | ---------------------------------------------------------- |
| Работает за O(n)                    | Перебирает элементы подряд                                 |
| Возвращает пару итераторов          | На несовпадающие элементы в обоих диапазонах               |
| Может принимать лямбды или функторы | Через пользовательский предикат                            |
| Не проверяет длины контейнеров      | Вы должны убедиться, что второй диапазон не короче первого |

### Лучшая практика

| Совет                                                             | Почему                                                  |
| ----------------------------------------------------------------- | ------------------------------------------------------- |
| Всегда проверяйте результат на `!= end()`                         | Чтобы избежать разыменования невалидного итератора      |
| Используйте с `std::equal`, если нужно только проверить равенство |                                                         |
| Используйте лямбды или функторы для гибкого сравнения             | Например, `abs(a - b) < 1e-6` для `double`              |
| Учитывайте длины контейнеров                                      | Если второй диапазон короче — UB                        |
| Комбинируйте с `std::distance` для получения индекса              | Полезно для работы с `std::vector`, `std::string` и др. |
