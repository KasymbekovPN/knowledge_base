[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::find_first_of` из заголовочного файла `<algorithm>` используется для **поиска первого элемента в диапазоне**, который совпадает с **любым элементом из другого диапазона**.

> 💡 Это похоже на функцию `std::find`, но вместо одного значения вы ищете **любое значение из набора**.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: поиск через operator==
template<class InputIterator, class ForwardIterator>
InputIterator find_first_of(InputIterator first1, InputIterator last1,
                             ForwardIterator first2, ForwardIterator last2);

// Версия 2: с пользовательским предикатом (C++11+)
template<class InputIterator, class ForwardIterator, class BinaryPredicate>
InputIterator find_first_of(InputIterator first1, InputIterator last1,
                             ForwardIterator first2, ForwardIterator last2,
                             BinaryPredicate pred);
```

- Возвращает итератор на **первый найденный элемент**
- Если ничего не найдено — возвращает `last1`

### Важные моменты

| Особенность                                                     | Объяснение                                                            |
| --------------------------------------------------------------- | --------------------------------------------------------------------- |
| Ищет первый элемент из второго диапазона, который есть в первом | Порядок важен                                                         |
| Работает за O(n*m)                                              | Для каждого элемента первого диапазона проверяет все элементы второго |
| Может принимать лямбды, функторы или функции                    | Через пользовательский предикат                                       |
| Не требует отсортированности                                    | Подходит для любого порядка данных                                    |
| Никогда не изменяет данные                                      | Только читает                                                         |
### Лучшая практика

| Совет                                                                          | Почему                                             |
| ------------------------------------------------------------------------------ | -------------------------------------------------- |
| Используйте `std::find_first_of`, если нужно искать среди нескольких вариантов | Например, символы разделителей                     |
| Используйте лямбду или функтор для неточного сравнения                         | Например, числа с допуском (`abs(a - b) < 1e-6`)   |
| Храните второй диапазон как `std::set` или `std::unordered_set`                | Для ускорения поиска (если часто используете)      |
| Проверяйте результат на `!= end()`                                             | Чтобы избежать разыменования невалидного итератора |
| Избегайте больших диапазонов без оптимизации                                   | Это O(n*m), может быть медленным                   |
