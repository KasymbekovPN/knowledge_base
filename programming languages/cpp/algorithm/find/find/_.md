[[programming languages/cpp/algorithm/find/_|<=]]

Функция `std::find` из заголовочного файла `<algorithm>` используется для **поиска элемента в диапазоне**. Она работает с любыми контейнерами, поддерживающими итераторы (векторы, списки, массивы и т.д.).

```cpp
#include <algorithm>

template<class InputIterator, class T>
InputIterator find(InputIterator first, InputIterator last, const T& value);
```

- `first`, `last` — итераторы, задающие диапазон поиска `[first, last)`
- `value` — значение, которое ищем
- Возвращает:
  - Итератор на первый найденный элемент, равный `value`
  - `last`, если элемент не найден

### Важные моменты

| Особенность                       | Объяснение                                                                |
| --------------------------------- | ------------------------------------------------------------------------- |
| Сравнение идёт через `operator==` | Проверяет, равен ли элемент `value`                                       |
| Работает за линейное время O(n)   | Перебирает элементы подряд                                                |
| Не требует отсортированности      | Подходит для любого порядка данных                                        |
| Возвращает итератор               | Можно использовать для изменения элемента (если контейнер не константный) |

### Как проверить, найден ли элемент?

```cpp
auto it = std::find(...);
if (it != end) {
    // found
} else {
    // not found
}
```

### Когда использовать `std::find`?

| Ситуация                                      | Рекомендация                                                             |
| --------------------------------------------- | ------------------------------------------------------------------------ |
| Поиск значения в неотсортированном контейнере | ✅ Отлично подходит                                                       |
| Контейнер содержит тысячи элементов           | ⚠️ Может быть медленным                                                  |
| Нужна скорость поиска                         | ❌ Лучше использовать `std::unordered_set`, `std::map` или бинарный поиск |
| Нужно найти позицию элемента                  | ✅ Возвращает итератор                                                    |
| Нужно найти все вхождения                     | ❌ Используйте цикл или `std::find_if`                                    |
