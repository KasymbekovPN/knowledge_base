Функция `std::adjacent_find` из заголовочного файла `<algorithm>` используется для **поиска двух соседних элементов**, которые **удовлетворяют определённому условию**. По умолчанию она ищет **два одинаковых (равных) подряд идущих элемента**.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: ищет два равных соседних элемента
template<class ForwardIterator>
ForwardIterator adjacent_find(ForwardIterator first, ForwardIterator last);

// Версия 2: ищет два соседних элемента, удовлетворяющих предикату
template<class ForwardIterator, class BinaryPredicate>
ForwardIterator adjacent_find(ForwardIterator first, ForwardIterator last, BinaryPredicate pred);
```

- Возвращает итератор на **первую позицию**, где найдено совпадение,
- Если ничего не найдено — возвращает `last`.

### Важные моменты

| Особенность                                  | Объяснение                     |
| -------------------------------------------- | ------------------------------ |
| Работает за O(n)                             | Проверяет пары по порядку      |
| Не требует отсортированности                 | Подходит для любого контейнера |
| Может принимать лямбды, функторы или функции | Для гибкого условия            |
| Возвращает указатель на первый элемент пары  | `*it` и `*(it + 1)` — пара     |
### Лучшая практика

| Совет                                                                    | Почему                                             |
| ------------------------------------------------------------------------ | -------------------------------------------------- |
| Используйте `std::adjacent_find`, если вам нужно найти соседние элементы | Особенно полезно при анализе данных                |
| Используйте лямбду для нетривиального сравнения                          | Например, числа с допуском (`abs(a - b) < 1e-6`)   |
| Проверяйте результат на `!= end()`                                       | Чтобы избежать разыменования невалидного итератора |
| Используйте с `std::string`, `std::vector`, массивами                    | Универсально                                       |
| Избегайте лишних вызовов в цикле                                         | Это O(n), но может быть медленно на больших данных |
