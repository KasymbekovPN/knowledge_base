Функция `std::reverse` из заголовочного файла `<algorithm>` используется для **обратного порядка элементов в диапазоне**.

Она особенно полезна:
- При работе с массивами, строками и STL контейнерами (`std::vector`, `std::list`, `std::deque`)
- Для изменения порядка данных без создания нового контейнера
- В алгоритмах, где важен обратный обход

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator>
void reverse(BidirectionalIterator first, BidirectionalIterator last);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- Функция **не возвращает ничего**, она модифицирует данные "на месте"

> ✅ Работает с любыми bidirectional итераторами (векторы, строки, списки)

### Важные моменты

| Особенность                                                      | Объяснение                                    |
| ---------------------------------------------------------------- | --------------------------------------------- |
| Меняет исходный контейнер                                        | Не создает копию                              |
| Работает за O(n)                                                 | Проверяет пары по одному разу                 |
| Требуется `operator=` для пользовательских типов                 | Чтобы можно было менять местами               |
| Подходит для `std::vector`, `std::list`, `std::string`, массивов | Универсальность                               |
| Нужно убедиться, что итераторы поддерживают двусторонний доступ  | Например, не подходит для `std::forward_list` |

## ✅ Лучшая практика

| Совет                                                                     | Почему                                                        |
| ------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Используйте `std::reverse`, если нужно перевернуть контейнер "на месте"   | Без создания копии                                            |
| Используйте `std::reverse_copy`, если оригинал должен остаться неизменным | Например, для анализа                                         |
| Избегайте `std::reverse` с `std::forward_list`                            | Он не поддерживает реверс напрямую                            |
| Комбинируйте с `std::distance` для получения индекса                      | Полезно при работе с `std::vector`, `std::string`             |
| Избегайте `std::reverse` в больших данных без оптимизации                 | Это O(n), может быть медленным при многократном использовании |
