Функция `std::unique` из заголовочного файла `<algorithm>` используется для **удаления соседних дубликатов** из диапазона.

> ⚠️ Важно: `std::unique` **не удаляет элементы физически**, а **перемещает уникальные элементы в начало**, и возвращает итератор на "новый конец".  
Чтобы реально удалить лишние элементы, нужно вызвать `erase()` — это называется **idiom erase–unique**.

### Синтаксис

```cpp
#include <algorithm>

// Версия 1: через operator==
template<class ForwardIterator>
ForwardIterator unique(ForwardIterator first, ForwardIterator last);

// Версия 2: с пользовательским предикатом (C++11+)
template<class ForwardIterator, class BinaryPredicate>
ForwardIterator unique(ForwardIterator first, ForwardIterator last,
                       BinaryPredicate pred);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `pred` — бинарный предикат, возвращающий `true`, если два элемента считаются равными
- Возвращает: итератор на "новый конец" — точка, после которой могут быть дубликаты

### Важные моменты

| Особенность                                  | Объяснение                            |
| -------------------------------------------- | ------------------------------------- |
| Не удаляет элементы физически                | Только перемещает их в начало         |
| Работает за O(n)                             | Проходит по каждому элементу один раз |
| Может принимать лямбды, функции, функторы    | Для неточного сравнения               |
| Нужно вызывать `erase()` после `std::unique` | Чтобы очистить остаток                |
| Сохраняет порядок неудалённых элементов      | Полезно при обработке данных          |

### Лучшая практика

| Совет                                                                          | Почему                                                        |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| Всегда комбинируйте `std::unique` с `erase()`                                  | Чтобы очистить память                                         |
| Используйте лямбду или функтор для гибкого сравнения                           | Например, `abs(a - b) < 1e-6` для `double`                    |
| Проверяйте, что контейнер отсортирован, если хотите полное удаление дубликатов | Иначе не все дубликаты будут удалены                          |
| Избегайте `std::unique` в больших данных без оптимизации                       | Это O(n), может быть медленным при многократном использовании |
| Используйте `std::unique` вместо цикла `for` с `erase`                         | Более читаемый и понятный код                                 |
