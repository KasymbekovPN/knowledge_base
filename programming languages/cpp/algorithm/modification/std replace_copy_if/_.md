Функция `std::replace_copy_if` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, заменяя элементы, которые удовлетворяют заданному условию (предикату)**.  
Она особенно полезна:
- При фильтрации и замене значений,
- Когда нужно изменить только определённые элементы,
- В обработке данных без ручных циклов.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator, class UnaryPredicate, class T>
OutputIterator replace_copy_if(InputIterator first, InputIterator last,
                               OutputIterator result,
                               UnaryPredicate pred, const T& new_value);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- `pred` — унарный предикат, возвращающий `true`, если элемент нужно заменить
- `new_value` — значение, на которое заменять
- Возвращает: итератор на конец скопированной последовательности

> ✅ Функция **не изменяет исходный контейнер**, а создаёт новый с заменёнными значениями.

### Лучшая практика

| Совет                                                                                        | Почему                                      |
| -------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Используйте `std::replace_copy_if`, если условие сложно выразить через `==`                  | Например, `x % 2 == 0`                      |
| Используйте лямбду для краткости                                                             | Особенно для временных условий              |
| Комбинируйте с `std::back_inserter` и `std::replace_copy_if`, если хотите сохранить оригинал | Полезно при тестировании                    |
| Избегайте `std::replace_copy_if` в больших циклах без оптимизации                            | Это O(n), может быть медленным              |
| Перегружайте `operator=` для пользовательских классов                                        | Чтобы можно было присваивать новое значение |
