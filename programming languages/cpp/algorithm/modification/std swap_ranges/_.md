Функция `std::swap_ranges` из заголовочного файла `<algorithm>` используется для **обмена элементами между двумя диапазонами**.

> ✅ Эта функция **меняет местами элементы в двух диапазонах**, и работает до тех пор, пока не закончится первый диапазон. Если второй диапазон короче — поведение **неопределено** (UB), так что будьте осторожны!

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator1, class ForwardIterator2>
ForwardIterator2 swap_ranges(ForwardIterator1 first1, ForwardIterator1 last1,
                             ForwardIterator2 first2);
```

- `first1`, `last1` — итераторы первого диапазона
- `first2` — начало второго диапазона
- Возвращает: итератор на конец второго диапазона (`first2 + N`, где `N = last1 - first1`)

### Важные моменты

| Особенность                                                 | Объяснение                                         |
| ----------------------------------------------------------- | -------------------------------------------------- |
| Не изменяет размер контейнеров                              | Только меняет значения                             |
| Работает за O(n)                                            | Для каждого элемента вызывается `std::swap`        |
| Требуется, чтобы второй диапазон был **достаточно большим** | Иначе — неопределённое поведение                   |
| Можно использовать с любыми итерируемыми структурами        | Например, `std::vector`, `std::list`, `std::array` |
| Не модифицирует итераторы или структуру контейнеров         | Только содержимое                                  |

### Лучшая практика

| Совет                                                         | Почему                           |
| ------------------------------------------------------------- | -------------------------------- |
| Проверяйте, что второй диапазон достаточно велик              | Чтобы избежать выхода за границы |
| Используйте `std::begin` / `std::end` для STL контейнеров     | Более читаемый и безопасный код  |
| Комбинируйте с `std::distance` для получения индексов         | Полезно при анализе данных       |
| Избегайте `std::swap_ranges` в больших данных без оптимизации | Это O(n), может быть медленным   |
| Используйте `std::swap_ranges` вместо ручных циклов           | Более читаемо и безопасно        |
