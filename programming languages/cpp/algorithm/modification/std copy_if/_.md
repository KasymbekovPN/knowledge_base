Функция `std::copy_if` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, только если выполняется определённое условие (предикат)**.

Она особенно полезна:
- При фильтрации данных,
- Копировании чётных/нечётных чисел,
- Выборке строк, удовлетворяющих условию,
- И вообще — когда нужно **выбрать подмножество** из исходной последовательности.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator, class UnaryPredicate>
OutputIterator copy_if(InputIterator first, InputIterator last,
                       OutputIterator result, UnaryPredicate pred);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- `pred` — унарный предикат, возвращающий `bool`
- Возвращает: итератор на конец скопированной последовательности

> ⚠️ Не добавляет завершающий ноль (`'\0'`) при работе с `char*`.

### Важные моменты

| Особенность                                                            | Объяснение                                   |
| ---------------------------------------------------------------------- | -------------------------------------------- |
| Не изменяет исходные данные                                            | Только чтение                                |
| Нужно использовать `std::back_inserter`, если цель не выделена заранее | Чтобы автоматически расширять контейнер      |
| Предикат должен быть унарным                                           | Принимает один аргумент                      |
| Можно комбинировать с другими STL алгоритмами                          | Например, `std::transform`, `std::remove_if` |
| Работает за O(n)                                                       | Проверяет каждый элемент по одному разу      |

### Когда использовать `std::copy_if`?

| Ситуация                                      | Почему                                            |
| --------------------------------------------- | ------------------------------------------------- |
| Нужно отфильтровать данные перед копированием | Например, чётные, положительные, длина строки > N |
| Хотите использовать STL вместо циклов         | Чистый и безопасный код                           |
| Работаете с любыми итерируемыми структурами   | `std::vector`, `std::list`, массивы, строки       |
| Цель — динамический контейнер                 | Лучше использовать `std::back_inserter`           |
| Хотите сохранить оригинальный порядок         | `std::copy_if` не меняет порядок                  |

### Лучшая практика

| Совет                                                             | Почему                                        |
| ----------------------------------------------------------------- | --------------------------------------------- |
| Используйте `std::back_inserter` с `std::copy_if`                 | Автоматическое расширение целевого контейнера |
| Используйте лямбды для гибких условий                             | Например, `x % 2 == 0`                        |
| Избегайте работы с фиксированными буферами без проверки размера   | Может вызвать переполнение                    |
| Комбинируйте с `std::distance` для получения количества элементов | Полезно для подсчёта                          |
| Используйте `std::copy_if` вместо циклов `for` с условиями        | Более читаемо и безопасно                     |
