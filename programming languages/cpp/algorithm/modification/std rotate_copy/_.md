Функция `std::rotate_copy` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, перемешивая их так, чтобы указанный элемент стал новым первым элементом**.

> ✅ В отличие от `std::rotate`, которая **изменяет исходный контейнер**,  
> `std::rotate_copy` **создаёт новый контейнер** с элементами, переставленными относительно точки `middle`.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class OutputIterator>
OutputIterator rotate_copy(ForwardIterator first, ForwardIterator middle, ForwardIterator last, OutputIterator result);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `middle` — итератор на элемент, который станет новым началом
- `result` — итератор на начало целевого контейнера
- Возвращает: итератор на конец скопированной последовательности

### Важные моменты

| Особенность                                                       | Объяснение                                            |
| ----------------------------------------------------------------- | ----------------------------------------------------- |
| Не изменяет исходный контейнер                                    | Только копирует                                       |
| Работает за O(n)                                                  | Проходит по каждому элементу                          |
| Может принимать лямбды, функторы, функции                         | Но не напрямую — `rotate_copy` не принимает предикаты |
| Нужно перегружать `operator=` для пользовательских типов          | Чтобы можно было копировать                           |
| Подходит для `std::vector`, `std::list`, `std::string` и массивов | Универсальность                                       |

### Лучшая практика

| Совет                                                         | Почему                                  |
| ------------------------------------------------------------- | --------------------------------------- |
| Используйте `std::back_inserter`, если цель пустая            | Чтобы автоматически расширять контейнер |
| Проверяйте, что `middle` находится между `first` и `last`     | Иначе — UB                              |
| Комбинируйте с `std::reverse` или `std::transform`            | Для сложных преобразований              |
| Избегайте `std::rotate_copy` в больших циклах без оптимизации | Это O(n), может быть медленным          |
| Перегружайте `operator=` для пользовательских классов         | Чтобы можно было копировать элементы    |
