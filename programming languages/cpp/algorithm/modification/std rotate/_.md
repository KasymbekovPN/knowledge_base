Функция `std::rotate` из заголовочного файла `<algorithm>` используется для **перемешивания элементов диапазона так, чтобы указанный элемент стал новым первым**.

Это мощный инструмент:
- Полезен при реализации циклических сдвигов,
- Может использоваться для частичной сортировки,
- Подходит для любых bidirectional и forward итераторов.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
ForwardIterator rotate(ForwardIterator first, ForwardIterator middle, ForwardIterator last);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `middle` — итератор на новый первый элемент (должен быть внутри `[first, last)`)
- Возвращает: итератор на новый конец старой части (позиция `first + (last - middle)`)

> ✅ Фактически, `std::rotate` делает следующее:
```cpp
[first ... middle ... last)
 => [middle ... last first ... middle - 1]
```
