Начиная с **C++20**, стандарт предоставляет алгоритм `std::shift_right` из заголовочного файла `<algorithm>`, сдвигает элементы **влево**

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator>
ForwardIterator shift_right(ForwardIterator first, ForwardIterator last, typename std::iterator_traits<ForwardIterator>::difference_type n);
```

- `first`, `last` — диапазон `[first, last)`
- `n` — количество позиций для сдвига
- Возвращают: итератор на новый конец первой части (после сдвига)

> ⚠️ После сдвига старые значения остаются в конце исходного диапазона, но они считаются недействительными.  
> Используйте `erase()` или работайте до `new_end`, чтобы удалить их.

## ⚠️ Важные моменты

| Особенность | Объяснение |
|-------------|------------|
| Работает "на месте" | Не создаёт новый контейнер |
| НЕ заполняет освобождённые места | Они остаются в неопределённом состоянии |
| Подходит для любых ForwardIterator | Например, `std::vector`, `std::list`, `std::string` |
| Удобнее `std::copy` + `std::fill` | Если вам нужен чистый сдвиг |
| Может быть использован в STL контейнерах | Без лишних циклов |

> ❗ Обратите внимание: `std::shift_right` **не заполняет освобожденное пространство** никаким значением.
