Функция `std::unique_copy` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, удаляя соседние дубликаты**.

> ✅ В отличие от `std::unique`, которая модифицирует исходный контейнер,  
> `std::unique_copy` **создаёт новый контейнер**, где рядом стоящие одинаковые элементы заменены на один экземпляр.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator>
OutputIterator unique_copy(InputIterator first, InputIterator last,
                           OutputIterator result);

template<class InputIterator, class OutputIterator, class BinaryPredicate>
OutputIterator unique_copy(InputIterator first, InputIterator last,
                           OutputIterator result, BinaryPredicate pred);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- `pred` — бинарный предикат сравнения (`a == b`)
- Возвращает: итератор на конец скопированной последовательности

### Важные моменты

| Особенность                                                  | Объяснение                        |
| ------------------------------------------------------------ | --------------------------------- |
| Не изменяет исходный контейнер                               | Создаёт копию                     |
| Работает за O(n)                                             | Проверяет каждый элемент один раз |
| Требуется перегрузка `operator==` для пользовательских типов | Чтобы можно было сравнивать       |
| Нужно использовать `std::back_inserter`, если цель пустая    | Иначе может быть выход за границы |
| Сохраняет порядок                                            | Только удаляет соседние дубликаты |

### Лучшая практика

| Совет                                                             | Почему                                                       |
| ----------------------------------------------------------------- | ------------------------------------------------------------ |
| Используйте `std::back_inserter`, если цель пустая                | Чтобы автоматически расширять контейнер                      |
| Используйте лямбду или функтор для гибкости                       | Особенно полезно с `double`, строками и сложными структурами |
| Комбинируйте с `std::distance` для получения количества элементов | Полезно при анализе                                          |
| Избегайте `std::unique_copy` в больших данных без оптимизации     | Это O(n), может быть медленным                               |
| Перегружайте `operator==` для пользовательских классов            | Чтобы можно было сравнивать элементы                         |
