Функция `std::reverse_copy` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, но в обратном порядке**.

> ✅ В отличие от `std::reverse`, которая **изменяет исходный контейнер**,  
> `std::reverse_copy` **создаёт новый контейнер**, в котором элементы идут в обратном порядке.

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator, class OutputIterator>
OutputIterator reverse_copy(BidirectionalIterator first,
                            BidirectionalIterator last,
                            OutputIterator result);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- Возвращает: итератор на конец скопированной последовательности

### Важные моменты

| Особенность                                                       | Объяснение                            |
| ----------------------------------------------------------------- | ------------------------------------- |
| Не изменяет исходный контейнер                                    | Создаёт копию в обратном порядке      |
| Работает за O(n)                                                  | Проходит по каждому элементу          |
| Требуется `operator=` для пользовательских типов                  | Чтобы можно было копировать           |
| Нужно убедиться, что цель достаточно велика                       | Или использовать `std::back_inserter` |
| Подходит для `std::vector`, `std::list`, `std::string` и массивов | Универсальность                       |
