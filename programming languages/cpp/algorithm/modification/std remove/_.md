Функция `std::remove` из заголовочного файла `<algorithm>` **не удаляет элементы физически**, а **перемещает все элементы, не равные заданному значению, в начало диапазона** и возвращает итератор на "новый конец".

> ⚠️ Это важный момент: `std::remove` — это **алгоритм перемешивания**, а не удаления.  
> Чтобы фактически удалить элементы, нужно вызвать метод `erase()`.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
ForwardIterator remove(ForwardIterator first, ForwardIterator last,
                       const T& value);
```

- `first`, `last` — итераторы, определяющие диапазон `[first, last)`
- `value` — значение, которое нужно исключить
- Возвращает: итератор на новый "конец" (точку, после которой идут удалённые элементы)

### Важные моменты

| Особенность                               | Объяснение                                       |
| ----------------------------------------- | ------------------------------------------------ |
| Не удаляет элементы физически             | Только перемешивает их в начало                  |
| Работает за O(n)                          | Проходит по всему диапазону                      |
| Не изменяет порядок неудалённых элементов | Их позиции сохраняются                           |
| Может работать с любыми контейнерами STL  | `std::vector`, `std::list`, `std::string` и т.д. |
| Нужно вызывать `erase()` после `remove()` | Для реального удаления                           |

### Лучшая практика

| Совет | Почему |
|-------|--------|
| Всегда комбинируйте `std::remove` с `erase()` | Чтобы очистить данные |
| Используйте `std::remove_if`, если нужна гибкая логика | Например, числа > N, строки с условием |
| Проверяйте, что тип поддерживает `operator==` | Чтобы `std::remove` мог сравнить значения |
| Избегайте `std::remove` в больших данных без оптимизации | Это O(n), может быть медленным при многократном использовании |
| Используйте `std::remove` вместо циклов | Более читаемо и безопасно |
