Функция `std::replace` из заголовочного файла `<algorithm>` используется для **замены всех элементов в диапазоне**, которые равны заданному значению, на другое значение.

Она особенно полезна:
- При работе с массивами, строками и STL контейнерами (`std::vector`, `std::list`, `std::string` и т.д.)
- Когда нужно заменить определённые значения без ручных циклов
- В обработке данных, фильтрации, очистке

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
void replace(ForwardIterator first, ForwardIterator last,
             const T& old_value, const T& new_value);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `old_value` — значение, которое нужно заменить
- `new_value` — новое значение
- Функция **не возвращает** ничего (`void`)

> ✅ Работает с любыми типами, где можно использовать `operator==`.

### Важные моменты

| Особенность                                                | Объяснение                   |
| ---------------------------------------------------------- | ---------------------------- |
| Изменяет исходный контейнер                                | Не создает новый             |
| Работает за O(n)                                           | Проходит по каждому элементу |
| Требует перегрузки `operator==` для пользовательских типов | Чтобы сравнение работало     |
| Не возвращает результат                                    | Изменяет данные "на месте"   |
| Никогда не выбрасывает исключений                          | Если `operator=` безопасен   |

### Лучшая практика

| Совет                                                               | Почему                                                       |
| ------------------------------------------------------------------- | ------------------------------------------------------------ |
| Используйте `std::replace`, если нужно заменить конкретное значение | Например, замена `0` на `-1`                                 |
| Проверяйте, что тип поддерживает `==` и присваивание                | Особенно при работе с пользовательскими классами             |
| Используйте `std::replace_copy`, если нужно сохранить оригинал      | Например, для анализа                                        |
| Комбинируйте с `std::back_inserter`                                 | Чтобы копировать в динамические контейнеры                   |
| Избегайте `std::replace` для больших структур с частыми вызовами    | Это O(n), может быть медленно при многократном использовании |
