Функция `std::copy` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой**.  
Это одна из базовых функций STL, которая работает с любыми итерируемыми структурами: массивы, `std::vector`, `std::list`, строки и т.д.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator>
OutputIterator copy(InputIterator first, InputIterator last, OutputIterator result);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`  
- `result` — итератор, указывающий на начало целевого контейнера
- Возвращает: итератор на конец скопированной последовательности

> Работает с любыми итераторами (включая массивы, `std::string`, `std::vector`, `std::list` и т.д.)

> Если размер цели больше, чем размер источника, то `std::copy` **не заполняет оставшиеся элементы**, поэтому неинициализированные значения остаются неопределёнными.

### Важные моменты

| Особенность                               | Объяснение                                          |
| ----------------------------------------- | --------------------------------------------------- |
| Не проверяет размер целевого буфера       | Вы должны убедиться, что `dest` достаточно велик    |
| Не добавляет `'\0'` в строки              | При работе с `char*` нужно вручную завершать строку |
| Работает за O(n)                          | Копирует каждый элемент по порядку                  |
| Подходит для POD типов и классов          | Если определены операторы присваивания              |
| Можно использовать с `std::back_inserter` | Чтобы автоматически расширять контейнер             |

### Когда использовать `std::copy`?

| Ситуация                                                   | Почему                                                 |
| ---------------------------------------------------------- | ------------------------------------------------------ |
| Нужно скопировать часть контейнера                         | Например, поддиапазон `std::vector`                    |
| Хотите использовать STL вместо цикла `for`                 | Чистый и безопасный код                                |
| Работаете с массивами, `std::vector`, `std::string` и т.д. | Универсально                                           |
| Хотите сохранить оригинальный порядок                      | `std::copy` просто копирует подряд                     |
| Хотите комбинировать с другими алгоритмами                 | Например, `std::find`, `std::search`, `std::transform` |

### Лучшая практика

| Совет                                                      | Почему                                  |
| ---------------------------------------------------------- | --------------------------------------- |
| Используйте `std::copy` вместо циклов                      | Более читаемо и безопасно               |
| Используйте `std::back_inserter`, если цель динамическая   | Например, `std::vector`, `std::string`  |
| Проверяйте размеры, если используете фиксированные массивы | Чтобы избежать переполнения             |
| Используйте `std::copy_if` для фильтрации                  | Например, только чётные числа           |
| Добавляйте `'\0'` вручную при работе с `char*`             | Чтобы получилась null-terminated строка |
