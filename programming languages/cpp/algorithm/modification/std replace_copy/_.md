Функция `std::replace_copy` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, заменяя указанные значения на новое значение**.  
В отличие от `std::replace`, она **не изменяет исходный контейнер**, а **создаёт новый с заменёнными значениями**.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator, class T>
OutputIterator replace_copy(InputIterator first, InputIterator last,
                             OutputIterator result,
                             const T& old_value, const T& new_value);
```

- `first`, `last` — итераторы, задающие исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- `old_value`, `new_value` — что заменять и на что
- Возвращает: `result + (last - first)` или итератор на конец скопированной последовательности

> ✅ Работает с любыми итерируемыми структурами: `std::vector`, `std::list`, массивами, строками и т.д.

### Важные моменты

| Особенность                                                                   | Объяснение                           |
| ----------------------------------------------------------------------------- | ------------------------------------ |
| Не изменяет исходный контейнер                                                | Создаёт копию                        |
| Работает за O(n)                                                              | Проверяет каждый элемент один раз    |
| Требуется перегрузка `operator==` для пользовательских типов                  | Чтобы можно было сравнивать элементы |
| Нужно использовать `std::back_inserter` или `std::inserter`, если цель пустая | Иначе может быть выход за границы    |
| Подходит для работы с `std::string`, `std::vector`, `std::array` и др.        | Универсальность                      |

### Лучшая практика

| Совет                                                             | Почему                                                               |
| ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| Используйте `std::back_inserter` с `std::replace_copy`            | Чтобы автоматически расширять целевой контейнер                      |
| Используйте лямбду или функтор для гибкости                       | Особенно с `std::replace_if`                                         |
| Не забывайте проверять размер целевого буфера                     | Если используете массивы                                             |
| Комбинируйте с `std::distance` для получения количества элементов | Полезно при анализе                                                  |
| Избегайте лишних копирований                                      | Для больших данных лучше работать с `std::move` или `std::transform` |
