Функция `std::remove_copy_if` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, исключая те элементы, которые удовлетворяют заданному условию (предикату)**.

> ✅ Это мощный инструмент:
> - Полезен при фильтрации данных,
> - Не изменяет исходный контейнер,
> - Подходит для любых итерируемых структур: `std::vector`, `std::string`, массивы и т.д.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class OutputIterator, class UnaryPredicate>
OutputIterator remove_copy_if(InputIterator first, InputIterator last,
                              OutputIterator result,
                              UnaryPredicate pred);
```

- `first`, `last` — исходный диапазон `[first, last)`
- `result` — итератор на начало целевого контейнера
- `pred` — унарный предикат, возвращающий `true`, если элемент нужно исключить
- Возвращает: итератор на конец скопированной последовательности

### Важные моменты

| Особенность                                                | Объяснение                                      |
| ---------------------------------------------------------- | ----------------------------------------------- |
| Не изменяет исходный диапазон                              | Создаёт новый контейнер                         |
| Работает за O(n)                                           | Проверяет каждый элемент один раз               |
| Может принимать лямбды, функции, функторы                  | Для гибкого условия                             |
| Нужно перегружать `operator=` для пользовательских классов | Чтобы можно было копировать                     |
| Подходит для работы с `std::back_inserter`                 | Чтобы автоматически расширять целевой контейнер |

### Лучшая практика

| Совет                                                           | Почему                                       |
| --------------------------------------------------------------- | -------------------------------------------- |
| Используйте `std::back_inserter`, если цель пустая              | Чтобы автоматически добавлять элементы       |
| Используйте лямбду или функтор для условия                      | Особенно полезно с `std::remove_copy_if`     |
| Комбинируйте с `std::distance` для подсчёта удалённых элементов | Полезно для анализа                          |
| Избегайте лишних копирований с большими данными                 | Используйте `std::move` или `std::remove_if` |
| Проверяйте, что `pred` корректно определён                      | Чтобы не возникало UB или ошибок сравнения   |
