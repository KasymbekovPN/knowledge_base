Функция `std::replace_if` из заголовочного файла `<algorithm>` используется для **замены элементов в диапазоне, удовлетворяющих заданному условию (предикату)**.  
Она особенно полезна:
- При фильтрации и замене значений,
- Когда нужно изменить только определённые элементы,
- В обработке данных без ручных циклов.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class UnaryPredicate, class T>
void replace_if(ForwardIterator first, ForwardIterator last,
                UnaryPredicate pred, const T& new_value);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `pred` — унарный предикат, возвращающий `true`, если элемент нужно заменить
- `new_value` — значение, на которое заменять

> ✅ Функция изменяет исходный контейнер "на месте".

### Важные моменты

| Особенность                                              | Объяснение                             |
| -------------------------------------------------------- | -------------------------------------- |
| Изменяет исходный диапазон                               | Без создания нового контейнера         |
| Работает за O(n)                                         | Проверяет каждый элемент один раз      |
| Может принимать лямбды, функции, функторы                | Очень гибкий выбор условия             |
| Нужно перегружать `operator=` для пользовательских типов | Чтобы можно было присвоить `new_value` |
| Не добавляет новые элементы                              | Контейнер должен быть достаточно велик |

### Лучшая практика

| Совет                                                                                        | Почему                                      |
| -------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Используйте `std::replace_if`, если условие сложно выразить через `==`                       | Например, `x % 2 == 0`                      |
| Используйте лямбду для краткости                                                             | Особенно для временных условий              |
| Комбинируйте с `std::back_inserter` и `std::replace_copy_if`, если хотите сохранить оригинал | Полезно при тестировании                    |
| Избегайте `std::replace_if` в больших циклах без оптимизации                                 | Это O(n), может быть медленным              |
| Перегружайте `operator=` для пользовательских классов                                        | Чтобы можно было присваивать новое значение |
