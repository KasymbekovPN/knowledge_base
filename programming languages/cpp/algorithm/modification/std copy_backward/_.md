Функция `std::copy_backward` из заголовочного файла `<algorithm>` используется для **копирования элементов из одного диапазона в другой, но в обратном порядке**.

Она особенно полезна:
- При копировании с перекрывающимися диапазонами,
- Когда нужно сохранить порядок элементов при копировании в конец другого контейнера,
- В алгоритмах, где важно направление копирования (например, при реализации очереди или стека).

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator1, class BidirectionalIterator2>
BidirectionalIterator2 copy_backward(BidirectionalIterator1 first,
                                    BidirectionalIterator1 last,
                                    BidirectionalIterator2 d_last);
```

- Копирует элементы из `[first, last)` в диапазон, заканчивающийся на `d_last`
- Элементы копируются **с конца**, поэтому:
  - Последний элемент исходного диапазона копируется первым
- Возвращает итератор на начало скопированного диапазона (`d_first`)

> ✅ Работает с любыми bidirectional и forward итераторами
