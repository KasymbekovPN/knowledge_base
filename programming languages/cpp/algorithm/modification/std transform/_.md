[[programming languages/cpp/algorithm/modification/_|<=]]

Функция `std::transform` из заголовочного файла `<algorithm>` — это мощный и универсальный инструмент, который **применяет функцию ко всем элементам диапазона**, и сохраняет результаты в другом диапазоне (или в том же самом).

Она особенно полезна:
- При преобразовании данных: изменение регистра, математические операции, фильтрация
- Для работы с любыми контейнерами STL (`std::vector`, `std::list`, `std::string`, массивы и т.д.)
- В комбинации с лямбдами, функторами и стандартными функциями

### Синтаксис

```cpp
#include <algorithm>

// 1. Одиночный диапазон
template<class InputIterator, class OutputIterator, class UnaryOperation>
OutputIterator transform(InputIterator first1, InputIterator last1,
                         OutputIterator result, UnaryOperation op);

// 2. Два диапазона
template<class InputIterator1, class InputIterator2, class OutputIterator, class BinaryOperation>
OutputIterator transform(InputIterator1 first1, InputIterator1 last1,
                         InputIterator2 first2, OutputIterator result,
                         BinaryOperation op);
```

| Версия           | Что делает                                    |
| ---------------- | --------------------------------------------- |
| Одиночная версия | Применяет унарную операцию к каждому элементу |
| Бинарная версия  | Применяет бинарную операцию к двум диапазонам |

### Важные моменты

| Особенность                                                   | Объяснение                                                        |
| ------------------------------------------------------------- | ----------------------------------------------------------------- |
| Не изменяет исходные данные (если не указать тот же диапазон) | Можно использовать как для изменения, так и для копирования       |
| Может принимать лямбды, функторы, функции                     | Очень гибкий выбор операции                                       |
| Нужно позаботиться о размере целевого контейнера              | Или использовать `std::back_inserter`                             |
| Работает за O(n) или O(n*m)                                   | В зависимости от количества диапазонов                            |
| Безопасно ли использовать с перекрытыми диапазонами?          | Да, если вы используете разные диапазоны или `std::back_inserter` |
