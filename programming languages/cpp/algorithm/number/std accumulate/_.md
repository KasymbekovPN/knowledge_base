[[programming languages/cpp/algorithm/number/_|<=]]

Функция `std::accumulate` из заголовочного файла `<numeric>` используется для **вычисления суммы (или обобщённой "суммы") элементов диапазона**.

> 📌 Это один из самых полезных алгоритмов для:
> - Суммирования,
> - Вычисления произведения,
> - Конкатенации строк,
> - И любых других бинарных операций.

### Синтаксис

```cpp
template<class InputIterator, class T>
T accumulate(InputIterator first, InputIterator last, T init);

template<class InputIterator, class T, class BinaryOperation>
T accumulate(InputIterator first, InputIterator last, T init, BinaryOperation op);
```

- `first`, `last` — диапазон `[first, last)`
- `init` — начальное значение
- `op` — бинарная операция (например, `+`, `*`, лямбда)

### Важные моменты

| Особенность                                                             | Объяснение                                              |
| ----------------------------------------------------------------------- | ------------------------------------------------------- |
| Требует `<numeric>`                                                     | Не путать с `<algorithm>`                               |
| Начальное значение (`init`) обязательно                                 | Даже если контейнер пустой                              |
| Работает с любыми типами                                                | `int`, `double`, `std::string`, пользовательские классы |
| Может принимать лямбды, функторы, `std::plus`, `std::multiplies` и т.д. | Очень гибко                                             |
| Не изменяет исходный диапазон                                           | Только читает                                           |

### Лучшая практика

| Совет                                                | Почему                               |
| ---------------------------------------------------- | ------------------------------------ |
| Всегда указывайте начальное значение                 | Чтобы избежать ошибок                |
| Используйте `0LL` для `long long`, если нужно        | Избегайте переполнения               |
| Используйте лямбды для сложных операций              | Читаемо и гибко                      |
| Не используйте `accumulate` для перемещения объектов | Он копирует/добавляет                |
| Комбинируйте с `std::transform` при необходимости    | Например: `transform` → `accumulate` |
