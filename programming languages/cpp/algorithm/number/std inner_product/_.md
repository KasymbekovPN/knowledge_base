Функция `std::inner_product` из заголовочного файла `<numeric>` вычисляет **внутреннее (скалярное) произведение** двух диапазонов, но на самом деле — это **обобщённый алгоритм свёртки**, который можно использовать для множества задач.

> ✅ Это мощная функция:
> - Для скалярного произведения векторов,
> - Для кастомных операций "умножения" и "сложения",
> - Как альтернатива `std::accumulate` с двумя источниками.

### Синтаксис

```cpp
template<class InputIterator1, class InputIterator2, class T>
T inner_product(InputIterator1 first1, InputIterator1 last1,
                InputIterator2 first2, T init);

template<class InputIterator1, class InputIterator2, class T,
         class BinaryOperation1, class BinaryOperation2>
T inner_product(InputIterator1 first1, InputIterator1 last1,
                InputIterator2 first2, T init,
                BinaryOperation1 op1,  // "sum"
                BinaryOperation2 op2); // "mul"
```

- Диапазоны: `[first1, last1)` и `[first2, first2 + N)`
- `init` — начальное значение
- `op1` — бинарная операция "суммы" (по умолчанию `+`)
- `op2` — бинарная операция "произведения" (по умолчанию `*`)

### Важные моменты

| Особенность                                                             | Объяснение                |
| ----------------------------------------------------------------------- | ------------------------- |
| Требует `<numeric>`                                                     | Не путать с `<algorithm>` |
| Второй диапазон должен быть **достаточно длинным**                      | Иначе — UB                |
| Начальное значение (`init`) обязательно                                 | Даже если пусто           |
| Может принимать лямбды, функторы, `std::plus`, `std::multiplies` и т.д. | Очень гибко               |
| Не изменяет исходные данные                                             | Только читает             |

### Лучшая практика

| Совет                                                           | Почему                        |
| --------------------------------------------------------------- | ----------------------------- |
| Убедитесь, что второй диапазон не короче первого                | Иначе — UB                    |
| Используйте `std::inner_product` вместо ручного цикла           | Читаемее и безопаснее         |
| Используйте лямбды для сложных условий                          | Например, взвешенные суммы    |
| Комбинируйте с `std::distance`, чтобы получить индексы          | Полезно при анализе           |
| Избегайте `std::inner_product` в больших циклах без оптимизации | Это O(n), может быть медленно |
