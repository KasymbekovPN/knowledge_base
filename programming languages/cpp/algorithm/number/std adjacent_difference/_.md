Функция `std::adjacent_difference` из заголовочного файла `<numeric>` используется для **вычисления разности между соседними элементами** в диапазоне и записи результатов в выходной контейнер.

> ✅ Это полезно для:
> - Нахождения приращений (дельт),
> - Восстановления исходного массива по префиксным суммам,
> - Обработки временных рядов, сигналов, изменений.

### Синтаксис

```cpp
#include <numeric>

template<class InputIterator, class OutputIterator>
OutputIterator adjacent_difference(InputIterator first, InputIterator last,
                                   OutputIterator result);

template<class InputIterator, class OutputIterator, class BinaryOperation>
OutputIterator adjacent_difference(InputIterator first, InputIterator last,
                                   OutputIterator result, BinaryOperation op);
```

- Первый элемент результата = первый элемент входа,
- Каждый следующий: `result[i] = input[i] - input[i-1]` (или `op(input[i], input[i-1])`)
- Возвращает итератор на конец результирующего диапазона

### Важные моменты

| Особенность                                                        | Объяснение                                              |
| ------------------------------------------------------------------ | ------------------------------------------------------- |
| Требует `<numeric>`                                                | Не путать с `<algorithm>`                               |
| Первый элемент результата = первый элемент входа                   | Не вычисляется как разность                             |
| Может принимать лямбды, функторы, `std::minus`, `std::plus` и т.д. | Очень гибко                                             |
| Не изменяет исходный диапазон                                      | Только читает                                           |
| Работает с любыми типами, поддерживающими операцию                 | `int`, `double`, `std::string`, пользовательские классы |

### Лучшая практика

| Совет                                                                 | Почему                         |
| --------------------------------------------------------------------- | ------------------------------ |
| Используйте `std::adjacent_difference` вместо ручного цикла           | Читаемо и безопасно            |
| Используйте `std::back_inserter`, если размер неизвестен              | Удобно и безопасно             |
| Используйте лямбды для сложных операций                               | Например, процентное изменение |
| Комбинируйте с `std::partial_sum` для кодирования/декодирования       | Полезно в алгоритмах           |
| Избегайте `std::adjacent_difference` в больших циклах без оптимизации | Это O(n), может быть медленно  |
