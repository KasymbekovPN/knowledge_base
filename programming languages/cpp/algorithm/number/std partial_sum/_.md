Функция `std::partial_sum` из заголовочного файла `<numeric>` вычисляет **частичные суммы (префиксные суммы)** элементов диапазона и записывает результаты в выходной диапазон.

> ✅ Это мощный инструмент для:
> - Построения префиксных сумм,
> - Вычисления накопленных значений (сумма, произведение, конкатенация и т.д.),
> - Работы с массивами, векторами, строками и другими контейнерами.

### Синтаксис

```cpp
#include <numeric>

template<class InputIterator, class OutputIterator>
OutputIterator partial_sum(InputIterator first, InputIterator last,
                           OutputIterator result);

template<class InputIterator, class OutputIterator, class BinaryOperation>
OutputIterator partial_sum(InputIterator first, InputIterator last,
                           OutputIterator result, BinaryOperation op);
```

- Возвращает итератор на конец результирующего диапазона
- Каждый элемент результата — это "накопленная" сумма от начала до текущего элемента

### Важные моменты

| Особенность                                                             | Объяснение                             |
| ----------------------------------------------------------------------- | -------------------------------------- |
| Требует `<numeric>`                                                     | Не путать с `<algorithm>`              |
| Может принимать лямбды, функторы, `std::plus`, `std::multiplies` и т.д. | Очень гибко                            |
| Не изменяет исходный диапазон                                           | Только читает                          |
| Результат зависит от порядка                                            | Особенно при некоммутативных операциях |
| Первый элемент результата = первый элемент входа                        | Начальное значение не добавляется      |

### Лучшая практика

| Совет                                                         | Почему                        |
| ------------------------------------------------------------- | ----------------------------- |
| Используйте `std::partial_sum` вместо ручного цикла           | Читаемо и безопасно           |
| Используйте `std::back_inserter`, если размер неизвестен      | Удобно и безопасно            |
| Используйте лямбды для сложных операций                       | Например, взвешенные суммы    |
| Комбинируйте с `std::distance`, чтобы получить индексы        | Полезно при анализе           |
| Избегайте `std::partial_sum` в больших циклах без оптимизации | Это O(n), может быть медленно |
