Функция `std::shuffle` из заголовочного файла `<algorithm>` используется для **случайного перемешивания элементов в диапазоне**.

> ✅ Это современная, безопасная и эффективная замена устаревшего `std::random_shuffle` (удалён в C++17).

### Синтаксис

```cpp
#include <algorithm>
#include <random>

template<class RandomAccessIterator, class URBG>
void shuffle(RandomAccessIterator first, RandomAccessIterator last, URBG&& g);
```

- `first`, `last` — итераторы диапазона `[first, last)`
- `g` — **генератор случайных чисел** (Uniform Random Bit Generator, URBG)
- Перемешивает элементы **равномерно и без смещений**

### Важные моменты

| Особенность                                                               | Объяснение                                         |
| ------------------------------------------------------------------------- | -------------------------------------------------- |
| Требует **C++11+**                                                        | `std::random_shuffle` устарел                      |
| Работает только с **random-access итераторами**                           | Подходит для `std::vector`, `std::array`, массивов |
| Нужен **современный генератор** (`std::mt19937`, `std::ranlux24`, и т.д.) | Не используйте `rand()`                            |
| Алгоритм — **Fisher-Yates shuffle**                                       | Оптимальный, равномерный                           |
| Не используйте `std::random_device` напрямую как генератор                | Используйте его для затравки (`seed`)              |

### Лучшая практика

| Совет                                                         | Почему                       |
| ------------------------------------------------------------- | ---------------------------- |
| Всегда используйте `std::shuffle`, а не `std::random_shuffle` | Современный стандарт         |
| Используйте `std::mt19937` как генератор                      | Высокое качество случайности |
| Затравляйте генератор через `std::random_device`              | Хорошая энтропия             |
| Для тестов используйте фиксированное зерно                    | Воспроизводимость            |
| Избегайте `rand()` и `srand()`                                | Устарели, низкое качество    |
