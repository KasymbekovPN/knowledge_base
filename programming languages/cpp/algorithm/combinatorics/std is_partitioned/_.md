Функция `std::is_partitioned` из заголовочного файла `<algorithm>` используется для **проверки, разделён ли диапазон на две части по заданному условию (предикату)**:
- Все элементы, удовлетворяющие предикату, идут **в начале**,
- Все остальные — **в конце**.

> ✅ Это полезно при проверке результата `std::partition`, или если нужно убедиться, что данные "разделены".

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class UnaryPredicate>
bool is_partitioned(InputIterator first, InputIterator last, UnaryPredicate pred);
```

- Возвращает `true`, если диапазон разбит так, что:
  - Все элементы, для которых `pred(elem) == true`, находятся **до** тех, для которых `pred(elem) == false`
- Возвращает `false` — если порядок нарушен
- Работает за O(n)

### Важные моменты

| Особенность                               | Объяснение                     |
| ----------------------------------------- | ------------------------------ |
| Не изменяет данные                        | Только читает                  |
| Работает за O(n)                          | Проходит один раз              |
| Может принимать лямбды, функции, функторы | Для гибкого условия            |
| Пустой диапазон считается разделённым     | `is_partitioned(...)` → `true` |
| Первое нарушение завершает проверку       | Оптимизация                    |

### Лучшая практика

| Совет                                                                      | Почему                         |
| -------------------------------------------------------------------------- | ------------------------------ |
| Используйте `std::is_partitioned` для проверки результата `std::partition` | Надёжно и читаемо              |
| Проверяйте, что предикат согласован с порядком                             | Иначе результат будет `false`  |
| Используйте лямбды для краткости                                           | Особенно для временных условий |
| Избегайте `std::is_partitioned` в больших циклах без оптимизации           | Это O(n), может быть медленным |
| Комбинируйте с `std::distance` для анализа                                 | Полезно при отладке            |
