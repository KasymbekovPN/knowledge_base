Функция `std::stable_partition` из заголовочного файла `<algorithm>` используется для **разделения диапазона на две части по заданному условию (предикату)**, при этом **сохраняется относительный порядок элементов** внутри каждой из групп.

> ✅ Это "стабильная" версия `std::partition`.  
Подходит, когда важно не нарушать исходный порядок элементов, удовлетворяющих или не удовлетворяющих предикату.

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator, class UnaryPredicate>
BidirectionalIterator stable_partition(BidirectionalIterator first,
                                       BidirectionalIterator last,
                                       UnaryPredicate pred);

template<class ExecutionPolicy, class ForwardIterator, class UnaryPredicate>
ForwardIterator stable_partition(ExecutionPolicy&& exec,
                                 ForwardIterator first,
                                 ForwardIterator last,
                                 UnaryPredicate pred);
```

- Все элементы, для которых `pred(elem)` возвращает `true`, перемещаются в начало,
- Остальные — в конец,
- Относительный порядок **внутри каждой группы сохраняется**,
- Возвращает итератор на первый элемент, который **не удовлетворяет** `pred`.

### Важные моменты

| Особенность                                              | Объяснение                                            |
| -------------------------------------------------------- | ----------------------------------------------------- |
| Сохраняет порядок внутри групп                           | Главное отличие от `std::partition`                   |
| Работает за O(n log n) или O(n) с дополнительной памятью | Может использовать временный буфер                    |
| Требует bidirectional или forward итераторов             | Подходит для `std::vector`, `std::list`, `std::deque` |
| Изменяет исходный контейнер                              | Не создаёт копию                                      |
| Возвращает итератор на границу раздела                   | Полезно для дальнейшей обработки                      |

### Лучшая практика

| Совет                                                                    | Почему                                   |
| ------------------------------------------------------------------------ | ---------------------------------------- |
| Используйте `std::stable_partition`, если порядок важен                  | Например, при работе с событиями         |
| Используйте `std::partition`, если нужна максимальная производительность | Быстрее                                  |
| Используйте лямбду или функтор для условия                               | Особенно полезно с `std::partition_copy` |
| Комбинируйте с `std::distance` для получения количества элементов        | Полезно при анализе                      |
| Избегайте `std::stable_partition` в больших циклах без оптимизации       | Это O(n log n), может быть медленным     |
