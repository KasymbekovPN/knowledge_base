Функция `std::next_permutation` из заголовочного файла `<algorithm>` используется для **получения следующей лексикографически большей перестановки** элементов в диапазоне.

> ✅ Это мощный инструмент:
> - Для генерации всех перестановок,
> - Решения задач комбинаторики,
> - Поиска "следующего" слова в словаре и т.д.

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator>
bool next_permutation(BidirectionalIterator first, BidirectionalIterator last);

template<class BidirectionalIterator, class Compare>
bool next_permutation(BidirectionalIterator first, BidirectionalIterator last, Compare comp);
```

- Изменяет диапазон `[first, last)` на следующую перестановку
- Возвращает:
  - `true`, если следующая перестановка существует и была сгенерирована,
  - `false`, если текущая перестановка была последней (лексикографически наибольшей), и диапазон сброшен на первую (наименьшую)

### Важные моменты

| Особенность                                                           | Объяснение                               |
| --------------------------------------------------------------------- | ---------------------------------------- |
| Диапазон должен быть **отсортирован** для генерации всех перестановок | Лучше начать с `std::sort`               |
| Работает за O(n)                                                      | Очень эффективно                         |
| Не создает копию                                                      | Модифицирует "на месте"                  |
| Возвращает `false`, если перестановка была последней                  | И сбрасывает на первую                   |
| Подходит для любых типов с `operator<` или компаратором               | `int`, `string`, пользовательские классы |

### Лучшая практика

| Совет                                                               | Почему                             |
| ------------------------------------------------------------------- | ---------------------------------- |
| Сначала отсортируйте контейнер                                      | Чтобы начать с первой перестановки |
| Используйте `do-while`, если нужно включить исходную перестановку   | Как в примерах выше                |
| Проверяйте возвращаемое значение                                    | Чтобы понять, когда закончить      |
| Избегайте `std::next_permutation` на больших данных без оптимизации | Число перестановок растёт как `n!` |
| Комбинируйте с `std::string`, `std::vector`, `std::array`           | Универсально                       |
