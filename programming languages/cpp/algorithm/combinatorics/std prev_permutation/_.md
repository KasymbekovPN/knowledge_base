Функция `std::prev_permutation` из заголовочного файла `<algorithm>` используется для **получения предыдущей лексикографически меньшей перестановки** элементов в диапазоне.

> ✅ Это "обратная" версия `std::next_permutation`.  
Она позволяет генерировать все перестановки **в порядке убывания**, или найти "предыдущее" слово в словаре.

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator>
bool prev_permutation(BidirectionalIterator first, BidirectionalIterator last);

template<class BidirectionalIterator, class Compare>
bool prev_permutation(BidirectionalIterator first, BidirectionalIterator last, Compare comp);
```

- Изменяет диапазон `[first, last)` на **предыдущую** лексикографическую перестановку
- Возвращает:
  - `true`, если такая перестановка существует,
  - `false`, если текущая — самая маленькая (первая), и диапазон был сброшен на последнюю (наибольшую) перестановку

### Важные моменты

| Особенность                                                                                                      | Объяснение                               |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Диапазон должен быть **отсортирован в порядке убывания**, чтобы пройти все перестановки через `prev_permutation` | Иначе цикл закончится быстро             |
| Работает за O(n)                                                                                                 | Очень эффективно                         |
| Не создает копию                                                                                                 | Модифицирует "на месте"                  |
| Возвращает `false`, если перестановка была первой (наименьшей)                                                   | И сбрасывает на последнюю (наибольшую)   |
| Подходит для любых типов с `operator<` или компаратором                                                          | `int`, `string`, пользовательские классы |
### Лучшая практика

| Совет                                                                 | Почему                             |
| --------------------------------------------------------------------- | ---------------------------------- |
| Начинайте с **наибольшей перестановки** (отсортированной по убыванию) | Чтобы пройти все варианты          |
| Используйте `do-while`, если нужно включить исходную перестановку     | Как в примерах выше                |
| Проверяйте возвращаемое значение                                      | Чтобы понять, когда закончить      |
| Избегайте на больших данных без оптимизации                           | Число перестановок растёт как `n!` |
| Комбинируйте с `std::string`, `std::vector`, `std::array`             | Универсально                       |
