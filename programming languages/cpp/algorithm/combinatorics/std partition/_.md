Функция `std::partition` из заголовочного файла `<algorithm>` используется для **перемещения элементов диапазона так, чтобы все элементы, удовлетворяющие заданному условию (предикату), оказались в начале**, а остальные — в конце.

> ✅ Это мощный инструмент:
> - Для разделения данных (например: чётные/нечётные, положительные/отрицательные),
> - В алгоритмах сортировки (например, quicksort),
> - Без создания новых контейнеров.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class UnaryPredicate>
ForwardIterator partition(ForwardIterator first, ForwardIterator last,
                          UnaryPredicate pred);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `pred` — унарный предикат, возвращающий `bool`
- Возвращает: итератор на первый элемент, который **не удовлетворяет** `pred` (граница раздела)

### Важные моменты

| Особенность                               | Объяснение                                      |
| ----------------------------------------- | ----------------------------------------------- |
| Не сохраняет порядок внутри групп         | Используйте `std::stable_partition`, если нужно |
| Работает за O(n)                          | Проходит по каждому элементу один раз           |
| Может принимать лямбды, функции, функторы | Для гибкого условия                             |
| Изменяет исходный контейнер               | Не создаёт копию                                |
| Возвращает итератор на границу раздела    | Полезно для дальнейшей обработки                |

### Лучшая практика

| Совет                                                             | Почему                                                        |
| ----------------------------------------------------------------- | ------------------------------------------------------------- |
| Используйте `std::partition`, если порядок не важен               | Самый быстрый способ разделения                               |
| Используйте `std::stable_partition`, если нужно сохранить порядок | Например, при обработке событий по времени                    |
| Используйте лямбду или функтор для условия                        | Особенно полезно с `std::partition_copy`                      |
| Комбинируйте с `std::distance` для получения количества элементов | Полезно при анализе                                           |
| Избегайте `std::partition` в больших циклах без оптимизации       | Это O(n), может быть медленным при многократном использовании |
