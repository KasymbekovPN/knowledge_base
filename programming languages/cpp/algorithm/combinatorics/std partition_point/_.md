`std::partition_point`

### 📘 `std::partition_point` в C++

Функция `std::partition_point` из заголовочного файла `<algorithm>` используется для **поиска первой позиции в уже разделённом диапазоне, где условие (предикат) перестаёт выполняться**.

> ✅ Это полезно, когда:
> - Диапазон уже был отсортирован или разделён с помощью `std::partition` или `std::stable_partition`,
> - Нужно быстро найти границу между элементами, удовлетворяющими и не удовлетворяющими условию.

---

## 🔍 Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class UnaryPredicate>
ForwardIterator partition_point(ForwardIterator first, ForwardIterator last,
                                UnaryPredicate pred);
```

- Предполагается, что диапазон `[first, last)` **уже разделён** относительно `pred`:  
  все элементы, для которых `pred(elem) == true`, идут **до** тех, для которых `pred(elem) == false`.
- Возвращает итератор на **первый элемент, для которого `pred(elem) == false`**
- Работает за **O(log n)**, если итератор — случайный (random-access), иначе O(n)

---

## ✅ Пример 1: базовое использование

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    // Массив: сначала чётные, потом нечётные
    std::vector<int> v = {2, 4, 6, 8, 1, 3, 5, 7};

    // Ищем точку раздела: первый нечётный элемент
    auto it = std::partition_point(v.begin(), v.end(), [](int x) {
        return x % 2 == 0;
    });

    std::cout << "Partition point at index: " << std::distance(v.begin(), it) << "\n";
    if (it != v.end()) {
        std::cout << "First element not satisfying predicate: " << *it << "\n";
    }
}
```

### Вывод:
```
Partition point at index: 4
First element not satisfying predicate: 1
```

> ✅ Условие: `x % 2 == 0` → `true` для чётных.  
> `partition_point` возвращает итератор на первый элемент, где это `false`.

## ✅ Пример 2: проверка, что диапазон разделён

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

bool is_even(int x) { return x % 2 == 0; }

int main() {
    std::vector<int> v1 = {2, 4, 6, 1, 3}; // разделён
    std::vector<int> v2 = {2, 1, 4, 3, 6}; // не разделён

    auto it1 = std::partition_point(v1.begin(), v1.end(), is_even);
    auto it2 = std::partition_point(v2.begin(), v2.end(), is_even);

    std::cout << "v1 is partitioned: " << (it1 != v1.end() ? "yes" : "no") << "\n"; // yes
    std::cout << "v2 is partitioned: " << (it2 != v2.end() ? "yes" : "no") << "\n"; // technically returns iterator, but logic broken
}
```

> ⚠️ `std::partition_point` **не проверяет**, что диапазон действительно разделён — он просто предполагает это и ищет границу.

Для проверки используйте `std::is_partitioned`.

## ✅ Пример 3: работа с пользовательским типом

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

struct Person {
    std::string name;
    int age;
};

int main() {
    // Разделены по возрасту: сначала >=18, потом <18
    std::vector<Person> people = {
        {"Alice", 25},
        {"Bob", 30},
        {"Charlie", 17},
        {"Diana", 16}
    };

    auto adult_end = std::partition_point(people.begin(), people.end(), [](const Person& p) {
        return p.age >= 18;
    });

    std::cout << "Adults: ";
    for (auto it = people.begin(); it != adult_end; ++it)
        std::cout << it->name << " ";

    std::cout << "\nMinors: ";
    for (; adult_end != people.end(); ++adult_end)
        std::cout << adult_end->name << " ";
}
```

### Вывод:
```
Adults: Alice Bob 
Minors: Charlie Diana 
```

## ✅ Пример 4: поиск в отсортированном массиве (аналог lower_bound)

Если массив отсортирован, можно использовать `partition_point` как `lower_bound`:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> sorted = {1, 3, 5, 7, 9, 11};

    // Найти первую позицию, где значение >= 6
    auto it = std::partition_point(sorted.begin(), sorted.end(), [](int x) {
        return x < 6; // все элементы < 6 идут в начале
    });

    if (it != sorted.end()) {
        std::cout << "First element >= 6: " << *it << "\n"; // 7
    }
}
```

✅ Эквивалент `std::lower_bound(..., 6)`.

## ⚠️ Важные моменты

| Особенность | Объяснение |
|-------------|------------|
| Предполагает, что диапазон **уже разделён** | Иначе результат неопределён |
| Работает за O(log n) для random-access итераторов | Очень эффективно |
| Не изменяет данные | Только читает |
| Может принимать лямбды, функции, функторы | Для гибкого условия |
| Возвращает `last`, если все элементы удовлетворяют `pred` | Граница — в конце |

---

## 🛠 Как работает внутри?

Алгоритм бинарного поиска (для random-access итераторов):

```cpp
while (first != last) {
    auto mid = first + (std::distance(first, last) / 2);
    if (pred(*mid)) {
        first = mid + 1;
    } else {
        last = mid;
    }
}
return first;
```

## 📌 Когда использовать `std::partition_point`?

| Ситуация | Почему |
|----------|--------|
| Нужно найти границу после `std::partition` | Быстро и эффективно |
| Хотите реализовать `lower_bound`/`upper_bound` вручную | Через предикат |
| Работаете с уже разделёнными данными | Например, активные/неактивные |
| Нужна высокая производительность | O(log n) при случайных итераторах |
| Хотите чистый код без циклов | Без ручного бинарного поиска |

## 🧩 Альтернативы

| Функция | Что делает |
|--------|------------|
| `std::partition(...)` | Разделяет диапазон |
| `std::stable_partition(...)` | То же, но сохраняет порядок |
| `std::lower_bound(...)` | Находит первую позицию для значения |
| `std::partition_point(...)` | Самый эффективный способ найти границу в разделённом диапазоне |

---

## 📝 Сводка

| Метод | Что делает |
|-------|------------|
| `std::partition_point(b, e, pred)` | Находит первую позицию, где `pred(elem) == false` |
| `std::partition(b, e, pred)` | Делает разбиение |
| `std::is_partitioned(...)` | Проверяет, разделён ли диапазон |
| `std::lower_bound(...)` | Частный случай `partition_point` |

---

## ✅ Лучшая практика

| Совет | Почему |
|-------|--------|
| Убедитесь, что диапазон действительно разделён | Иначе результат будет некорректным |
| Используйте `std::partition_point` вместо линейного поиска | Гораздо быстрее |
| Комбинируйте с `std::distance`, чтобы получить индекс | Полезно при анализе |
| Избегайте `std::partition_point` на неотсортированных данных без разделения | Это нарушит логику |
