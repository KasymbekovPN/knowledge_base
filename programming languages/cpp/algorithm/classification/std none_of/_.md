Функция `std::none_of` из заголовочного файла `<algorithm>` используется для **проверки, что ни один элемент диапазона не удовлетворяет заданному условию (предикату)**.

> ✅ Это логическая функция: возвращает `true`, если **все элементы не проходят** предикат, иначе — `false`.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class UnaryPredicate>
bool none_of(InputIterator first, InputIterator last, UnaryPredicate pred);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `pred` — унарный предикат, возвращающий `bool`
- Возвращает `true`, если **ни один** элемент **не удовлетворяет** `pred`
- Для пустого диапазона возвращает `true` (по логике "ничто не нарушает условие")

### Важные моменты

| Особенность                                                     | Объяснение                                                |
| --------------------------------------------------------------- | --------------------------------------------------------- |
| Работает за O(n) в худшем случае, но может завершиться досрочно | Как только найдётся `true` — возвращает `false`           |
| Не изменяет данные                                              | Только читает                                             |
| Может принимать лямбды, функции, функторы                       | Для гибкого условия                                       |
| Возвращает `true` для пустого диапазона                         | Логически: "ни один элемент не нарушает условие" → `true` |

### Лучшая практика

| Совет                                                     | Почему                         |
| --------------------------------------------------------- | ------------------------------ |
| Используйте `std::none_of` вместо `!std::any_of(...)`     | Читаемее и яснее по смыслу     |
| Используйте лямбды для краткости                          | Особенно для временных условий |
| Комбинируйте с `std::distance`, чтобы получить индекс     | Полезно при анализе            |
| Избегайте `std::none_of` в больших циклах без оптимизации | Это O(n), может быть медленно  |
| Помните: пустой диапазон → `true`                         | Это важно для логики программы |
