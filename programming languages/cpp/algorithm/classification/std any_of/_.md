Функция `std::any_of` из заголовочного файла `<algorithm>` используется для **проверки, выполняется ли условие (предикат) хотя бы для одного элемента** в диапазоне.

> ✅ Это логическая функция: возвращает `true`, если **хотя бы один** элемент удовлетворяет условию, иначе — `false`.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class UnaryPredicate>
bool any_of(InputIterator first, InputIterator last, UnaryPredicate pred);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `pred` — унарный предикат, возвращающий `bool`
- Возвращает `true`, если `pred(elem)` вернёт `true` хотя бы для одного элемента

### Важные моменты

| Особенность                                                     | Объяснение                                      |
| --------------------------------------------------------------- | ----------------------------------------------- |
| Работает за O(n) в худшем случае, но может завершиться досрочно | Как только найдётся `true` — останавливается    |
| Не изменяет данные                                              | Только читает                                   |
| Может принимать лямбды, функции, функторы                       | Для гибкого условия                             |
| Возвращает `false` для пустого диапазона                        | Нет ни одного элемента → условие не выполняется |

### Лучшая практика

| Совет                                                    | Почему                                 |
| -------------------------------------------------------- | -------------------------------------- |
| Используйте `std::any_of` вместо цикла с `break`         | Читаемо и безопасно                    |
| Используйте лямбды для краткости                         | Особенно для временных условий         |
| Комбинируйте с `std::distance`, чтобы получить индекс    | Полезно при анализе                    |
| Избегайте `std::any_of` в больших циклах без оптимизации | Это O(n), может быть медленно          |
| Проверяйте пустые контейнеры, если это важно             | Хотя `any_of` и так корректно работает |
