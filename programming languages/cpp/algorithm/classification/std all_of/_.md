Функция `std::all_of` из заголовочного файла `<algorithm>` используется для **проверки, выполняется ли заданное условие (предикат) для всех элементов** в диапазоне.

> ✅ Это логическая функция: возвращает `true`, если **все элементы удовлетворяют предикату**, иначе — `false`.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator, class UnaryPredicate>
bool all_of(InputIterator first, InputIterator last, UnaryPredicate pred);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `pred` — унарный предикат, возвращающий `bool`
- Возвращает `true`, если **каждый элемент** в диапазоне даёт `true` при применении `pred`
- Для **пустого диапазона** возвращает `true` (по логике "нет ни одного, нарушающего условие")

### Важные моменты

| Особенность                                                     | Объяснение                                                |
| --------------------------------------------------------------- | --------------------------------------------------------- |
| Работает за O(n) в худшем случае, но может завершиться досрочно | Как только найдётся `false` — останавливается             |
| Не изменяет данные                                              | Только читает                                             |
| Может принимать лямбды, функции, функторы                       | Для гибкого условия                                       |
| Возвращает `true` для пустого диапазона                         | Логически: "все элементы (их нет) удовлетворяют" → `true` |

### Лучшая практика

| Совет                                                    | Почему                         |
| -------------------------------------------------------- | ------------------------------ |
| Используйте `std::all_of` вместо цикла с `break`         | Читаемо и безопасно            |
| Используйте лямбды для краткости                         | Особенно для временных условий |
| Комбинируйте с `std::distance`, чтобы получить индекс    | Полезно при анализе            |
| Избегайте `std::all_of` в больших циклах без оптимизации | Это O(n), может быть медленно  |
| Помните: пустой диапазон → `true`                        | Это важно для логики программы |

## ✅ Пример 1: все числа чётные?

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {2, 4, 6, 8};

    bool all_even = std::all_of(v.begin(), v.end(), [](int x) {
        return x % 2 == 0;
    });

    if (all_even)
        std::cout << "All numbers are even\n";
    else
        std::cout << "There is at least one odd number\n";
}
```

### Вывод:
```
All numbers are even
```

## ✅ Пример 2: все строки начинаются с заглавной буквы?

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cctype> // для std::isupper

int main() {
    std::vector<std::string> words = {"Hello", "World", "C++"};

    bool all_capitalized = std::all_of(words.begin(), words.end(), [](const std::string& s) {
        return !s.empty() && std::isupper(static_cast<unsigned char>(s[0]));
    });

    std::cout << "All capitalized: " << std::boolalpha << all_capitalized << "\n";
}
```

### Вывод:
```
All capitalized: true
```

## ✅ Пример 3: все студенты сдали экзамен?

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

struct Student {
    std::string name;
    int score;
};

int main() {
    std::vector<Student> students = {
        {"Alice", 75},
        {"Bob", 82},
        {"Charlie", 68}
    };

    // Все ли набрали больше 60 баллов?
    bool all_passed = std::all_of(students.begin(), students.end(), [](const Student& s) {
        return s.score >= 60;
    });

    if (all_passed)
        std::cout << "All students passed!\n";
    else
        std::cout << "Someone failed.\n";
}
```

### Вывод:
```
All students passed!
```

## ✅ Пример 4: строка состоит только из цифр?

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <cctype> // для std::isdigit

int main() {
    std::string input = "12345";

    bool all_digits = std::all_of(input.begin(), input.end(), [](char c) {
        return std::isdigit(static_cast<unsigned char>(c));
    });

    std::cout << "String is numeric: " << std::boolalpha << all_digits << "\n";
}
```

### Вывод:
```
String is numeric: true
```

```cpp
for (; first != last; ++first) {

        return false;

return true;
```

## 📌 Когда использовать `std::all_of`?

| Ситуация | Почему |
|----------|--------|
| Нужно проверить, что все элементы удовлетворяют условию | Например, все активны, все положительные |
| Хотите избежать цикла `for` с `break` | Более читаемо |
| Работаете с STL вместо ручных проверок | Безопаснее и понятнее |
| Нужно логическое условие в `if` | `if (std::all_of(...))` |
| Хотите комбинировать с другими алгоритмами | Например, `std::any_of`, `std::none_of` |

---

## 🧩 Альтернативы

| Функция | Что делает |
|--------|------------|
| `std::any_of(...)` | Проверяет, что **хотя бы один** элемент удовлетворяет условию |
| `std::none_of(...)` | Проверяет, что **ни один** не удовлетворяет |
| `std::find_if(...)` | Находит первый элемент, который **не** удовлетворяет (для инверсии) |
| `std::all_of(...)` | Самый прямой способ проверить "все" |

---

## 📝 Сводка

| Метод | Что делает |
|-------|------------|
| `std::all_of(b, e, pred)` | `true`, если все элементы удовлетворяют `pred` |
| `std::any_of(...)` | `true`, если хотя бы один удовлетворяет |
| `std::none_of(...)` | `true`, если ни один не удовлетворяет |
| `!std::any_of(...)` | То же, что и `std::none_of` |
