[[programming languages/cpp/algorithm/count/_|<=]]

В C++ **`std::count_if`** — это мощный алгоритм из библиотеки `<algorithm>`, который позволяет **подсчитывать элементы в диапазоне, удовлетворяющие заданному условию (предикату)**.

Он особенно полезен, когда вы хотите:
- Подсчитать количество элементов, соответствующих определённым критериям,
- Использовать лямбды или функторы для гибкой проверки,
- Работать с любыми контейнерами: `std::vector`, `std::list`, массивами и даже строками.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIt, class UnaryPredicate>
typename iterator_traits<InputIt>::difference_type count_if(
    InputIt first, InputIt last, UnaryPredicate p);
```

- `first`, `last` — итераторы, задающие диапазон `[first, last)`
- `p` — унарный предикат (функция/лямбда/функтор), принимающий один аргумент и возвращающий `bool`
- Возвращает: **количество элементов**, для которых `p(element) == true`

### Важные моменты

| Особенность                               | Объяснение                        |
| ----------------------------------------- | --------------------------------- |
| Работает за O(n)                          | Перебирает все элементы диапазона |
| Не изменяет данные                        | Только подсчёт                    |
| Может принимать лямбды, функции, функторы | Очень гибкий выбор условия        |
| Не требует отсортированности              | Работает с любым порядком         |
| Никогда не вызывает UB                    | Безопасно использовать            |

### Когда использовать `std::count_if`?

| Ситуация                                      | Почему                                    |
| --------------------------------------------- | ----------------------------------------- |
| Нужно подсчитать элементы по сложному условию | Например, длина строки > 5, возраст > 18  |
| Контейнер не отсортирован                     | `count_if` работает независимо от порядка |
| Хотите использовать лямбду или функтор        | Гибкая логика                             |
| Нужно проверить множество условий             | Легко модифицируется                      |
| Хотите сохранить чистый код                   | Без лишних циклов и `if`                  |

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

int main() {
    vector<string> data = {"Hello", "", "World", " ", "C++", ""};
    int count = count_if(data.begin(), data.end(), [](const string& s){
        return !s.empty();
    });
    cout << "Count: " << count << endl;

    return 0;
}
```

```
Count: 4
```
