[[programming languages/cpp/algorithm/count/_|<=]]

Функция `std::count` из заголовочного файла `<algorithm>` используется для **подсчёта количества элементов**, равных заданному значению, в указанном диапазоне.

Она особенно полезна при работе с контейнерами STL: `std::vector`, `std::list`, `std::string`, массивы и т.д.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIt, class T>
typename iterator_traits<InputIt>::difference_type count(
    InputIt first, InputIt last, const T& value);
```

- `first`, `last` — итераторы, определяющие диапазон `[first, last)`
- `value` — значение, которое нужно подсчитать
- Возвращает количество элементов, равных `value`

> ✅ Работает с любыми итерируемыми структурами


### Важные моменты

| Особенность                  | Объяснение                                         |
| ---------------------------- | -------------------------------------------------- |
| Сравнение через `==`         | Используется оператор `==` для проверки совпадения |
| Работает за O(n)             | Перебирает все элементы подряд                     |
| Не требует отсортированности | Подходит для любого порядка данных                 |
| Никогда не изменяет данные   | Только читает значения                             |
