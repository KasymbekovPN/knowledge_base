[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::set_difference` из заголовочного файла `<algorithm>` используется для **нахождения разности двух отсортированных диапазонов** — то есть, элементов, которые **присутствуют в первом диапазоне, но отсутствуют во втором**.

> ✅ Это аналог операции "A \ B" в теории множеств.  
Подходит для:
- Поиска уникальных элементов,
- Удаления элементов одного набора из другого,
- Работы с `std::vector`, `std::set`, массивами и другими контейнерами.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator1, class InputIterator2, class OutputIterator>
OutputIterator set_difference(InputIterator1 first1, InputIterator1 last1,
                              InputIterator2 first2, InputIterator2 last2,
                              OutputIterator result);

template<class InputIterator1, class InputIterator2, class OutputIterator, class Compare>
OutputIterator set_difference(InputIterator1 first1, InputIterator1 last1,
                              InputIterator2 first2, InputIterator2 last2,
                              OutputIterator result, Compare comp);
```

- Оба исходных диапазона **должны быть отсортированы**
- Результат также будет отсортирован
- Возвращает итератор на конец результирующего диапазона

### Важные моменты

| Особенность                                                                                                       | Объяснение                  |
| ----------------------------------------------------------------------------------------------------------------- | --------------------------- |
| Оба диапазона **должны быть отсортированы**                                                                       | Иначе результат неопределён |
| Работает за O(n + m)                                                                                              | Очень эффективно            |
| Учитывает дубликаты: если элемент встречается `k` раз в `a` и `m` раз в `b`, он будет включён `max(0, k - m)` раз | Как в мультимножествах      |
| Не изменяет исходные диапазоны                                                                                    | Только читает               |
| Может принимать лямбды, функции, функторы                                                                         | Для гибкого сравнения       |

### Лучшая практика

| Совет                                                        | Почему                                       |
| ------------------------------------------------------------ | -------------------------------------------- |
| Убедитесь, что оба диапазона отсортированы                   | Иначе результат будет некорректным           |
| Используйте `std::set_difference` вместо `std::find` в цикле | Гораздо быстрее                              |
| Проверяйте дубликаты: `{1,2,2,3} \ {2}` = `{1,2,3}`          | `set_difference` учитывает количество        |
| Комбинируйте с `std::sort`, если данные не отсортированы     | Для однократной проверки — может быть дороже |
| Избегайте `std::set_difference` на неотсортированных данных  | Это нарушит логику                           |
