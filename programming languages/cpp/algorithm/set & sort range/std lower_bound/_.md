[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::lower_bound` из заголовочного файла `<algorithm>` используется для **поиска первого элемента в отсортированном диапазоне, который не меньше заданного значения** (т.е. `>= value`).

> ✅ Это ключевой инструмент для:
> - Бинарного поиска,
> - Работы с отсортированными контейнерами (`std::vector`, `std::set`, `std::array`),
> - Эффективного поиска в O(log n).

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
ForwardIterator lower_bound(ForwardIterator first, ForwardIterator last,
                            const T& value);

template<class ForwardIterator, class T, class Compare>
ForwardIterator lower_bound(ForwardIterator first, ForwardIterator last,
                            const T& value, Compare comp);
```

- Диапазон `[first, last)` **должен быть отсортирован** (в порядке, соответствующем `comp`)
- Возвращает итератор на **первый элемент ≥ `value`**
- Если такого элемента нет — возвращает `last`

### Важные моменты

| Особенность                                            | Объяснение                          |
| ------------------------------------------------------ | ----------------------------------- |
| Диапазон **должен быть отсортирован**                  | Иначе результат неопределён         |
| Работает за O(log n)                                   | Бинарный поиск                      |
| Возвращает **первый** элемент, который `>= value`      | Если есть дубликаты — первый из них |
| Если `value` больше всех элементов — возвращает `last` | Проверяйте перед разыменованием     |
| Может принимать лямбды, функции, функторы              | Для гибкого сравнения               |

### Лучшая практика

| Совет                                                               | Почему                                |
| ------------------------------------------------------------------- | ------------------------------------- |
| Убедитесь, что диапазон отсортирован                                | Иначе результат будет некорректным    |
| Проверяйте `it != end()` перед разыменованием                       | Чтобы избежать UB                     |
| Используйте `std::lower_bound` для вставки в отсортированный вектор | `vec.insert(lower_bound(...), value)` |
| Комбинируйте с `std::distance`, чтобы получить индекс               | Полезно при анализе                   |
| Избегайте `std::lower_bound` на неотсортированных данных            | Это нарушит логику                    |
