[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::includes` из заголовочного файла `<algorithm>` используется для **проверки, является ли один отсортированный диапазон подмножеством другого**.

> ✅ Это не про строки или файлы — `std::includes` работает с **отсортированными контейнерами** и проверяет, **содержатся ли все элементы одного диапазона в другом**.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator1, class InputIterator2>
bool includes(InputIterator1 first1, InputIterator1 last1,
              InputIterator2 first2, InputIterator2 last2);

template<class InputIterator1, class InputIterator2, class Compare>
bool includes(InputIterator1 first1, InputIterator1 last1,
              InputIterator2 first2, InputIterator2 last2,
              Compare comp);
```

- Возвращает `true`, если **второй диапазон `[first2, last2)` полностью содержится в первом `[first1, last1)`**
- Оба диапазона **должны быть отсортированы** (и в том же порядке, что и компаратор)
- Работает за O(n + m)

### Важные моменты

| Особенность                                 | Объяснение                                                                 |
| ------------------------------------------- | -------------------------------------------------------------------------- |
| Оба диапазона **должны быть отсортированы** | Иначе результат неопределён                                                |
| Учитывает **дубликаты**                     | Если в подмножестве два `3`, то в основном должно быть как минимум два `3` |
| Работает за O(n + m)                        | Очень эффективно                                                           |
| Не изменяет данные                          | Только читает                                                              |
| Может принимать лямбды, функции, функторы   | Для гибкого сравнения                                                      |

### Лучшая практика

| Совет                                                    | Почему                                       |
| -------------------------------------------------------- | -------------------------------------------- |
| Убедитесь, что оба диапазона отсортированы               | Иначе результат будет некорректным           |
| Используйте `std::includes` вместо `std::find` в цикле   | Гораздо быстрее                              |
| Проверяйте дубликаты: `{1,2,2}` не входит в `{1,2}`      | `includes` учитывает количество              |
| Комбинируйте с `std::sort`, если данные не отсортированы | Для однократной проверки — может быть дороже |
| Избегайте `std::includes` на неотсортированных данных    | Это нарушит логику                           |
