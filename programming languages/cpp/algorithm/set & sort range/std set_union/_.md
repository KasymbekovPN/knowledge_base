[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::set_union` из заголовочного файла `<algorithm>` используется для **объединения двух отсортированных диапазонов в один отсортированный диапазон, удаляя дубликаты** — как в математическом объединении множеств.

> ✅ Это идеально подходит для:
> - Объединения двух отсортированных контейнеров,
> - Работы с `std::set`, `std::vector`, массивами,
> - Эффективного слияния данных без дубликатов.

### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator1, class InputIterator2, class OutputIterator>
OutputIterator set_union(InputIterator1 first1, InputIterator1 last1,
                         InputIterator2 first2, InputIterator2 last2,
                         OutputIterator result);

template<class InputIterator1, class InputIterator2, class OutputIterator, class Compare>
OutputIterator set_union(InputIterator1 first1, InputIterator1 last1,
                         InputIterator2 first2, InputIterator2 last2,
                         OutputIterator result, Compare comp);
```

- Оба исходных диапазона **должны быть отсортированы**
- Результат также будет отсортирован
- Дубликаты удаляются: если элемент есть в обоих диапазонах — он будет включён **один раз**
- Возвращает итератор на конец результирующего диапазона

### Важные моменты

| Особенность                                 | Объяснение                           |
| ------------------------------------------- | ------------------------------------ |
| Оба диапазона **должны быть отсортированы** | Иначе результат неопределён          |
| Работает за O(n + m)                        | Очень эффективно                     |
| Удаляет дубликаты                           | Каждый элемент в результате уникален |
| Не изменяет исходные диапазоны              | Только читает                        |
| Может принимать лямбды, функции, функторы   | Для гибкого сравнения                |

### Лучшая практика

| Совет                                                    | Почему                             |
| -------------------------------------------------------- | ---------------------------------- |
| Убедитесь, что оба диапазона отсортированы               | Иначе результат будет некорректным |
| Используйте `std::back_inserter`, если размер неизвестен | Чтобы избежать переполнения        |
| Используйте `std::greater` для объединения по убыванию   | Или свою лямбду                    |
| Комбинируйте с `std::distance` для получения размера     | Полезно при анализе                |
| Избегайте `std::set_union` на неотсортированных данных   | Это нарушит логику                 |
