Функция `std::binary_search` из заголовочного файла `<algorithm>` используется для **проверки, существует ли заданное значение в отсортированном диапазоне**.

> ✅ Это эффективный способ поиска за **O(log n)**, но **только для отсортированных контейнеров**.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
bool binary_search(ForwardIterator first, ForwardIterator last,
                   const T& value);

template<class ForwardIterator, class T, class Compare>
bool binary_search(ForwardIterator first, ForwardIterator last,
                   const T& value, Compare comp);
```

- Возвращает `true`, если значение найдено
- Возвращает `false`, если не найдено
- Диапазон `[first, last)` **должен быть отсортирован**

### Важные моменты

| Особенность                               | Объяснение                  |
| ----------------------------------------- | --------------------------- |
| Диапазон **должен быть отсортирован**     | Иначе результат неопределён |
| Работает за O(log n)                      | Очень эффективно            |
| Возвращает только `true`/`false`          | Не возвращает итератор      |
| Не изменяет данные                        | Только читает               |
| Может принимать лямбды, функции, функторы | Для гибкого сравнения       |

### Лучшая практика

| Совет                                                                        | Почему                             |
| ---------------------------------------------------------------------------- | ---------------------------------- |
| Убедитесь, что диапазон отсортирован                                         | Иначе результат будет некорректным |
| Используйте `std::binary_search` вместо `std::find` в отсортированных данных | Гораздо быстрее                    |
| Если нужен итератор — используйте `std::lower_bound`                         | `binary_search` не возвращает его  |
| Комбинируйте с `std::distance` для получения индексов                        | Полезно при анализе                |
| Избегайте `std::binary_search` на неотсортированных данных                   | Это нарушит логику                 |
