[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::set_symmetric_difference` из заголовочного файла `<algorithm>` используется для **нахождения симметрической разности двух отсортированных диапазонов** — то есть, элементов, которые **присутствуют только в одном из двух диапазонов** (но не в обоих).

> ✅ Это аналог операции "A XOR B" или `(A \ B) ∪ (B \ A)` в теории множеств.  
Подходит для:
- Поиска различий между двумя наборами данных,
- Сравнения списков, файлов, конфигураций,
- Работы с `std::vector`, `std::set`, массивами и другими контейнерами.
### Синтаксис

```cpp
#include <algorithm>

template<class InputIterator1, class InputIterator2, class OutputIterator>
OutputIterator set_symmetric_difference(InputIterator1 first1, InputIterator1 last1,
                                       InputIterator2 first2, InputIterator2 last2,
                                       OutputIterator result);

template<class InputIterator1, class InputIterator2, class OutputIterator, class Compare>
OutputIterator set_symmetric_difference(InputIterator1 first1, InputIterator1 last1,
                                       InputIterator2 first2, InputIterator2 last2,
                                       OutputIterator result, Compare comp);
```

- Оба исходных диапазона **должны быть отсортированы**
- Результат также будет отсортирован
- Возвращает итератор на конец результирующего диапазона

### Лучшая практика

| Совет | Почему |
|-------|--------|
| Убедитесь, что оба диапазона отсортированы | Иначе результат будет некорректным |
| Используйте `std::set_symmetric_difference` вместо `std::find` в цикле | Гораздо быстрее |
| Проверяйте дубликаты: `{1,2,2} XOR {2}` = `{1,2}` | Учитывает количество вхождений |
| Комбинируйте с `std::sort`, если данные не отсортированы | Для однократной проверки — может быть дороже |
| Избегайте `std::set_symmetric_difference` на неотсортированных данных | Это нарушит логику |
