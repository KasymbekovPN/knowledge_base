Функция `std::inplace_merge` из заголовочного файла `<algorithm>` используется для **слияния двух соседних отсортированных диапазонов в один отсортированный диапазон "на месте"** — то есть без выделения дополнительного контейнера.

> ✅ Это ключевой шаг в **алгоритме сортировки слиянием (merge sort)**, когда нужно объединить уже отсортированные части массива.

### Синтаксис

```cpp
#include <algorithm>

template<class BidirectionalIterator>
void inplace_merge(BidirectionalIterator first,
                   BidirectionalIterator middle,
                   BidirectionalIterator last);

template<class BidirectionalIterator, class Compare>
void inplace_merge(BidirectionalIterator first,
                   BidirectionalIterator middle,
                   BidirectionalIterator last,
                   Compare comp);
```

- `[first, middle)` — первый отсортированный диапазон
- `[middle, last)` — второй отсортированный диапазон
- После вызова весь диапазон `[first, last)` будет отсортирован
- Работает "на месте" — не требует дополнительного контейнера (хотя может использовать временный буфер)

### Важные моменты

| Особенность                                                            | Объяснение                                            |
| ---------------------------------------------------------------------- | ----------------------------------------------------- |
| Оба диапазона **должны быть отсортированы**                            | Иначе результат не будет корректным                   |
| Работает за O(n log n) при нехватке памяти, O(n) — с временным буфером | STL старается оптимизировать                          |
| Требует **bidirectional итераторов**                                   | Подходит для `std::vector`, `std::deque`, `std::list` |
| Не изменяет размер контейнера                                          | Только переставляет элементы                          |
| Может использовать временный буфер                                     | Для повышения производительности                      |

### Лучшая практика

| Совет                                                      | Почему                             |
| ---------------------------------------------------------- | ---------------------------------- |
| Убедитесь, что оба диапазона отсортированы                 | Иначе результат будет некорректным |
| Используйте `std::inplace_merge` в реализации merge sort   | Это естественное применение        |
| Проверяйте, что `middle` находится между `first` и `last`  | Иначе — UB                         |
| Комбинируйте с `std::distance` для получения индексов      | Полезно при анализе                |
| Избегайте `std::inplace_merge` на неотсортированных данных | Это нарушит логику                 |
