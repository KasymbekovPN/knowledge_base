[[programming languages/cpp/algorithm/set & sort range/_|<=]]

Функция `std::equal_range` из заголовочного файла `<algorithm>` используется для **поиска диапазона всех элементов, равных заданному значению** в отсортированном контейнере.

> ✅ Это эквивалент комбинации `std::lower_bound` и `std::upper_bound`, но **выполняется за один проход** — более эффективно при работе с большими данными.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
std::pair<ForwardIterator, ForwardIterator>
equal_range(ForwardIterator first, ForwardIterator last, const T& value);

template<class ForwardIterator, class T, class Compare>
std::pair<ForwardIterator, ForwardIterator>
equal_range(ForwardIterator first, ForwardIterator last, const T& value, Compare comp);
```

- Возвращает `std::pair`:
  - `.first` — итератор на **первый элемент ≥ `value`** (как `lower_bound`)
  - `.second` — итератор на **первый элемент > `value`** (как `upper_bound`)
- Диапазон `[first, second)` содержит **все элементы, равные `value`**
- Работает за O(log n)

### Важные моменты

| Особенность                                  | Объяснение                              |
| -------------------------------------------- | --------------------------------------- |
| Диапазон **должен быть отсортирован**        | Иначе результат неопределён             |
| Работает за O(log n)                         | Бинарный поиск                          |
| Возвращает `std::pair<It, It>`               | Диапазон всех элементов, равных `value` |
| Если элемент отсутствует — `first == second` | Проверяйте перед использованием         |
| Может принимать лямбды, функции, функторы    | Для гибкого сравнения                   |

### Лучшая практика

| Совет                                                              | Почему                             |
| ------------------------------------------------------------------ | ---------------------------------- |
| Убедитесь, что диапазон отсортирован                               | Иначе результат будет некорректным |
| Проверяйте `first != second` перед использованием                  | Чтобы избежать пустого диапазона   |
| Используйте `std::distance(first, second)` для подсчёта количества | Полезно при статистике             |
| Комбинируйте с `structured binding` (C++17)                        | Чистый и понятный код              |
| Избегайте `std::equal_range` на неотсортированных данных           | Это нарушит логику                 |
