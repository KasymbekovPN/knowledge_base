Функция `std::fill` из заголовочного файла `<algorithm>` используется для **заполнения диапазона одним и тем же значением**.

> ✅ Это простой, но мощный инструмент:
> - Для инициализации контейнеров,
> - Сброса значений,
> - Замены циклов `for`.

---

## 🔍 Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class T>
void fill(ForwardIterator first, ForwardIterator last, const T& value);
```

- `[first, last)` — диапазон для заполнения
- `value` — значение, которым нужно заполнить
- Ничего не возвращает (изменяет "на месте")

### Важные моменты

| Особенность                                                | Объяснение                                              |
| ---------------------------------------------------------- | ------------------------------------------------------- |
| Не изменяет размер контейнера                              | Только заполняет существующие элементы                  |
| Работает за O(n)                                           | Очень эффективно                                        |
| Может заполнять любые типы                                 | `int`, `double`, `std::string`, пользовательские классы |
| Подходит для любых ForwardIterator-совместимых контейнеров | `vector`, `array`, `list`, массивы                      |
| Использует копирование                                     | Убедитесь, что `T` имеет конструктор копирования        |

### Лучшая практика

| Совет                                                      | Почему                        |
| ---------------------------------------------------------- | ----------------------------- |
| Используйте `std::fill` вместо цикла `for` с присваиванием | Читаемо и безопасно           |
| Убедитесь, что контейнер достаточно большой                | `fill` не увеличивает размер  |
| Комбинируйте с `std::distance`, чтобы получить количество  | Полезно при анализе           |
| Избегайте `std::fill` в больших циклах без оптимизации     | Это O(n), может быть медленно |
| Используйте `std::fill` с `std::array` и `std::vector`     | Универсально                  |
