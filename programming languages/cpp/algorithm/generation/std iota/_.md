Функция `std::iota` из заголовочного файла `<numeric>` используется для **заполнения диапазона последовательными значениями**, начиная с заданного числа.

> ✅ Название происходит от математики (iota — функция, возвращающая последовательность), а в программировании означает:  
> "заполни 1, 2, 3, 4, ..."

### Синтаксис

```cpp
#include <numeric>

template<class ForwardIterator, class T>
void iota(ForwardIterator first, ForwardIterator last, T value);
```

- `[first, last)` — диапазон для заполнения
- `value` — начальное значение
- Каждый следующий элемент увеличивается на `1` (с помощью `++`)
- Подходит для любых типов, поддерживающих `operator++` и копирование

### Важные моменты

| Особенность                                                    | Объяснение                             |
| -------------------------------------------------------------- | -------------------------------------- |
| Требует `<numeric>`                                            | Не путать с `<algorithm>`              |
| Работает за O(n)                                               | Очень эффективно                       |
| Увеличивает значение через `++`                                | Должен быть определён `operator++`     |
| Не изменяет размер контейнера                                  | Только заполняет существующие элементы |
| Подходит для `int`, `double`, `enum`, пользовательских классов | Если реализован `++`                   |

### Лучшая практика

| Совет                                                     | Почему                        |
| --------------------------------------------------------- | ----------------------------- |
| Используйте `std::iota` вместо цикла `for (int i=0; ...)` | Читаемо и безопасно           |
| Убедитесь, что контейнер достаточно большой               | `iota` не увеличивает размер  |
| Комбинируйте с `std::sort` и `std::stable_sort`           | Для индексной сортировки      |
| Избегайте `std::iota` в больших циклах без оптимизации    | Это O(n), может быть медленно |
| Используйте с `std::vector<size_t>` для индексов          | Безопаснее, чем `int`         |
