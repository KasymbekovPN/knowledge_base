[[programming languages/cpp/algorithm/generation/_|<=]]

Функция `std::generate_n` из заголовочного файла `<algorithm>` используется для **генерации `n` значений с помощью функции (или лямбды) и записи их в диапазон, начиная с заданного итератора**.

> ✅ Это "ограниченная" версия `std::generate`, где вы указываете **не диапазон**, а **количество элементов**.

### Синтаксис

```cpp
#include <algorithm>

template<class OutputIterator, class Size, class Generator>
OutputIterator generate_n(OutputIterator first, Size count, Generator gen);
```

- `first` — итератор, с которого начинается запись
- `count` — количество элементов для генерации
- `gen` — функция без параметров, возвращающая значение
- Возвращает: `first + count`
- Подходит для итераторов вывода (`OutputIterator`) — например, `std::back_inserter`

### Важные моменты

| Особенность                               | Объяснение                                   |
| ----------------------------------------- | -------------------------------------------- |
| Не изменяет размер контейнера напрямую    | Но `std::back_inserter` делает `push_back()` |
| Может принимать лямбды, функции, функторы | Очень гибко                                  |
| Генератор вызывается ровно `count` раз    | Без пропусков                                |
| Подходит для любых `OutputIterator`       | Включая `std::ostream_iterator`              |

### Лучшая практика

| Совет                                                             | Почему                        |
| ----------------------------------------------------------------- | ----------------------------- |
| Используйте `std::generate_n` с `std::back_inserter` для векторов | Удобно и безопасно            |
| Убедитесь, что генератор корректно захватывает переменные         | Особенно `[&]`                |
| Используйте функторы для сложных последовательностей              | Например, Фибоначчи           |
| Комбинируйте с `reserve()` при использовании `back_inserter`      | Эффективнее                   |
| Избегайте `std::generate_n` в больших циклах без оптимизации      | Это O(n), может быть медленно |
