[[programming languages/cpp/algorithm/generation/_|<=]]

Функция `std::generate` из заголовочного файла `<algorithm>` используется для **заполнения диапазона значениями, генерируемыми функцией (или лямбдой)**.

> ✅ Это мощный инструмент:
> - Для инициализации контейнеров,
> - Генерации последовательностей (случайных чисел, фибоначчи, счётчиков),
> - Замены циклов `for`.

### Синтаксис

```cpp
#include <algorithm>

template<class ForwardIterator, class Generator>
void generate(ForwardIterator first, ForwardIterator last, Generator gen);
```

- `[first, last)` — диапазон для заполнения
- `gen` — функция без параметров, возвращающая значение
- Вызывается `last - first` раз
- Ничего не возвращает (заполняет "на месте")

### Важные моменты

| Особенность                                                | Объяснение                             |
| ---------------------------------------------------------- | -------------------------------------- |
| Не изменяет размер контейнера                              | Только заполняет существующие элементы |
| Может принимать лямбды, функции, функторы                  | Очень гибко                            |
| Не возвращает значение                                     | Всё происходит "на месте"              |
| Генератор вызывается ровно `last - first` раз              | Без пропусков                          |
| Подходит для любых ForwardIterator-совместимых контейнеров | `vector`, `array`, `list`, массивы     |

### Лучшая практика

| Совет                                                      | Почему                                       |
| ---------------------------------------------------------- | -------------------------------------------- |
| Используйте `std::generate` вместо цикла `for` с индексом  | Читаемо и безопасно                          |
| Используйте лямбды с захватом для состояния                | Например, счётчик, RNG                       |
| Убедитесь, что контейнер достаточно большой                | `generate` не увеличивает размер             |
| Комбинируйте с `std::back_inserter`? ❌ Нельзя!             | Он не поддерживает присваивание по итератору |
| Избегайте `std::generate` в больших циклах без оптимизации | Это O(n), может быть медленно                |
