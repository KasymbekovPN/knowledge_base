
C++11 — первый по-настоящему крупный апдейт после C++98/03. Добавил auto, lambda-выражения, move-семантику и rvalue-ссылки, smart pointers (unique_ptr, shared_ptr), range-based for, nullptr, constexpr, variadic templates, std::thread и вообще многопоточность в стандарте, а также static_assert и unordered_map/set.

C++14 — небольшое дополнение к C++11. Главное: generic lambda (auto в параметрах лямбд), возврат типа auto из обычных функций, relaxed constexpr (можно писать циклы и условия), std::make_unique, разделители в числовых литералах (1'000'000).

C++17 — заметный шаг вперёд. structured bindings (auto [a, b] = pair), if/switch с инициализатором, std::optional, std::variant, std::any, std::filesystem, parallel-алгоритмы STL, inline-переменные, fold-выражения для variadic templates, class template argument deduction (не нужно писать `vector<int>` явно).

C++20 — один из крупнейших релизов. Concepts (ограничения на шаблонные параметры), coroutines, ranges (диапазоны и ленивые view вместо begin/end), modules (замена `#include`), std::span, three-way comparison (оператор <=>), consteval/constinit, std::format (позже доработан).

C++23 — более умеренное обновление. std::expected для обработки ошибок, deducing this, multidimensional subscript operator (mdspan), расширения ranges, import std (модульный импорт стандартной библиотеки), std::print/println.

C++26 (в разработке) — ожидаются reflection, contracts, дальнейшее расширение constexpr и SIMD-поддержка (std::simd), но стандарт ещё не финализирован.

**Инициализация и auto**

```cpp
// C++03
std::vector<int> v;
for (std::vector<int>::iterator it = v.begin(); it != v.end(); ++it) { }

// C++11: auto + range-based for + uniform init
std::vector<int> v{1, 2, 3};
for (auto x : v) { }

// C++17: structured bindings
std::map<std::string, int> m;
for (auto& [key, value] : m) { }
```

**Лямбды**

```cpp
// C++11: обычная лямбда, тип параметра фиксирован
auto add = [](int a, int b) { return a + b; };

// C++14: generic lambda
auto add = [](auto a, auto b) { return a + b; };

// C++20: явные шаблонные параметры в лямбде
auto add = []<typename T>(T a, T b) { return a + b; };
```

**Умные указатели**

```cpp
// C++11: unique_ptr есть, но создание не exception-safe
std::unique_ptr<Foo> p(new Foo());

// C++14: make_unique (make_shared был уже в C++11)
auto p = std::make_unique<Foo>();
```

**constexpr**

```cpp
// C++11: только одно return-выражение
constexpr int square(int x) { return x * x; }

// C++14: полноценные циклы, локальные переменные, ветвления
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) result *= i;
    return result;
}
```

**Обработка ошибок/опциональных значений**

```cpp
// До C++17: либо exceptions, либо pair<bool, T>, либо указатель

// C++17: optional / variant
std::optional<int> parse(const std::string& s);
std::variant<int, std::string> v = 42;

// C++23: expected — значение или ошибка без исключений
std::expected<int, std::string> parse(const std::string& s) {
    if (s.empty()) return std::unexpected("empty string");
    return std::stoi(s);
}
```

**Шаблоны и concepts**

```cpp
// C++11-17: SFINAE, читается тяжело
template <typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
T add(T a, T b) { return a + b; }

// C++20: concepts
template <std::integral T>
T add(T a, T b) { return a + b; }
```

**Диапазоны**

```cpp
// До C++20: цепочка алгоритмов STL с временными контейнерами
std::vector<int> v{1,2,3,4,5};
std::vector<int> tmp;
std::copy_if(v.begin(), v.end(), std::back_inserter(tmp), [](int x){ return x % 2 == 0; });

// C++20: ranges, ленивые views, без промежуточных контейнеров
for (int x : v | std::views::filter([](int x){ return x % 2 == 0; })
              | std::views::transform([](int x){ return x * x; })) { }
```

**Многопоточность → корутины**

```cpp
// C++11: потоки
std::thread t([]{ /* работа */ });
t.join();

// C++20: coroutines — приостанавливаемая функция
Generator<int> counter() {
    for (int i = 0;; ++i) co_yield i;
}
```
