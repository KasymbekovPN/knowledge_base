В C++ **функциональный объект (functor)** — это объект, который может быть вызван как обычная функция. Это достигается с помощью перегрузки оператора `operator()`.

__Функциональные объекты__ — мощный инструмент, который позволяет:
- Хранить состояние,
- Передавать логику в алгоритмы STL,
- Создавать "замыкания" до появления лямбд.

**Функтор — это полноценный класс** , и может содержать **сколько угодно других методов** .

| Преимущество | Объяснение |
|-------------|------------|
| **Состояние** | Может хранить данные между вызовами |
| **Гибкость** | Можно передавать в STL-алгоритмы |
| **Производительность** | Часто оптимизируются лучше указателей на функции |
| **Полиморфизм поведения** | Позволяет создавать разные "функции" из одного типа |

### Сравнение: функтор vs указатель на функцию

| Особенность        | Функтор (`operator()`)                | Указатель на функцию     |
| ------------------ | ------------------------------------- | ------------------------ |
| Хранение состояния | ✅ Да                                  | ❌ Нет                    |
| Производительность | ✅ Инлайнится компилятором             | ❌ Вызов через указатель  |
| Перегрузка         | ✅ Да (можно перегрузить `operator()`) | ❌ Нет                    |
| Гибкость           | ✅ Много методов/состояний             | ❌ Только одна реализация |

### Функторы vs Лямбды

| Особенность        | Функтор                     | Лямбда                      |
| ------------------ | --------------------------- | --------------------------- |
| Состояние          | ✅ Да                        | ✅ Да (в C++11+)             |
| Контекст           | Явно заданный               | Автоматически захватывается |
| Читаемость         | ❗ Требует класса            | ✅ Короткая запись           |
| Производительность | ✅ Оптимизируется            | ✅ Оптимизируется            |
| Гибкость           | ✅ Перегрузка, много методов | ❌ Одиночный `operator()`    |

### Когда использовать функторы?

| Ситуация                                        | Рекомендация         |
| ----------------------------------------------- | -------------------- |
| Нужно хранить состояние между вызовами          | ✅ Функтор            |
| Нужна сложная логика                            | ✅ Функтор            |
| Нужно переопределить `operator()` несколько раз | ✅ Функтор            |
| Простая логика, кратко                          | ✅ Лямбда             |
| Совместимость со старым кодом                   | ✅ Функтор (до C++11) |
