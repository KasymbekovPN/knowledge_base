[[_cpp|<=]]

**Лямбда-выражение** — это удобный способ создания анонимных функций прямо в коде. Они особенно полезны при работе с STL-алгоритмами, callback и многопоточностью.

### Общая структура лямбды

```cpp
[capture](parameters) -> return_type {
    // body
}
```

- __capture__ - список захвата - какие переменные доступны внутри лямбды
- __parameters__ - параметры функции
- __return_type__ - тип возвращаемого значения, необязательный

### Когда использовать лямбды?

- При передаче в алгоритмы STL: `std::for_each`, `std::transform`, `std::sort` и др.
- Для краткой реализации callback-функций.
- Для замыканий с состоянием.
- При использовании с `std::function` и `std::bind`.

### Особенности и подводные камни

| Особенность                                                                                                            | Объяснение                                   |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **Тип лямбды уникален**                                                                                                | Даже две одинаковые лямбды имеют разные типы |
| **Нельзя присвоить лямбду другому типу напрямую**                                                                      | Используйте `std::function` для хранения     |
| **Можно захватывать `this`**                                                                                           | Полезно в методах класса                     |
| **Не используйте `return` без указания `-> return_type`**, если компилятор не может вывести тип возвращаемого значения |                                              |

### Сравнение: функтор vs лямбда

| Возможность             | Функтор               | Лямбда            |
| ----------------------- | --------------------- | ----------------- |
| Количество `operator()` | ✅ Много перегрузок    | ❌ Только один     |
| Хранение состояния      | ✅ Да                  | ✅ Да              |
| Читаемость              | ❌ Нужно писать класс  | ✅ Более компактно |
| Гибкость                | ✅ Больше возможностей | ❌ Одна операция   |
| Совместимость с STL     | ✅ Да                  | ✅ Да              |

### Лучшая практика

| Рекомендация                                                      | Почему                                    |
| ----------------------------------------------------------------- | ----------------------------------------- |
| Используйте `[]` для простых действий                             | Например, в `std::sort`, `std::transform` |
| Используйте `std::function` для хранения                          | Чтобы передавать лямбды между функциями   |
| Избегайте захвата больших объектов по ссылке                      | Может вызвать dangling reference          |
| Используйте `mutable`, если нужно изменять захваченные переменные | Иначе они константны                      |
| Используйте `-> decltype(auto)` для сложных возвращаемых типов    | Для универсальных лямбд                   |
