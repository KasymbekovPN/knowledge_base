[[programming languages/cpp/move semantic/_|<=]]

**Оператор присваивания с перемещением** — это специальный метод класса, появившийся в **C++11**, который позволяет **эффективно "забирать" ресурсы у временного объекта**, вместо их копирования. Это часть **move семантики**, которая делает код более производительным.

```cpp
class CustomContainer {
private:
    int* data;
    size_t size;

public:
	// ...

    CustomContainer& operator=(CustomContainer&& other) noexcept {
        cout << "mv operator=" << endl;
        if (this != &other) {
            delete[] data;
            data = other.data;
            size = other.size;
            other.data = nullptr;
        }
        return *this;
    }

	// ...
}
```

- Принимает rvalue reference (`T&&`),
- Проверяет на самоприсваивание `if (this != &other)`,
- Должен быть помечен как `noexcept`, если вы хотите, чтобы STL его активно использовал.
### Важные моменты

| Момент                                              | Объяснение                                                        |
| --------------------------------------------------- | ----------------------------------------------------------------- |
| После перемещения исходный объект остаётся валидным | Но его состояние не определено (например, `other.data = nullptr`) |
| Необходимость `noexcept`                            | STL использует `noexcept` для выбора между copy и move            |
| Рекомендуется проверка `this != &other`             | Чтобы избежать самоприсваивания                                   |

### Когда вызывается move assignment?

| Ситуация | Вызывается ли move? |
|----------|---------------------|
| `MyClass a, b; b = MyClass();` | ✅ Да |
| `MyClass a, b; b = std::move(a);` | ✅ Да |
| Передача временного объекта в функцию: `void foo(MyClass obj)` | ✅ При присваивании внутри функции |
| Возврат из функции | ✅ Может быть применён при копировании в принимающий объект |

### Как правильно написать move assignment

- Удаляем старые данные,
- Забираем новые,
- Обнуляем исходный объект,
- Возвращаем `*this`.

### Move vs Copy assignment

| Тип оператора | Что происходит |
|----------------|----------------|
| Copy assignment | Копирует все данные |
| Move assignment | "Забирает" ресурсы у временного объекта |
| Move быстрее copy? | Да, если есть ресурс (например, динамическая память) |

### Когда компилятор создаёт move assignment автоматически?

Если ваш класс:
- Не имеет пользовательского деструктора,
- Не имеет пользовательского copy конструктора или оператора присваивания,

то компилятор **автоматически сгенерирует move assignment**.

### Когда move assignment отключён?

- Если вы объявили свой copy конструктор или оператор присваивания,
- Если вы объявили свой деструктор,
- Если вы явно удалили move assignment: `MyClass& operator=(MyClass&&) = delete;`
