[[programming languages/cpp/move semantic/_|<=]]

**Rvalue-ссылка в C++** — это мощный механизм, введённый в **C++11**, который позволяет

- писать эффективный код за счёт **перемещения ресурсов** вместо копирования,
- реализовывать **move семантику** и **perfect forwarding**.

Это ссылка на временный объект (_rvalue_), обозначается как `T&&`.

```cpp
int&& rref = 5; // rref — rvalue reference на временный объект 5
```

> ❗ Важно: `T&&` не всегда означает "ссылка на временное значение". Это зависит от контекста.

Когда вы используете **rvalue-ссылку как параметр функции**, это позволяет вашей функции принимать **временные объекты (rvalues)** и, при необходимости, **перемещать** их внутрь, вместо того чтобы копировать.

### Как правильно использовать rvalue-ссылки как параметры

#### ✔️ Используйте, когда:
- Вы хотите принять **временный объект**,
- Хотите избежать копирования,
- У вас есть move-конструкторы/операторы,
- Вы пишете функцию, которая **берёт владение объектом**.

#### ❌ Не используйте, если:
- Функция должна работать и с временными, и с именованными объектами одинаково,
- Объект может быть использован повторно,
- Нет move-семантики для типа.


```cpp
#include <iostream>

void _print(int&& value) {
    std::cout << "rvalue: " << value << std::endl;
}

void _print(int& value) {
    std::cout << "lvalue: " << value << std::endl;
}

int main() {
    int a {42};
    _print(a);
    _print(12);
    _print(std::move(a));

    return 0;
}
```

```
lvalue: 42
rvalue: 12
rvalue: 42
```

### Когда использовать rvalue-ссылки?

| Ситуация                                             | Рекомендация                                               |
| ---------------------------------------------------- | ---------------------------------------------------------- |
| Нужно переместить ресурсы из одного объекта в другой | Используйте `std::move` и move конструкторы                |
| Пишете шаблонную функцию                             | Используйте `std::forward<T>()`                            |
| Хотите повысить производительность STL контейнеров   | Используйте `emplace_back`, а не `push_back(std::move(x))` |
| Реализуете свой класс с ресурсами                    | Реализуйте move-семантику                                  |
