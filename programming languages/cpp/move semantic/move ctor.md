[[programming languages/cpp/move semantic/_|<=]]

**Конструктор перемещения** — это специальный конструктор, появившийся в **C++11**, который позволяет **"забрать" ресурсы у временного объекта**, вместо их копирования. Это основа **move семантики**, которая значительно повышает производительность программ.

```cpp
class CustomContainerM {

private:
    size_t size;
    int* data;

public:
	
	// ...
	
    CustomContainerM(CustomContainerM&& other) noexcept:
        size(other.size) {
        data = other.data;
        other.data = nullptr;
	}

    // ...
}
```

- Принимает **rvalue reference** (`T&&`) как параметр.
- Должен быть помечен как `noexcept`, если вы хотите, чтобы STL и другие библиотеки могли его использовать эффективно.

### Когда вызывается move конструктор?

| Ситуация                                                       | Вызывается ли move? |
| -------------------------------------------------------------- | ------------------- |
| `MyClass a = MyClass();`                                       | ✅ Да (или RVO)      |
| `MyClass a = std::move(b);`                                    | ✅ Да                |
| Передача временного объекта в функцию: `void foo(MyClass obj)` | ✅ Да                |
| Возврат из функции                                             | ✅ Да (или RVO)      |

### Move vs Copy

| Операция           | Что происходит                                       |
| ------------------ | ---------------------------------------------------- |
| Copy конструктор   | Копирует все данные                                  |
| Move конструктор   | "Забирает" ресурсы у временного объекта              |
| Move быстрее copy? | Да, если есть ресурс (например, динамическая память) |

###  Когда компилятор создаёт move автоматически?

Если класс:
- Не имеет пользовательского деструктора,
- Не имеет пользовательского copy конструктора/оператора,

то компилятор **автоматически сгенерирует move конструктор**.

```cpp
struct Point {
    int x, y;
}; // move конструктор будет сгенерирован
```

### Когда move конструктор отключён?

- Если вы объявили свой copy конструктор или оператор присваивания,
- Если вы объявили свой деструктор,
- Если вы явно удалили move конструктор: `MyClass(MyClass&&) = delete;`
