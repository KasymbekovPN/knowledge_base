[[programming languages/cpp/move semantic/_|<=]]

Функция `std::move` — это один из ключевых элементов **move семантики** в C++, появившийся в **C++11**.

> ❗ `std::move` **ничего не перемещает**.  
Она просто **приводит объект к rvalue reference (`T&&`)**, чтобы вызвать **move-конструктор** или **move-оператор присваивания**, если они определены.

Это позволяет "забрать" ресурсы у объекта, вместо того чтобы их копировать.


```cpp
template <typename T>
std::remove_reference_t<T>&& move(T&& t) noexcept;
```

Функция `std::move()`:
1. Убирает ссылку из типа `T` (`std::remove_reference<T>::type`),
2. Преобразует объект в _rvalue reference_ (`T&&`),
3. Возвращает его как _rvalue_.

```cpp
#include <iostream>
#include <utility>

using std::cout;
using std::endl;

int main() {
    std::string str {"Hello"};
    std::string mstr = std::move(str);

    // str is valud but undefined
    // possible empty
    cout << "str:  '" << str << "'" << endl;
    // mstr took inner data str
    cout << "mstr: '" << mstr << "'" << endl;

    return 0;
}
```

```
str:  ''
mstr: 'Hello'
```

### Когда использовать `std::move`

| Ситуация                                                | Пример                                     |
| ------------------------------------------------------- | ------------------------------------------ |
| Передача владения временным объектом                    | `MyClass c = std::move(temp);`             |
| Реализация move-конструктора или оператора присваивания | `data = std::move(other.data);`            |
| Работа с STL контейнерами                               | `vec.push_back(std::move(x));`             |
| Когда нужно "забрать" ресурс у объекта                  | Например, умные указатели, строки, векторы |
### Важно помнить

| Факт                                                                    | Объяснение                                                 |
| ----------------------------------------------------------------------- | ---------------------------------------------------------- |
| После `std::move(obj)` объект `obj` остаётся валидным                   | Но его содержимое не определено                            |
| Move быстрее copy только если есть ресурс (например, выделенная память) | Для POD типов move не даёт преимуществ                     |
| Не используйте `std::move` там, где можно обойтись без него             | Например, с локальными переменными внутри функции          |
| Move может быть заменён компилятором на RVO/NRVO                        | Компилятор может оптимизировать возврат объекта из функции |
### Лучшая практика

| Рекомендация                                                                | Почему                                             |
| --------------------------------------------------------------------------- | -------------------------------------------------- |
| Используйте `std::move`, когда хотите передать владение                     | Эффективнее, чем копирование                       |
| Не используйте `std::move` с локальными переменными, если не нужно          | Лишняя сложность                                   |
| Не используйте `std::move` с объектами, которые будут использоваться дальше | Объект будет в неопределённом состоянии            |
| Используйте `std::forward<T>` в шаблонах                                    | Чтобы сохранить категорию значения (lvalue/rvalue) |
