**Семантика перемещения (Move Semantics)** — это важная особенность C++11 и выше, которая позволяет **эффективно передавать и возвращать временные объекты**, избегая лишних копирований.

Обычно при передаче или возврате объектов из функции происходит **копирование**, что может быть дорогостоящим для сложных типов (например, `std::vector`, `std::string`).

Семантика перемещения позволяет:
- **"Передавать владение" ресурсами** (памятью, дескрипторами и т.д.) от одного объекта к другому,
- Избежать лишнего копирования,
- Увеличить производительность.

| Термин | Описание |
|--------|----------|
| **Rvalue (правостороннее значение)** | Временный объект, который скоро умрёт (например: `x + y`, `"Hello"`, `std::string("temp")`) |
| **Lvalue (левостороннее значение)** | Именованный объект, который существует "долго" (например: переменная) |
| **Rvalue reference (`T&&`)** | Специальный тип ссылки, связанный с rvalue |
| **Move constructor** | Конструктор, который "перемещает" данные из временного объекта |
| **Move assignment operator** | Оператор присваивания, принимающий rvalue и "перемещающий" данные |

## 📌 Когда используется семантика перемещения?

### 1. При возврате временного объекта из функции
```cpp
std::string getTempString() {
    std::string s = "temporary";
    return s; // будет использован move
}
```

### 2. При передаче временного объекта в функцию
```cpp
void process(std::string&& s) {
    std::cout << s << std::endl;
}

process("Hello");         // OK: строковый литерал неявно преобразуется
process(std::string("Hi")); // OK
```

### 3. При использовании `std::move`
Функция `std::move()` **не перемещает**, а просто **приводит объект к rvalue reference**, чтобы вызвать move-версию конструктора/оператора:

```cpp
MyData a;
MyData b = std::move(a); // Теперь b владеет данными, a в "валидном, но неопределённом состоянии"
```

- __NRVO__ - named return value optimization
