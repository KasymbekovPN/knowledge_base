[[_cpp containers|<=]]

`std::span` - это класс из стандартной библиотеки C++20, представляющий невладеющий (non-owning) вид на непрерывную последовательность объектов. Это безопасная альтернатива работе с сырыми указателями и размерами.

## Основные характеристики

1. **Невладеющий** - не управляет временем жизни данных
2. **Легковесный** - обычно занимает 2 машинных слова (указатель + размер)
3. **Безопасный** - проверяет границы в debug-режиме
4. **Гибкий** - может работать с массивами, векторами и другими контейнерами

## Особенности использования

### Преимущества:
1. Безопаснее сырых указателей
2. Удобнее передачи (ptr + size)
3. Работает с любыми непрерывными данными
4. Нулевые накладные расходы в release-сборке

### Ограничения:
1. Только для непрерывных данных
2. Не управляет временем жизни
3. C++20 и новее
