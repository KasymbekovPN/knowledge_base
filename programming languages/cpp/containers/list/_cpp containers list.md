[[_cpp containers|<=]]

`std::list` в C++ — это контейнер, представляющий собой двусвязный список. Он поддерживает эффективное добавление и удаление элементов в любом месте списка, но не предоставляет произвольного доступа к элементам по индексу (как, например, `std::vector`).
