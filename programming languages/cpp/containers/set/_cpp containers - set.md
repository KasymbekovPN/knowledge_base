[[_cpp containers|<=]]

В C++ `std::set` — это ассоциативный контейнер, который хранит уникальные элементы в отсортированном порядке. Он реализован как сбалансированное бинарное дерево поиска (обычно красно-черное дерево), что обеспечивает логарифмическую сложность для операций вставки, удаления и поиска.
