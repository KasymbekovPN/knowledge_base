В C++ **строковые литералы** — это способ представления строк прямо в коде. Они могут быть разных типов в зависимости от используемой кодировки и типа данных, на которые указывают.

## Основные виды строковых литералов в C++

| Тип литерала | Синтаксис | Тип данных (`decltype`) | Пример |
|--------------|-----------|--------------------------|--------|
| Обычный     | `"..."`   | `const char*`            | `"Hello"` |
| UTF-8       | `u8"..."`  | `const char*` (UTF-8)    | `u8"Привет"` |
| Unicode 16  | `u"..."`   | `const char16_t*`        | `u"Hello"` |
| Unicode 32  | `U"..."`   | `const char32_t*`        | `U"Hello"` |
| Широкие символы | `L"..."` | `const wchar_t*`         | `L"Hello"` |
