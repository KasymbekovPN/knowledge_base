[[programming languages/cpp/string/std_string/_|<=]]

| Способ                                     | Пример                                                   |
| ------------------------------------------ | -------------------------------------------------------- |
| Пустая строка                              | `std::string s;`                                         |
| Инициализация строковым литералом          | `std::string s = "Hello";`                               |
| Копирование другой строки                  | `std::string s2 = s1;`                                   |
| Подстрока другой строки                    | `std::string s3(s1, 0, 5);` // первые 5 символов из `s1` |
| Из массива `char[]`                        | `char arr[] = "World"; std::string s(arr);`              |
| С заданным количеством одинаковых символов | `std::string s(5, 'x');` // "xxxxx"                      |
