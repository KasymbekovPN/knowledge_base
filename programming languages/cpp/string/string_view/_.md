[[programming languages/cpp/string/_|<=]]

`std::string_view` — это легковесный **неуправляемый "обзор" на строку**, введённый в __C++17__ как часть стандартной библиотеки. Он позволяет работать со строками без копирования данных, что делает его **очень эффективным** для передачи и обработки строковых данных.

- Это **непладжерная ссылка (non-owning)** на уже существующую строку.
- Может указывать на:
  - `const char*`
  - `std::string`
  - Строковые литералы
- Не копирует данные.
- Обеспечивает **постоянный доступ к подстроке** без выделения памяти.

#### Характеристики

| Характеристика           | Значение                                            |
| ------------------------ | --------------------------------------------------- |
| Тип                      | `std::string_view` (из `<string_view>`)             |
| Управление памятью       | Нет (только наблюдатель)                            |
| Изменяемость             | Только чтение (`const`)                             |
| Поддержка UTF-8 / UTF-16 | Да (через `char`, `char8_t`, `char16_t`, `wchar_t`) |
| Версия стандарта         | C++17 и новее                                       |
#### Преимущества

| Преимущество    | Объяснение                                      |
| --------------- | ----------------------------------------------- |
| Быстродействие  | Не копирует данные                              |
| Гибкость        | Работает с любыми типами строк                  |
| Безопасность    | Предоставляет методы `substr`, `find` и т.д.    |
| Экономия памяти | Идеально для функций, только считывающих строки |
#### Ограничения

| Ограничение | Почему |
|------------|--------|
| Нельзя изменять содержимое | `string_view` — только для чтения |
| Жизненный цикл важен | Если строка уничтожена, `string_view` становится недействительным |
| Нет гарантии null-termination | `data()` может не возвращать `'\0'`-завершённую строку |

#### Когда использовать `std::string_view`

| Ситуация | Рекомендация |
|----------|--------------|
| Функция принимает строку для чтения | Используйте `std::string_view` |
| Нужна модификация строки | Используйте `std::string` |
| Передача в C API | Используйте `.data()` или передавайте `std::string` |
| Нужны широкие символы (`wchar_t`) | Используйте `std::wstring_view` |
