# Docker — введение

Docker — это платформа для контейнеризации приложений. Контейнер — это изолированный процесс со своим набором файлов, библиотек и зависимостей, который работает на общем с хостом ядре ОС (в отличие от виртуальной машины, где эмулируется всё железо).

## Зачем это нужно

- **"Работает у меня, но не работает у тебя"** — контейнер упаковывает приложение вместе со всем окружением, поэтому оно одинаково запускается везде: у разработчика, на CI, на проде.
- **Изоляция** — процессы, файловая система, сеть контейнера отделены от хоста.
- **Лёгкость** — контейнер стартует за секунды и весит гораздо меньше, чем виртуальная машина, потому что не тащит с собой полноценную ОС.

## Ключевые понятия

| Термин                    | Что это                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------- |
| **Image (образ)**         | Неизменяемый шаблон — файловая система + метаданные, из которого создаются контейнеры |
| **Container (контейнер)** | Запущенный экземпляр образа                                                           |
| **Dockerfile**            | Текстовый рецепт, описывающий, как собрать образ                                      |
| **Registry**              | Хранилище образов (например, Docker Hub)                                              |
| **Volume**                | Механизм для сохранения данных вне жизненного цикла контейнера                        |
