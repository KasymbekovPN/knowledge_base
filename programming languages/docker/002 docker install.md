# Установка Docker на Windows

## Что выбрать: Docker Desktop или Docker Engine

На Windows нативно **Docker Engine** (демон) не запускается — ему нужно ядро Linux. Поэтому есть два пути:

- **Docker Desktop** — официальное GUI-приложение, которое разворачивает Docker Engine внутри лёгкой Linux-VM через WSL 2. Даёт CLI, панель управления, интеграцию с Kubernetes и Compose "из коробки". Это стандартный путь для 95% разработчиков на Windows.
- **"Голый" Docker Engine внутри WSL 2** — установить Linux-дистрибутив (Ubuntu) через WSL и поставить туда Docker Engine напрямую, без Docker Desktop. Более "линуксовый" путь, без GUI, но и без лицензионных ограничений Docker Desktop (актуально для крупных компаний — у Docker Desktop есть платная лицензия для коммерческого использования в организациях от 250+ сотрудников).

Для обучения — однозначно **Docker Desktop**, дальше будем ставить его.

## Требования

- Windows 10 64-bit версии 21H2+ или Windows 11 (любая редакция, включая Home)
- Включённая аппаратная виртуализация в BIOS (Intel VT-x / AMD-V)
- Права администратора

## Шаги установки

**1. Проверить виртуализацию**

Открой Диспетчер задач → вкладка "Производительность" → ЦП. Если внизу справа написано `Виртуализация: Включено` — всё готово, переходи к шагу 2. Если "Отключено" — нужно зайти в BIOS/UEFI (обычно `F2`, `Del` или `Esc` при загрузке) и включить `Intel Virtualization Technology` / `AMD SVM Mode`.

**2. Установить WSL 2**

Открой PowerShell **от администратора** и выполни:

```powershell
wsl --install
```

Это поставит компонент WSL, ядро Linux и дистрибутив Ubuntu по умолчанию. После — перезагрузка.

Если WSL уже был установлен раньше, вместо этого выполни:

```powershell
wsl --update
```

**3. Скачать и установить Docker Desktop**

Скачай установщик с [официальной страницы Docker Desktop](https://www.docker.com/products/docker-desktop). Для обычного x64-процессора — версия x64, для устройств на ARM (Snapdragon X) — версия ARM64.

Запусти `Docker Desktop Installer.exe`, оставь галочку **"Use WSL 2 instead of Hyper-V"** включённой (это значение по умолчанию), доустанови.

**4. Проверить установку**

После перезапуска открой PowerShell и выполни:

```powershell
docker --version
docker run hello-world
```

Если видишь приветственное сообщение от `hello-world` — всё работает: клиент достучался до демона, демон скачал образ из registry и запустил контейнер.

## Полезная настройка: ограничение ресурсов WSL

По умолчанию WSL 2 может забирать много RAM. Чтобы ограничить, создай файл `%USERPROFILE%\.wslconfig`:

```ini
[wsl2]
memory=8GB
processors=4
```

После изменения перезапусти WSL:

```powershell
wsl --shutdown
```
