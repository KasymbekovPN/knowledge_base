Rust — системный язык программирования, созданный Mozilla (первый релиз 1.0 в 2015), сейчас развивается под эгидой Rust Foundation. Основная идея: производительность на уровне C/C++, но без целого класса ошибок памяти и гонок данных — и всё это проверяется на этапе компиляции, без сборщика мусора и почти без рантайм-оверхеда.

**Ключевые идеи, которые всё определяют:**

- **Ownership (владение).** У каждого значения есть ровно один владелец. Когда владелец выходит из области видимости, значение уничтожается автоматически (похоже на RAII в C++, но это встроено в язык и проверяется компилятором, а не держится на дисциплине программиста).
- **Borrowing (заимствование).** Вместо передачи владения можно "одолжить" ссылку — либо много неизменяемых (`&T`), либо ровно одну изменяемую (`&mut T`) одновременно. Это правило на этапе компиляции исключает data races и use-after-free.
- **Lifetimes.** Компилятор отслеживает, как долго живёт каждая ссылка, чтобы гарантировать — она никогда не переживёт данные, на которые указывает. Для C++-разработчика это как если бы dangling pointer стал ошибкой компиляции, а не UB в рантайме.
- **Без null, без исключений.** Вместо null — `Option<T>`, вместо исключений — `Result<T, E>`. Ошибки обрабатываются явно через типы, а не через try/catch.
- **Trait-система** вместо классического ООП-наследования — похоже на интерфейсы/концепты, но с возможностью статической (generics, монолитизация как шаблоны C++) и динамической (`dyn Trait`, vtable) диспетчеризации.
- **Fearless concurrency.** Правила владения и заимствования распространяются и на потоки — компилятор не даст скомпилировать код с гонкой данных (в большинстве случаев).
- **`unsafe`** — люк для случаев, где нужен низкоуровневый контроль (сырые указатели, FFI); весь unsafe-код явно помечен и локализован.

**Экосистема:** Cargo — менеджер пакетов и сборщик (аналог связки CMake+vcpkg), crates.io — репозиторий пакетов, `rustc` — компилятор на основе LLVM. Компилятор известен строгими, но информативными сообщениями об ошибках.

**Где используется:** системное ПО, WebAssembly, встраиваемые системы, сетевые сервисы (tokio-экосистема), части браузеров (Firefox), утилиты (ripgrep, fd), и всё активнее — компоненты, встраиваемые в существующие C++ кодовые базы через FFI.
