## Три вида циклов — вместо четырёх в C++

В C++ есть `for`, `while`, `do-while`, и C-style `for` с тремя частями. В Rust — `loop`, `while`, `for`, и `do-while` отсутствует как отдельная конструкция.

### `loop` — бесконечный цикл, и он тоже выражение

```rust
let mut counter = 0;

let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // break может возвращать значение из loop!
    }
};

println!("{result}"); // 20
```

Это то, чего в C++ нет вообще — `break` с значением, которое становится результатом всего цикла как выражения. Ближайший аналог в C++ — `while(true) { ... }` с переменной, объявленной снаружи для хранения результата:

```cpp
int counter = 0;
int result;
while (true) {
    counter++;
    if (counter == 10) { result = counter * 2; break; }
}
```

`loop` идиоматичен именно там, где нужно "выполнять, пока не найдём что-то и не вернём это" — часто заменяет паттерн retry-логики.

### `while` — как в C++, без сюрпризов

```rust
let mut n = 5;
while n != 0 {
    println!("{n}");
    n -= 1;
}
```

Единственное отличие — то же самое правило про `bool`: условие обязано быть `bool`, никакого `while (n)` для чисел.

### `for` — принципиально другой, чем в C++

Вот здесь разница максимальная. В Rust `for` — **только** по итератору, C-style `for (int i = 0; i < n; i++)` не существует как конструкция вообще:

```rust
for i in 0..5 {          // диапазон, эксклюзивный справа: 0,1,2,3,4
    println!("{i}");
}

for i in 0..=5 {         // диапазон, инклюзивный справа: 0,1,2,3,4,5
    println!("{i}");
}

let v = vec![10, 20, 30];
for x in &v {             // итерация по ссылкам — v не перемещается, доступна после цикла
    println!("{x}");
}

for x in v {               // итерация по значению — v перемещается, элементы владеются циклом
    println!("{x}");
}
```

Прямой аналог классического `for (int i = 0; i < n; i++)`:

```cpp
for (int i = 0; i < 5; i++) {
    std::cout << i;
}
```

переписывается как:

```rust
for i in 0..5 {
    println!("{i}");
}
```

Это устраняет целый класс классических C++ багов: off-by-one в условии, забытый `i++`, изменение индекса внутри тела цикла, из-за которого логика "уезжает". В Rust индекс диапазона просто недоступен для модификации изнутри — итератор двигает его сам.

Range-based for в C++11 (`for (auto& x : v)`) — это уже прямой аналог `for x in &v`/`for x in &mut v`:

```cpp
for (auto& x : v) { x *= 2; }        // C++, изменяем элементы
```

```rust
for x in &mut v { *x *= 2; }         // Rust, аналог
```

### `do-while` — заменяется идиомой через `loop`

Раз конструкции нет, паттерн "выполнить хотя бы раз, потом проверить условие" пишут через `loop` с условием и `break` в конце:

```rust
let mut n = 0;
loop {
    n += 1;
    println!("{n}");
    if n >= 5 { break; }
}
```

## `break` и `continue` — с метками (labels) для вложенных циклов

Это тоже то, чего в стандартном C++ нет (там только `goto` как обходной путь для выхода из нескольких уровней вложенности):

```rust
'outer: for i in 0..5 {
    for j in 0..5 {
        if i * j > 6 {
            break 'outer; // выходим сразу из внешнего цикла
        }
        println!("{i} {j}");
    }
}
```

В C++ эквивалент — либо флаг-переменная с проверкой на каждом уровне, либо `goto`:

```cpp
bool done = false;
for (int i = 0; i < 5 && !done; i++) {
    for (int j = 0; j < 5; j++) {
        if (i * j > 6) { done = true; break; }
        std::cout << i << " " << j;
    }
}
```

`continue 'label` работает аналогично — переходит к следующей итерации конкретного помеченного цикла, а не самого внутреннего.

## `if let` / `while let` — уже разобрали в контексте `let`, но это тоже ветвление

Напомню кратко в контексте этой темы: `if let`/`while let` — это специализированная форма ветвления по одному паттерну, синтаксический сахар над `match`, который уже разбирали подробно раньше. Полноценно — см. прошлое сообщение про `let`.

## Сводная таблица

|Конструкция|Rust|C++|Ключевое отличие|
|---|---|---|---|
|Условное ветвление|`if`/`else`|`if`/`else`|В Rust — выражение, обязательный `bool`, все ветки — один тип|
|Тернарный аналог|`if cond { a } else { b }`|`cond ? a : b`|В Rust нет отдельного тернарного оператора — `if`-выражение и есть аналог|
|Бесконечный цикл|`loop`|`while(true)` / `for(;;)`|`loop` может возвращать значение через `break value`|
|Цикл с условием|`while`|`while`|Идентичны, кроме строгого `bool`|
|Цикл по коллекции/диапазону|`for x in iter`|`for(auto& x : container)` (C++11+)|В Rust — единственная форма `for`, C-style индексного `for` нет вообначе|
|Do-while|нет|`do { } while()`|В Rust — идиома через `loop` + `break`|
|Выход из вложенных циклов|`break 'label`|`goto` / флаг|В Rust — часть языка, безопасно и читаемо|

## Небольшая ловушка для C++-разработчика: `for` не создаёт индекс, к которому есть прямой доступ снаружи

```rust
for i in 0..5 { }
println!("{i}"); // ОШИБКА: i не существует здесь — область видимости цикла
```

В C++ до C++11 индекс, объявленный в `for(int i = ...)`, тоже был scoped к циклу (начиная с C++11 это тоже так), так что здесь поведение на самом деле совпадает — но стоит явно проговорить, если у тебя в памяти есть C-style паттерны, где индекс иногда специально объявляли снаружи цикла для использования после.
