Сначала проверю актуальные версии Emacs и Doom, а также текущий список модулей Doom. Потом соберу инструкцию и конфиги.

Собираю установочный скрипт и конфиги Doom под C++/Rust/CMake/Docker.

Проверяю синтаксис скрипта и elisp.

Я собрал скрипт установки и конфиги Doom под ваш стек: C++ с clangd, Rust, CMake, Docker, Magit и отладчик. Синтаксис файлов я проверил, но целиком на WSL установку не прогонял.

**Почему Emacs собирается из исходников.** В Ubuntu 24.04 через apt ставится Emacs 29.3. Последняя версия Emacs — 31.1, но Doom официально заявляет поддержку Emacs 27.1–30.2, поэтому скрипт собирает 30.2.

**Почему отдельно собирается libtree-sitter.** Doom перешёл с внешнего пакета tree-sitter на встроенный treesit. После этого на C++ встречается ошибка "language grammar for c is unavailable (version-mismatch): 15". Причина в том, что системная libtree-sitter 0.20 не умеет загружать свежие грамматики. Поэтому скрипт собирает libtree-sitter 0.25.

## Шаги

**0. Проверьте WSLg.** Нужна Windows 11 или свежий WSL. В терминале Ubuntu выполните:

```bash
wsl.exe --version          # WSL 2.x
echo $WAYLAND_DISPLAY      # должно вывести wayland-0
```

Ядер и памяти для сборки и clangd лучше выделить побольше. Это настраивается в `%UserProfile%\.wslconfig` (`processors=`, `memory=`), после чего нужно выполнить `wsl --shutdown`.

**1. Положите файлы в одну папку:**

```bash
mkdir -p ~/emacs-setup && cp /mnt/c/Users/<вы>/Downloads/{setup-emacs-wsl.sh,init.el,config.el,packages.el,clangd.example} ~/emacs-setup/
cd ~/emacs-setup
```

**2. Запустите установку.** Целиком:

```bash
bash setup-emacs-wsl.sh all
```

Или по шагам, если что-то упадёт и нужно перезапустить отдельную часть:

|Шаг|Что делает|
|---|---|
|`deps`|Зависимости для сборки Emacs|
|`treesitter`|libtree-sitter 0.25 в `/usr/local`|
|`emacs`|Emacs 30.2: pgtk, native-comp (AOT), tree-sitter, modules. Самый долгий шаг, 15–40 минут|
|`tools`|ripgrep, fd, clang/clangd/clang-tidy/clang-format, cmake, ninja, gdb, bear, ccache, шрифт JetBrains Mono|
|`rust`|rustup, rust-analyzer, clippy, rustfmt|
|`doom`|Клонирует Doom, копирует ваши конфиги, затем выполняет `doom install`, `doom env`, `doom sync`, `doom doctor`|

После шага `emacs` должно вывестись `native-comp: t` и `tree-sitter: t`. Во время `doom install` на вопросы отвечайте `y`.

**3. Первый запуск:**

```bash
source ~/.bashrc
emacs &
```

Внутри Emacs выполните `M-x nerd-icons-install-fonts` и перезапустите Emacs, чтобы появились иконки. Когда вы впервые откроете `.cpp` или `.rs`, Doom предложит собрать tree-sitter-грамматику, ответьте `y`.

**4. Подготовьте C++-проект.** Держите его в `~/projects`, а не в `/mnt/c`: так в разы быстрее.

```bash
cmake -S . -B build -G Ninja -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cp ~/emacs-setup/clangd.example .clangd
```

Если проект собирается не через CMake, получите `compile_commands.json` через `bear -- make`. Без этого файла clangd на монолите почти бесполезен.

**5. Проверка:**

- `doom doctor` не должен показывать красных ошибок.
- В C++-файле в modeline должен появиться `eglot` и clangd. `M-x +tree-sitter/doctor` проверяет tree-sitter.
- `SPC g g` открывает Magit, `SPC o t` открывает терминал vterm. При первом открытии vterm скомпилирует модуль, ответьте `y`.

## Важное в конфигах

- **eglot + clangd:** `--background-index`, `--clang-tidy`, `--header-insertion=never`. Если ядер мало, уменьшите `-j=8` в `config.el`.
- **`format` без `+onsave`:** форматирование только вручную через `SPC c f`. Так clang-format не перепишет чужой код в монолите при сохранении.
- **Отладка через dape + gdb:** gdb 15 из Ubuntu понимает DAP сам. Клавиши: `SPC d d` старт, `SPC d b` брейкпоинт, `SPC d n` / `SPC d s` / `SPC d o` шаги.
- **Rust:** rust-analyzer проверяет через clippy и со всеми features.
- **Если мешают vim-клавиши:** удалите строку `(evil +everywhere)` из `init.el` и выполните `doom sync`.

## Если что-то не так

|Проблема|Решение|
|---|---|
|Emacs не видит `cargo` или `rust-analyzer`|`doom env`, затем перезапуск Emacs|
|Ошибки tree-sitter в C++|Уберите `+tree-sitter` у `cc` в `init.el`, выполните `doom sync`. Обычный `c++-mode` с clangd работает отлично|
|Глюки отрисовки или клавиатуры в GUI|В шаге `emacs` замените `--with-pgtk` на `--with-x-toolkit=gtk3` и пересоберите|
|Поменяли `init.el` или `packages.el`|Всегда выполняйте `doom sync`|

Могу дополнительно сделать ярлык в меню «Пуск» Windows для запуска Emacs из WSL одним кликом.

### setup-emacs-wsl
```sh
#!/usr/bin/env bash
# Emacs 30.2 (pgtk + native-comp + tree-sitter) + Doom Emacs + C++/Rust тулчейн
# Ubuntu 24.04 под WSL2 (WSLg).
#
# Использование:
#   bash setup-emacs-wsl.sh all          # всё по порядку
#   bash setup-emacs-wsl.sh deps         # отдельный шаг: deps|treesitter|emacs|tools|rust|doom
#
# init.el / config.el / packages.el должны лежать рядом со скриптом.
set -euo pipefail

EMACS_VERSION="30.2"      # Doom официально поддерживает до 30.2
TS_SERIES="0.25"          # libtree-sitter: Ubuntu-шная 0.20 не грузит свежие грамматики (ABI 15)
BUILD_DIR="$HOME/src"
JOBS="$(nproc)"
HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

log() { printf '\n\033[1;32m==> %s\033[0m\n' "$*"; }

step_deps() {
  log "Зависимости для сборки Emacs"
  sudo apt update
  sudo apt install -y build-essential
  # libgccjit должен совпадать по версии с gcc, которым собирается Emacs
  local gcc_ver
  gcc_ver="$(gcc -dumpversion | cut -d. -f1)"
  echo "gcc major version: ${gcc_ver}"
  sudo apt install -y \
    git curl wget pkg-config texinfo \
    libgtk-3-dev libgnutls28-dev "libgccjit-${gcc_ver}-dev" libgccjit0 \
    libjpeg-dev libpng-dev libgif-dev libtiff-dev librsvg2-dev libwebp-dev \
    libharfbuzz-dev libcairo2-dev libsqlite3-dev libxml2-dev \
    libncurses-dev libacl1-dev libgpm-dev libm17n-dev libotf-dev \
    cmake libtool-bin libvterm-dev
  if dpkg -s libtree-sitter-dev >/dev/null 2>&1; then
    log "Удаляю системный libtree-sitter-dev (0.20) — будет собран свежий"
    sudo apt remove -y libtree-sitter-dev
  fi
}

step_treesitter() {
  log "Сборка libtree-sitter ${TS_SERIES}.x"
  mkdir -p "$BUILD_DIR" && cd "$BUILD_DIR"
  [ -d tree-sitter ] || git clone --filter=blob:none https://github.com/tree-sitter/tree-sitter.git
  cd tree-sitter
  git fetch --tags --quiet
  local tag
  tag="$(git tag -l "v${TS_SERIES}.*" | sort -V | tail -1)"
  [ -n "$tag" ] || { echo "Не найден тег v${TS_SERIES}.*"; exit 1; }
  git checkout --quiet "$tag"
  make -j"$JOBS"
  sudo make install          # -> /usr/local/lib, /usr/local/include
  sudo ldconfig
  echo "libtree-sitter: $tag"
}

step_emacs() {
  log "Сборка Emacs ${EMACS_VERSION} (займёт 15–40 минут)"
  mkdir -p "$BUILD_DIR" && cd "$BUILD_DIR"
  [ -f "emacs-${EMACS_VERSION}.tar.xz" ] || \
    wget "https://ftp.gnu.org/gnu/emacs/emacs-${EMACS_VERSION}.tar.xz"
  rm -rf "emacs-${EMACS_VERSION}"
  tar xf "emacs-${EMACS_VERSION}.tar.xz"
  cd "emacs-${EMACS_VERSION}"
  ./configure \
    --with-pgtk \
    --with-native-compilation=aot \
    --with-tree-sitter \
    --with-modules \
    --with-gnutls \
    --without-pop \
    CFLAGS="-O2"
  make -j"$JOBS"
  sudo make install
  emacs --version | head -1
  emacs -Q --batch --eval \
    '(princ (format "native-comp: %s\ntree-sitter: %s\n" (native-comp-available-p) (treesit-available-p)))'
}

step_tools() {
  log "C++ тулчейн и утилиты"
  sudo apt install -y \
    ripgrep fd-find \
    clang clangd clang-tidy clang-format \
    cmake ninja-build gdb bear ccache \
    shellcheck fonts-jetbrains-mono
  mkdir -p "$HOME/.local/bin"
  ln -sf "$(command -v fdfind)" "$HOME/.local/bin/fd"
}

step_rust() {
  log "Rust (rustup + rust-analyzer)"
  if ! command -v rustup >/dev/null 2>&1; then
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
  fi
  # shellcheck disable=SC1091
  source "$HOME/.cargo/env"
  rustup component add rust-analyzer rust-src clippy rustfmt
}

step_doom() {
  log "Doom Emacs"
  [ -d "$HOME/.config/emacs" ] || \
    git clone --depth 1 https://github.com/doomemacs/doomemacs "$HOME/.config/emacs"

  mkdir -p "$HOME/.config/doom"
  for f in init.el config.el packages.el; do
    if [ -f "$HERE/$f" ]; then
      [ -f "$HOME/.config/doom/$f" ] && cp "$HOME/.config/doom/$f" "$HOME/.config/doom/$f.bak"
      cp "$HERE/$f" "$HOME/.config/doom/$f"
    fi
  done

  if ! grep -q '.config/emacs/bin' "$HOME/.bashrc"; then
    echo 'export PATH="$HOME/.config/emacs/bin:$HOME/.local/bin:$PATH"' >> "$HOME/.bashrc"
  fi
  export PATH="$HOME/.config/emacs/bin:$HOME/.local/bin:$PATH"
  # shellcheck disable=SC1091
  [ -f "$HOME/.cargo/env" ] && source "$HOME/.cargo/env"

  doom install      # интерактивно: на вопросы отвечать y
  doom env          # снимок PATH (cargo, ~/.local/bin) для GUI-Emacs
  doom sync
  doom doctor || true
}

case "${1:-all}" in
  deps)       step_deps ;;
  treesitter) step_treesitter ;;
  emacs)      step_emacs ;;
  tools)      step_tools ;;
  rust)       step_rust ;;
  doom)       step_doom ;;
  all)        step_deps; step_treesitter; step_emacs; step_tools; step_rust; step_doom ;;
  *) echo "usage: $0 [all|deps|treesitter|emacs|tools|rust|doom]"; exit 1 ;;
esac

log "Готово. Перезапусти терминал (или: source ~/.bashrc) и запускай: emacs &"
```

### config.el
```lisp
;;; config.el -*- lexical-binding: t; -*-
;;
;; Личные настройки. Изменения применяются после перезапуска Emacs
;; (или M-x doom/reload). doom sync нужен только после правки init.el / packages.el.

(setq user-full-name "Pablo")

;;; ─── Внешний вид ──────────────────────────────────────────────────────────
(setq doom-font (font-spec :family "JetBrains Mono" :size 15)
      doom-theme 'doom-one
      display-line-numbers-type 'relative)

;;; ─── Проекты ──────────────────────────────────────────────────────────────
;; Код держи в файловой системе Linux (~/projects), а не в /mnt/c — в разы быстрее.
(setq projectile-project-search-path '(("~/projects" . 2)))

;;; ─── Производительность LSP ───────────────────────────────────────────────
(setq read-process-output-max (* 4 1024 1024))

(after! eglot
  (setq eglot-events-buffer-config '(:size 0 :format full) ; не логировать JSON-RPC
        eglot-autoshutdown t                               ; гасить сервер, когда закрыт последний буфер
        eglot-extend-to-xref t)                            ; оставаться в LSP при переходе в заголовки

  ;; clangd под большой монолит. -j подстрой под число ядер, выделенных WSL.
  (add-to-list 'eglot-server-programs
               '((c-mode c-ts-mode c++-mode c++-ts-mode)
                 . ("clangd"
                    "-j=8"
                    "--background-index"
                    "--clang-tidy"
                    "--completion-style=detailed"
                    "--header-insertion=never"
                    "--pch-storage=memory")))

  ;; rust-analyzer: проверка через clippy, все features
  (setq-default eglot-workspace-configuration
                '(:rust-analyzer (:check (:command "clippy")
                                  :cargo (:features "all")))))

;;; ─── Сборка ───────────────────────────────────────────────────────────────
;; SPC c c — compile, затем ]e / [e или M-g n / M-g p по ошибкам
(setq compilation-scroll-output 'first-error)

;;; ─── Отладка: dape (DAP) ──────────────────────────────────────────────────
;; gdb 14+ умеет DAP нативно (в Ubuntu 24.04 gdb 15) — отдельный адаптер не нужен.
(use-package! dape
  :defer t
  :config
  (setq dape-buffer-window-arrangement 'right))

(map! :leader
      (:prefix ("d" . "debug")
       :desc "Start / attach"     "d" #'dape
       :desc "Toggle breakpoint"  "b" #'dape-breakpoint-toggle
       :desc "Continue"           "c" #'dape-continue
       :desc "Next"               "n" #'dape-next
       :desc "Step in"            "s" #'dape-step-in
       :desc "Step out"           "o" #'dape-step-out
       :desc "Restart"            "r" #'dape-restart
       :desc "Quit"               "q" #'dape-quit))

;;; ─── Magit на большом репозитории ─────────────────────────────────────────
(after! magit
  (setq magit-diff-refine-hunk t)
  ;; Если status открывается медленно — эти секции самые дорогие:
  (remove-hook 'magit-status-sections-hook #'magit-insert-tags-header))

```
