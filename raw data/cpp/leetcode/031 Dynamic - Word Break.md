## Word Break

**Условие:** дана строка `s` и словарь `wordDict` (список слов). Определить, можно ли разбить `s` на последовательность одного или нескольких слов из словаря (слова можно использовать многократно).

### Идея

Определим `dp[i]` — булево значение: можно ли разбить префикс `s[0..i-1]` (первые `i` символов) на слова из словаря. Переход: `dp[i] = true`, если существует такая позиция `j < i`, что `dp[j] == true` (префикс до `j` уже успешно разбит) **и** подстрока `s[j..i-1]` целиком является словом из словаря. То есть перебираем все возможные точки "последнего разреза".

База: `dp[0] = true` — пустой префикс тривиально "разбит" (ничего разбивать не надо).

### Решение

```cpp
#include "word_break.h"  
  
#include <vector>  
#include <string>  
#include <unordered_set>  
#include <iostream>  
  
namespace word_break {  
  
bool word_break(const std::string& s, const std::vector<std::string>& word_dict) {  
    const std::unordered_set<std::string> DICT(word_dict.begin(), word_dict.end());  
    const int N{static_cast<int>(s.size())};  
  
    std::vector<bool> dp(N+1, false);  
    dp[0] = true;  
  
    for (int i{1}; i <= N; ++i) {  
        for (int j{0}; j <= i; ++j) {  
            if (dp[j] && DICT.contains(s.substr(j, i - j))) {  
                dp[i] = true;  
                // нашли хотя бы один способ разбить префикс до i -> дальше не ищем  
                break;  
            }        
        }    
    }  

    return dp[N];  
}  
  
void demo() {  
    const std::string S{"leetcode"};  
    const std::vector<std::string> DICT{"leet", "code"};  
    std::cout  
        << "word_break : "  
        << std::boolalpha  
        << word_break(S, DICT)  
        << std::noboolalpha  
        << std::endl;  
}  
  
}
```

### Разбор

- `dict` — хеш-множество слов словаря для O(1) проверки принадлежности (вместо линейного поиска по вектору).
- Внешний цикл `i` — правая граница текущего префикса `s[0..i-1]`, который проверяем на разбиваемость.
- Внутренний цикл `j` — перебирает все возможные позиции последнего "разреза": если `dp[j]` уже `true` (префикс до `j` успешно разбит) и оставшийся кусок `s[j..i-1]` — целое слово из словаря, значит и `dp[i] = true`.
- `s.substr(j, i - j)` извлекает подстроку с позиции `j` длиной `i - j` (то есть символы с индекса `j` по `i-1` включительно).
- `break` после нахождения первого подходящего `j` — как только `dp[i]` установлено в `true`, дальнейший перебор `j` для этого `i` бессмысленен (булево значение не может "улучшиться").

### Пример

```
s = "leetcode", wordDict = ["leet", "code"]

dp[0]=true

i=1: j=0: dp[0]=true, s[0:1]="l" -> не в словаре. dp[1]=false
i=2: j=0: s[0:2]="le" -> нет. dp[2]=false
i=3: j=0: s[0:3]="lee" -> нет. dp[3]=false
i=4: j=0: s[0:4]="leet" -> в словаре! dp[4]=true
i=5: j=0: "leetc" -> нет. j=1..3: dp[j]=false -> пропуск. j=4: dp[4]=true, s[4:5]="c" -> нет. dp[5]=false
i=6: аналогично, ни один j не подходит. dp[6]=false
i=7: j=4: dp[4]=true, s[4:7]="cod" -> нет. dp[7]=false
i=8: j=4: dp[4]=true, s[4:8]="code" -> в словаре! dp[8]=true

Результат: dp[8] = true  ("leet" + "code")
```

### Сложность

- Время: **O(n³)** в худшем случае — `O(n²)` пар `(i, j)`, и для каждой пары `substr` создаёт новую строку за `O(n)`. Проверка в `unordered_set` в среднем O(длина подстроки), что тоже до O(n).
- Память: **O(n)** под `dp`, плюс O(суммарная длина слов словаря) под `dict`.

### Оптимизация без создания подстрок (избегаем O(n) на substr)

Если сравнивать подстроку с словами словаря напрямую по индексам (без `substr`), можно снизить константу, но асимптотика в худшем случае останется той же без использования более продвинутых структур (например, Trie или хеширования подстрок за O(1) через префиксные хеши). На собеседовании обычно достаточно версии выше — но стоит упомянуть, что `substr` создаёт копию, и это может быть узким местом при больших `n`.

### Частые вариации

- **Word Break II** — вернуть **все** возможные разбиения (не просто true/false) — DP + backtracking для восстановления всех вариантов, часто с мемоизацией промежуточных результатов (`unordered_map<int, vector<string>>`), чтобы не пересчитывать одни и те же суффиксы многократно.
- **Concatenated Words** — найти все слова в списке, которые можно составить из других слов этого же списка — по сути Word Break, применённый к каждому слову с оставшимся списком как словарём.
- **Longest Word in Dictionary through Deleting** — не про DP, но часто путается по тематике "слова + словарь"; на деле — задача на two pointers/подпоследовательности.

### Частый доп. вопрос: "а если словарь очень большой?"

Проверку `dict.contains(s.substr(j, i-j))` можно оптимизировать через **Trie** (префиксное дерево) по словарю — тогда при переборе `j` от `i` в обратную сторону можно инкрементально проверять совпадение по Trie, не выделяя новую подстроку на каждом шаге и рано прерывая перебор, если текущий префикс уже не совпадает ни с одним словом в Trie.
