## Product of Array Except Self

**Условие:** дан массив `nums`. Вернуть массив `answer`, где `answer[i]` — произведение всех элементов `nums`, кроме `nums[i]`. Нельзя использовать деление. Ожидается O(n) по времени (доп. память под сам выходной массив не считается).

### Идея

Наивно: посчитать общее произведение и делить на `nums[i]` — O(n), но запрещено (деление, плюс проблема с нулями). Без деления: `answer[i] = (произведение всех элементов слева от i) * (произведение всех элементов справа от i)`.

Считаем это в два прохода:

1. Прямой проход — записываем в `answer[i]` произведение всех элементов **слева** от `i`.
2. Обратный проход — умножаем `answer[i]` на произведение всех элементов **справа** от `i`, накапливая это произведение в одной переменной (без отдельного массива).

### Решение

```cpp
#include "product_except_self.h"  
  
#include <iostream>  
#include <format>  
  
namespace product_except_self {  
  
static void print_vector(const std::vector<int>& v, std::string&& label) {  
    std::cout << std::format("[{}] (", label);  
    std::string delimiter;  
    for (const auto& i : v) {  
        std::cout << std::format("{}{}", delimiter, i);  
        delimiter = ", ";  
    }
	std::cout << ")\n";  
}  
  
std::vector<int> make_product(const std::vector<int>& nums) {  
    const int N{static_cast<int>(nums.size())};  
    std::vector<int> answer(N, 1);  
  
    // проход слева направо: answer[i] = произведение nums[0..i-1]  
    int prefix{1};  
    for (int i{}; i < N; ++i) {  
        answer[i] = prefix;  
        prefix *= nums[i];  
    }  

    // проход справа налево: домножаем на произведение nums[i+1..n-1]  
    int suffix{1};  
    for (int i{N-1}; i >= 0; --i) {  
        answer[i] *= suffix;  
        suffix *= nums[i];  
    }  

    return answer;  
}  
  
void demo() {  
    const std::vector<int> NUMS = {1, 2, 3, 4, 5, 6, 7, 8, 9};  
    auto result0 = make_product(NUMS);  
    print_vector(result0, "V0");  
}  
  
}
```

### Разбор

- После первого прохода `answer[i]` содержит произведение всех элементов **строго левее** `i`. `prefix` накапливается постепенно: на шаге `i` мы записываем текущее накопленное значение (до включения `nums[i]`), затем обновляем `prefix`.
- Второй проход аналогичен, но справа налево и с умножением (а не присваиванием), т.к. в `answer[i]` уже лежит "левая" часть.
- Ни деление, ни отдельный массив под суффиксные произведения не используются — `suffix` это скаляр, обновляемый на лету. Именно поэтому доп. память O(1) (не считая выходного массива).
- Нули обрабатываются корректно автоматически: если один элемент равен 0, для всех остальных позиций произведение "слева * справа" правильно включит этот 0 в нужную сторону; если нулей два и больше, все `answer[i]` станут 0 естественным образом, без специальной проверки.

### Пример

```
nums    = [1, 2, 3, 4]
prefix-проход: answer = [1, 1, 2, 6]
suffix-проход (suffix идёт 1, 4, 12, 24):
  i=3: answer[3] *= 1  -> 6;   suffix = 4
  i=2: answer[2] *= 4  -> 8;   suffix = 12
  i=1: answer[1] *= 12 -> 12;  suffix = 24
  i=0: answer[0] *= 24 -> 24;  suffix = 24
answer = [24, 12, 8, 6]
```

### Сложность

- Время: **O(n)** — два линейных прохода.
- Память: **O(1)** доп. памяти (не считая выходного массива `answer`, который по условию задачи не входит в space complexity).

### Частый доп. вопрос

Спросят: "а если бы деление было разрешено?" — тогда: посчитать `totalProduct`, и `answer[i] = totalProduct / nums[i]`, но отдельно обработать случай с нулями (если ровно один ноль — только эта позиция ненулевая, если больше одного — весь ответ нулевой).
