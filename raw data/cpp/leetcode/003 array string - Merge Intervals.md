## Merge Intervals

**Условие:** дан массив интервалов `intervals`, где `intervals[i] = [start_i, end_i]`. Объединить все пересекающиеся интервалы и вернуть массив непересекающихся интервалов, покрывающих все входные.

### Идея

Если интервалы не отсортированы, проверять пересечения — сложно и требует O(n²) сравнений. Но если отсортировать по началу (`start`), то пересекающиеся интервалы гарантированно окажутся рядом друг с другом. Дальше — один проход: сравниваем текущий интервал с последним добавленным в результат; если они пересекаются или касаются — расширяем последний, иначе — добавляем новый.

Два интервала `[a, b]` и `[c, d]` (при `a <= c`, после сортировки) пересекаются или соприкасаются, если `c <= b`.

### Решение

```cpp
#include "merge_intervals.h"  
  
#include <algorithm>  
#include <vector>  
#include <iostream>  
#include <format>  
  
namespace merge_intervals {  
  
std::vector<std::vector<int>> merge(std::vector<std::vector<int>>& intervals) {  
    if (intervals.empty()) return {};  
  
    std::ranges::sort(  
        intervals,  
        [](const auto& a, const auto& b) {  
            return a[0] < b[0];  
        });  
    std::vector<std::vector<int>> result;  
    result.push_back(intervals[0]);  
  
    for (int i{1}; i < static_cast<int>(intervals.size()); ++i) {  
        auto& last = result.back();  
        if (const auto& cur = intervals[i]; cur[0] < last[1]) {  
            last[1] = std::max(last[1], cur[1]);  
        } else {  
            result.push_back(cur);  
        }
	}  

    return result;  
}  
  
void demo() {  
    auto INTERVALS = std::vector<std::vector<int> >{  
        {1, 3}, {15, 18}, {2, 6}, {8, 10}  
    };  
    for (const auto result = merge(INTERVALS); auto i : result) {  
        std::cout << std::format("[{}...{}]\n", i[0], i[1]);  
    }}
}
```

### Разбор

- Сортировка по началу интервала — ключевой шаг, приводит O(n²) задачу к O(n) после сортировки.
- `result.back()` — ссылка на последний добавленный (уже объединённый) интервал; сравниваем его конец с началом текущего.
- `cur[0] <= last[1]` — условие пересечения/касания. Если строго `<`, интервалы вида `[1,2]` и `[2,3]` не объединятся (зависит от условия задачи — обычно на LeetCode их **объединяют**, поэтому `<=`).
- `last[1] = std::max(last[1], cur[1])` — важно взять максимум, а не просто `cur[1]`, т.к. текущий интервал может быть полностью внутри предыдущего (например, `[1,10]` и `[2,3]`).
- `intervals` принимается по значению (не по ссылке), так как сортируем на месте — либо явно копируем перед сортировкой, либо, если можно мутировать вход, брать по `&`.

### Сложность

- Время: **O(n log n)** — доминирует сортировка, сам проход — O(n).
- Память: **O(n)** — под результат (или O(log n) / O(n) под сортировку, в зависимости от реализации `std::sort`).

### Частые вариации

- **Insert Interval** — вставить один новый интервал в уже отсортированный непересекающийся список за O(n), без полной пересортировки.
- **Meeting Rooms I/II** — по сути та же идея сортировки + свип, но считаем количество одновременных пересечений (нужна мин-куча по времени окончания или отдельная сортировка start/end).
- **Non-overlapping Intervals** — минимальное число удалений, чтобы не осталось пересечений (жадный алгоритм по концу интервала).
