## 3Sum

**Условие:** дан массив целых чисел `nums`. Найти все уникальные тройки `[nums[i], nums[j], nums[k]]` (индексы различны), сумма которых равна 0. В ответе не должно быть дублирующихся троек (по значениям).

### Идея

Наивный перебор всех троек — O(n³). Более быстрый путь без сортировки — hash set для третьего элемента, но с ним сложно избегать дублей. Стандартный оптимальный подход: **сортировка + два указателя**.

1. Сортируем массив.
2. Фиксируем первый элемент `nums[i]` в цикле.
3. Для оставшейся части массива (справа от `i`) ищем пару с суммой `-nums[i]` двумя указателями (`left`, `right`), как в классической задаче Two Sum на отсортированном массиве.
4. Пропускаем дубликаты на каждом уровне, чтобы не получить повторяющиеся тройки.

### Решение

```cpp
#include "three_sum.h"  
  
#include <iostream>  
#include <format>  
#include <algorithm>  
#include <ranges>  
  
namespace three_sum {  
  
std::vector<std::vector<int>> get_three_sum(std::vector<int>& nums) {  
    std::ranges::sort(nums);  
    std::vector<std::vector<int>> result;  
    int N{static_cast<int>(nums.size())};  
  
    for (int i{}; i < N - 2; ++i) {  
        // отсортировано: дальше только положительные -> сумма 0 невозможна  
        if (nums[i] > 0) break;  
  
        // пропуск дубликата первого элемента  
        if (i > 0 && nums[i] == nums[i - 1]) continue;  
  
        int left{i + 1};  
        int right{N - 1};  
        int target{ -nums[i] };  
  
        while (left < right) {  
            if (int sum{nums[left] + nums[right]}; sum == target) {  
                result.push_back({nums[i], nums[left], nums[right]});  
  
                // сдвигаем оба указателя и пропускаем дубликаты  
                while (left < right && nums[left] == nums[left  + 1]) ++left;  
                while (left < right && nums[right] == nums[right - 1]) --right;  
  
                ++left;  
                --right;  
            } else if (sum < target) {  
                ++left;  
            } else {  
                --right;  
            }
		}
	}  

    return result;  
}  
  
void demo() {  
    std::vector<int> NUMBERS{-1, 0, 1, 2, -1, -4};  
    for (const auto& result = get_three_sum(NUMBERS); auto& vec: result ) {  
        std::string delimiter{""};  
        std::cout << "[";  
        for (auto& item: vec) {  
            std::cout << std::format("{}{}", delimiter, item);  
            delimiter = ", ";  
        }
		std::cout << "]\n";  
    }
}
  
}
```

### Разбор

- `nums[i] > 0` → `break`: после сортировки, если текущий (самый маленький из оставшихся) элемент уже положителен, то сумма трёх элементов справа от него точно не может быть 0 — можно завершить внешний цикл досрочно.
- `nums[i] == nums[i-1]` → `continue`: если фиксированный элемент повторяет предыдущий, все тройки с ним уже были найдены на предыдущей итерации — пропускаем, чтобы не дублировать.
- Внутри — стандартный two-pointer поиск пары с суммой `target = -nums[i]` на отсортированном подмассиве `[i+1, n-1]`.
- После нахождения совпадения — два внутренних `while` пропускают повторяющиеся значения у `left` и `right`, чтобы не добавить одну и ту же тройку дважды (например, при `[-2,0,0,2,2]`).
- `nums` принимается по значению, так как сортируем на месте — не мутируем вход вызывающего кода.

### Пример

```
nums = [-1, 0, 1, 2, -1, -4]
после сортировки: [-4, -1, -1, 0, 1, 2]

i=0 (-4): target=4, left=1,right=5: nums[1]+nums[5]=-1+2=1<4 -> left++
          left=2,right=5: -1+2=1<4 -> left++
          left=3,right=5: 0+2=2<4 -> left++
          left=4,right=5: 1+2=3<4 -> left++  (left==right, стоп)

i=1 (-1): target=1, left=2,right=5: nums[2]+nums[5]=-1+2=1==1 -> найдено [-1,-1,2]
          пропуск дублей: left++, right--  -> left=3,right=4
          left=3,right=4: 0+1=1==1 -> найдено [-1,0,1]
          left++, right-- -> left=4,right=3 -> стоп

i=2 (-1): nums[2]==nums[1] -> пропуск (дубликат первого элемента)

i=3 (0): target=0, left=4,right=5: 1+2=3>0 -> right--  (left==right, стоп)

Результат: [[-1,-1,2], [-1,0,1]]
```

### Сложность

- Время: **O(n²)** — внешний цикл O(n), внутренний two-pointer проход O(n) для каждого `i`.
- Память: **O(log n)`–`O(n)** под сортировку (в зависимости от реализации `std::sort`), не считая памяти под результат.

### Частые вариации

- **Two Sum II (отсортированный массив)** — база для этой задачи, чистый two-pointer без внешнего цикла.
- **3Sum Closest** — вместо точного совпадения ищем тройку с суммой, ближайшей к `target`; та же схема, но обновляем лучший результат по `abs(sum - target)`.
- **4Sum** — дополнительный внешний цикл (`i`, `j`) + внутренний two-pointer; сложность O(n³) с аналогичным пропуском дублей на каждом уровне.
- **k-Sum обобщение** — рекурсивное сведение к `(k-1)-Sum`, база — `2Sum` через two-pointer.
