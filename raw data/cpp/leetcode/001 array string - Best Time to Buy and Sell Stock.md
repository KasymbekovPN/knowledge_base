## Best Time to Buy and Sell Stock

**Условие:** дан массив `prices`, где `prices[i]` — цена акции в день `i`. Разрешена ровно одна покупка и одна последующая продажа (продать можно только после покупки). Найти максимальную прибыль. Если прибыль невозможна — вернуть 0.

### Идея

Перебор всех пар (день покупки, день продажи) — O(n²). Но нужен только один проход: идём по массиву и держим минимальную цену, встреченную до текущего дня (`minPrice`). Для каждого дня считаем прибыль, если продать сегодня, купив по `minPrice`, и обновляем максимум. Это работает, потому что для дня продажи `i` оптимальная покупка — это минимум цены на отрезке `[0, i-1]`.

### Решение

```cpp
#include "best_time_buy_sell.h"  
  
#include <vector>  
#include <iostream>  
#include <format>  
#include <algorithm>  
#include <limits>  
  
namespace best_time_buy_sell {  
  
int max_profit(const std::vector<int> &prices) {  
    int min_price{std::numeric_limits<int>::max()};  
    int best_price{0};  
  
    for (int price: prices) {  
        min_price = std::min(min_price, price);  
        best_price = std::max(best_price, price - min_price);  
    }  
    return best_price;  
}  
  
void demo() {  
    const std::vector<int> PRICES = {10, 2, 3, 4, 5, 6, 3, 7, 18, 9};  
    std::cout << std::format("best_time_buy_sell: {}\n", max_profit(PRICES));  
}  
  
}
```

### Разбор

- `minPrice` — минимальная цена среди уже просмотренных дней (потенциальная точка входа).
- На каждом шаге сначала обновляем `minPrice` (можно купить и сегодня, если сегодня дешевле всего), затем считаем, сколько заработали бы, продав именно сегодня.
- `bestProfit` инициализирован нулём — это гарантирует, что при монотонно убывающих ценах ответ будет 0 (транзакцию просто не совершаем).
- Порядок операций важен: `minPrice` обновляется до расчёта прибыли за тот же день — это корректно, т.к. купить и продать в один день с прибылью нельзя (или считается, что мгновенная сделка даёт 0), а обновление `minPrice` текущей ценой влияет только на будущие дни.

### Сложность

- Время: **O(n)** — один проход.
- Память: **O(1)**.

### Частые вариации на собеседовании

- **Best Time to Buy and Sell Stock II** — разрешено много транзакций подряд → суммируем все возрастающие разницы (`prices[i] - prices[i-1]`, если положительно).
- **III** — не более двух транзакций → DP с 4 состояниями (buy1, sell1, buy2, sell2).
- **IV** — не более `k` транзакций → DP `O(n·k)`.
- **с cooldown / комиссией** — DP с дополнительными состояниями.
