## House Robber

**Условие:** дан массив `nums`, где `nums[i]` — сумма денег в доме `i`. Нельзя ограбить два соседних дома подряд (иначе сработает сигнализация). Найти максимальную сумму, которую можно ограбить.

### Идея

Для каждого дома `i` есть выбор: либо ограбить его (тогда предыдущий дом `i-1` ограбить нельзя, берём лучший результат до `i-2` плюс `nums[i]`), либо не грабить (тогда лучший результат — тот же, что был до `i-1`). Определим `dp[i]` — максимальная сумма, которую можно получить, рассматривая только первые `i+1` домов:

`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

где `dp[i-1]` — вариант "не грабим дом i", `dp[i-2] + nums[i]` — вариант "грабим дом i, дом i-1 пропускаем".

### Решение

```cpp
#include "house_robber.h"  
  
#include <vector>  
#include <algorithm>  
#include <format>  
#include <iostream>  
  
namespace house_robber {  
  
int rob(const std::vector<int>& nums) {  
    int prev2{0}; // dp[i-2], лучший результат "два дома назад"  
    int prev1{0}; // dp[i-1], лучший результат "один дом назад"  
  
    for (const auto& num : nums) {  
        const int current{std::max(prev1, prev2 + num)};  
        prev2 = prev1;  
        prev1 = current;  
    }  
    return prev1;  
}  
  
int rob_dp(const std::vector<int>& nums) {  
    const int N{static_cast<int>(nums.size())};  
    if (N == 0) return 0;  
    if (N == 1) return nums[0];  
  
    std::vector<int> dp(N);  
    dp[0] = nums[0];  
    dp[1] = std::max(nums[0], nums[1]);  
  
    for (int i{2}; i < N; ++i) {  
        dp[i] = std::max(dp[i - 1], dp[i - 2] + nums[i]);  
    }  
    return dp[N - 1];  
}  
  
void demo() {  
    const std::vector<int> NUMS{2, 7, 9, 3, 1};  
    std::cout << std::format("rob {}\n", rob(NUMS));  
    std::cout << std::format("rob_dp {}\n", rob_dp(NUMS));  
}  
  
}
```

### Решение (DP с O(1) памяти)

### Разбор

- `prev2` и `prev1` — скользящее окно из двух последних значений `dp[]`, как и в Climbing Stairs — полный массив не нужен, поскольку `dp[i]` зависит только от `dp[i-1]` и `dp[i-2]`.
- На каждом шаге: `cur = max(prev1, prev2 + num)` — либо пропускаем текущий дом (берём лучший результат без него — `prev1`), либо грабим его, добавляя к лучшему результату **через один** дом назад (`prev2`), поскольку соседний дом грабить нельзя.
- `prev2 = 0, prev1 = 0` — начальные значения корректно обрабатывают пустой массив и массив из одного элемента без отдельных проверок (для одного дома `cur = max(0, 0 + nums[0]) = nums[0]`, что верно).
- Сдвиг окна: после вычисления `cur` — `prev2` становится тем, что было `prev1`, `prev1` становится `cur`.

### Пример

```
nums = [2, 7, 9, 3, 1]

num=2: cur=max(0, 0+2)=2;  prev2=0, prev1=2
num=7: cur=max(2, 0+7)=7;  prev2=2, prev1=7
num=9: cur=max(7, 2+9)=11; prev2=7, prev1=11
num=3: cur=max(11, 7+3)=11; prev2=11, prev1=11
num=1: cur=max(11, 11+1)=12; prev2=11, prev1=12

Результат: 12  (ограбить дома 2 и 9 и 1: индексы 0,2,4 -> 2+9+1=12)
```

### Сложность

- Время: **O(n)** — один проход.
- Память: **O(1)**.

### Вариант с явным массивом DP (для наглядности перехода)

Полезно показать сначала эту версию, объяснив рекуррентную формулу на конкретных индексах, а затем оптимизировать до O(1) памяти.

### Частые вариации

- **House Robber II** — дома расположены **по кругу** (первый и последний — соседи). Решается запуском обычного `rob()` дважды: на подмассиве `[0, n-2]` и на `[1, n-1]` (исключая либо первый, либо последний дом), и берём максимум из двух результатов — так исключается одновременное ограбление первого и последнего домов.
- **House Robber III** — дома образуют **бинарное дерево**, нельзя грабить родителя и прямого потомка одновременно — решается через DFS, возвращающий пару `(результат без ограбления текущего узла, результат с ограблением)`.
- **Climbing Stairs** — уже разобранная задача, идентичная структура скользящего окна из двух предыдущих значений, но с суммированием вместо `max`.
- **Delete and Earn** — сводится к House Robber после группировки чисел по значению (сумма одинаковых чисел) и сортировки.

### Частый доп. вопрос: "почему `dp[i-2] + nums[i]`, а не `dp[i-1] + nums[i]` при ограблении?"

Потому что если грабим дом `i`, дом `i-1` грабить нельзя (соседние дома под сигнализацией) — значит лучший результат для соседа `i-1` учитывать нельзя, берём лучший результат **до** него, то есть `dp[i-2]`, который уже мог включать или не включать дом `i-2`, но точно не включает дом `i-1`.
