Составь список файлов с расширением jpg, находящихся в той же папке, что и этот файл.

2) Итеративно пройдись по списоку jpg-файлов

2.1) Каждый файл это фото чека. Нужно извлечь

2.1.1) Время и дату, если она есть

2.1.2) Общую сумму

2.1.3) таблицу данных `Название`(из чека) `Описанание`(название может быть сокращенным тебе нужно попытаться его расшифровать) `Количество`(из чека, литры, штуки, нраммы) `Цена`(из чека)

2.1.4) на основе полученных из чека данных нужно создать строку
```
{
    "datatime": ...,
    "total": ...,
    "items": [
        {
            "name": ...,
            "description": ...,
            "quantity": ...,
            "price": ...
        }
    ]
}
```

2.1.5) Загрузка полученных данных на диск

2.1.5.1) если datatime не обнаружена, то в папку <current-folder>/no-datatime в файл c именем <jpg-file-name> и расширением json нужно записать полученную json-строку

2.1.5.2) если datatime не обнаружена, то в папку <current-folder>/<datatime> в файл c именем <datatime>_<jpg-file-name> и расширением json нужно записать полученную json-строку
