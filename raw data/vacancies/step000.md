
Напиши скрипт на python внутри которого будет задан путь-до-папки из этой папки он будет читать файл *.html. 

Скрипт должен быть сохранен в папку `raw data/vacancies`

Из файла должна доставаться следующая информация:
1) Имя компонии
2) Тип графика
3) Тип устройства на работы
4) Зарплата, если указана, иначе помечать что не указана
5) Опыт
6) Является ли компания аккедитованной
7) Краткое описание проекта
8) Условия 
9) Обязаности
10) Требования/скилы

Скрипт должен формировать json, содержащий список объектов. Каждый объект соответсвует файлу.

json должен записываться в путь-до-папки/output.json
