### https://hh.ru/vacancy/134935929

Место работы — **Екатеринбург**, формат удалённо/гибрид, при релокации компания компенсирует аренду жилья на первые три месяца.

**Вакансия: 8/10** — Embedded-разработчик C/C++, «Прософт-Системы» (российский разработчик ПО и оборудования для автоматизации объектов энергетики — гидро-, тепло-, атомные, солнечные и ветряные станции, электрические подстанции), Екатеринбург (удалённо/гибрид), опыт 3-6 лет.

**Что нужно делать:**
- Разрабатывать, отлаживать новое и перерабатывать существующее ПО для промышленных контроллеров и ПК
- Сопровождать ПО
- Разрабатывать тесты ПО
- Документировать результаты работы

**Пожелания:**
- Высшее ИТ/инженерное образование
- Уверенное знание C/C++
- Умение создавать надёжный, тестируемый, документированный исходный код
- Знание паттернов проектирования
- Опыт написания кроссплатформенных приложений (плюсом)

---

**Хорошо бьётся:**
- C/C++ — сильная сторона
- Умение создавать надёжный, тестируемый, документированный код — прямое совпадение со стилем работы (защитные алгоритмы терминалов защит требовали именно такого подхода)
- Знание паттернов проектирования — сильная сторона (архитектор)
- Разработка/отладка/переработка ПО для промышленных контроллеров — прямая параллель с историческим embedded-опытом
- Домен энергетики и автоматизации объектов энергетики — **прямое совпадение с основным профессиональным опытом** (терминалы защит электрооборудования, устройство плавного пуска — те же классы задач: контроль и управление энергетическим оборудованием)
- Документирование результатов работы — управленческий опыт совпадает

**Разрыв:**
- Кроссплатформенность (плюсом) — конкретный опыт не описан явно
- Специфика конкретных промышленных контроллеров этой компании — потребует изучения на месте, но не является барьером

---

Это один из лучших матчей по совокупности домена и технологий: требования сформулированы широко и без специализированных технических барьеров (нет Qt, нет DSP, нет embedded Linux дистрибутивостроения), а сфера деятельности компании — автоматизация энергетических объектов — практически дословно совпадает с вашим историческим профессиональным треком (терминалы защит электрооборудования для гидро/тепло/атомных станций и подстанций — это именно тот класс индустрии, где вы уже работали). Мягкая формулировка требований ("пожелания", а не жёсткие условия) дополнительно снижает формальный барьер входа.

### https://hh.ru/vacancy/136884074

**Вакансия: 8/10** — Разработчик микроконтроллеров, Сбер (Центр квантовых технологий, победитель премии HR-Бренд), Москва (офис, м. Тульская), опыт 3-6 лет. Разработка ускорителей вычислений на основе интегральной фотоники, оптическая машина для замены слоёв в нейросетях, строительные блоки фотонного квантового компьютера.

**Обязанности:**
- Создание прошивок под новые устройства (с пониманием устройства целиком)
- Запуск и отладка совместно с командой электронщиков
- Участие в создании архитектуры устройств следующих поколений
- Прохождение и проведение code review

**Требования:**
- **Промышленный опыт работы с STM32**, наличие завершённых проектов
- Хорошее знание C/C++
- Опыт работы с интерфейсами **USB, UART, CAN, SPI, I2C**
- Опыт работы с Ethernet

**Будет плюсом:** опыт с Zephyr, Git и CI/CD применительно к МК, базовый Python, наличие pet-проектов

---

**Хорошо бьётся:**
- **STM32** — прямое совпадение (продвинутый уровень, промышленный опыт с завершёнными проектами)
- C/C++ — сильная сторона
- UART/CAN/SPI/I2C — прямое совпадение с историческим embedded-опытом (терминалы защит, устройство плавного пуска, блок измерения температур)
- Запуск и отладка совместно с электронщиками — участие (не самостоятельное проектирование), более мягкая форма hardware-взаимодействия
- Code review — управленческий опыт совпадает
- Python (базовый, плюсом) — есть
- Git (плюсом) — есть

**Разрыв:**
- USB, Ethernet на аппаратном уровне — частично новые интерфейсы
- Zephyr (плюсом) — новая RTOS, не встречалась
- Домен фотонных вычислений/квантовых технологий как контекст железа (термостабилизация, управление лазерами) — новый, но не создаёт технического барьера для программирования МК как такового

---

Это ещё один сильный embedded-матч: обязательные требования (промышленный STM32-опыт, C/C++, стандартные интерфейсы UART/CAN/SPI/I2C) почти дословно совпадают с вашим историческим опытом работы с терминалами защит и измерительными устройствами, без специализированных надстроек вроде Qt или Embedded Linux. Домен (фотоника, квантовые вычисления) необычный и интересный, но конкретная задача — прошивки для термостабилизации, управления лазерами и питанием — остаётся классической embedded-разработкой, где ваш опыт применим напрямую.

### https://hh.ru/vacancy/135993367

**Вакансия: 8/10** — Ведущий программист микроконтроллеров, «Гаскар Групп» (российский разработчик и производитель БВС полного цикла — от идеи до серии), Москва (офис/гибрид, м. Войковская), опыт 3-6 лет. Ведущий разработчик встраиваемых систем для прошивок BMS, ESC, служебных MCU и FCU беспилотных аппаратов.

**Чем предстоит заниматься:**
- Разработка и поддержка прошивок **BMS, ESC, служебных MCU и FCU**
- Проектирование архитектуры прошивки с учётом требований к надёжности и реальному времени
- Написание unit- и интеграционных тестов
- Код-ревью и менторинг разработчиков

**Требования:**
- 3+ года разработки прошивок на C/C++ для **STM32**
- **RTOS**: уверенный опыт с FreeRTOS или аналогами, планирование задач и управление ресурсами
- Глубокое знание **UART, SPI, I2C, CAN, USB, PWM, ADC**
- Уверенная работа с **SWD, осциллографом, логическим анализатором**
- Git, практика ревью кода
- Опыт работы с Linux

**Будет плюсом:** прошивки BMS/ESC, работа с прошивками полётных контроллеров (PX4/ArduPilot), протоколы MAVLink/DroneCAN, управление бесколлекторными двигателями (векторное управление/FOC), Python/Bash

---

**Хорошо бьётся:**
- **STM32** — прямое совпадение (продвинутый уровень)
- C/C++ от 3 лет — с запасом
- **UART, SPI, I2C, CAN, PWM, ADC** — прямое совпадение с историческим embedded-опытом (терминалы защит, устройство плавного пуска)
- SWD, осциллограф, логический анализатор — базовая embedded-практика (2013-2018)
- Git, ревью кода — прямое совпадение с тимлидским опытом
- Код-ревью и менторинг разработчиков — прямое совпадение с управленческой практикой
- Архитектура прошивки с учётом требований к надёжности и реальному времени — прямая параллель с защитными алгоритмами терминалов защит
- Управление бесколлекторными двигателями/FOC (плюсом) — концептуально близко к устройству плавного пуска (управление электродвигателем через силовой преобразователь)
- Python/Bash (плюсом) — есть

**Разрыв:**
- FreeRTOS конкретно — не подтверждено явно, хотя embedded real-time опыт даёт хорошую базу
- BMS/ESC firmware специфика (плюсом) — новая область силовой электроники, хотя концептуально близка к вашему опыту с силовыми преобразователями
- PX4/ArduPilot, MAVLink/DroneCAN (плюсом) — устойчивый дрон-специфичный пробел

---

Это ещё один сильный embedded-матч: базовые требования (STM32, стандартные интерфейсы на регистровом уровне, SWD-отладка) прямо совпадают с историческим опытом, а explicit требование к код-ревью и менторингу разработчиков хорошо резонирует с вашей управленческой практикой. Домен силовой электроники беспилотников (BMS — управление батареями, ESC — регуляторы оборотов двигателей) концептуально близок к вашему опыту с устройством плавного пуска (тоже управление электродвигателем через силовой преобразователь), что даёт хорошую содержательную базу для разговора на собеседовании, даже при отсутствии прямого опыта именно с БПЛА-компонентами.
