## Разборы вакансий

### https://hh.ru/vacancy/137005229

**Вакансия: 7/10** — Инженер-программист (разработчик ПО), АО «НТЦ Модуль» (аккредитованная ИТ-компания, разработка аппаратуры для авиационных/космических систем), Москва (офис, м. Аэропорт/Гражданская), опыт 3-6 лет.

**Обязанности:**
- Разработка специализированного прикладного ПО для приёма, декодирования, обработки и анализа структурированных потоков данных
- Системное проектирование и проработка архитектуры ПО (**монолитное ПО**, не микросервис)
- Работа с БД: проектирование, написание и оптимизация запросов
- Описание принятых технических решений
- Оформление документации по **ЕСПД (ГОСТ 19)**

**Требования:**
- Уверенный опыт разработки прикладного ПО (язык программирования некритичен, приветствуется Python и C++17+)
- **Опыт разработки монолитного ПО** в составе программного комплекса; понимание полного жизненного цикла разработки
- Навыки системного проектирования и архитектуры
- Работа с БД (приветствуется PostgreSQL)
- Уверенная работа в Linux
- Умение сопровождать код комментариями, грамотно описывать решения
- Знание ЕСПД (ГОСТ 19), MS Word для оформления по ГОСТ
- Высшее техническое; преимущество — образование в радиолокации/спутниковой навигации/связи

**Приветствуется:** опыт разработки ПО обработки телеметрических/потоковых данных, участие в ОКР/НИР с оформлением документации по госстандартам

---

**Хорошо бьётся:**
- C++17+ — прямое совпадение, с запасом
- **Опыт разработки монолитного ПО, понимание полного жизненного цикла разработки** — прямое совпадение (ваша система — не микросервисная архитектура)
- Системное проектирование и архитектура — сильная сторона (архитектор с 7+ лет опыта)
- SQL/NoSQL (средний) — частично закрывает PostgreSQL
- Linux — вероятно есть
- Умение сопровождать код комментариями, описывать решения — управленческий опыт совпадает
- Python (базовый) — есть, соответствует приветствуемому уровню

**Разрыв:**
- ЕСПД (ГОСТ 19), оформление документации по строгим госстандартам — новая формализованная практика, хотя архитектурная документация в целом есть
- Радиолокация/спутниковая навигация/связь как образование (преимущество) — новый домен, не строго обязательный
- Обработка телеметрических/потоковых данных (приветствуется) — концептуально близко к NBI-модулю и провайдерам опроса, но конкретный опыт с телеметрией не подтверждён

---

Это достижимая вакансия с широко сформулированными требованиями: язык программирования explicit "некритичен", а акцент сделан на инженерную культуру, понимание полного жизненного цикла разработки и опыт именно с монолитными системами (а не микросервисами) — это прямо резонирует с архитектурой ваших продуктов. Специфика домена (радиолокация, потоковые данные) заявлена как преимущество, а не обязательное условие, что снижает технический барьер по сравнению с другими вакансиями оборонного сектора.

### https://hh.ru/vacancy/137046189

Строго офисный формат, удалённой работы и гибрида нет; есть военная бронь.

**Вакансия: 7/10** — C++ разработчик (Embedded), НПО дальней радиолокации имени академика А.Л. Минца (НПОДАР, мировой лидер в разработке радиолокаторов для системы ракетно-космической обороны), Москва (офис, м. Аэропорт/Динамо/Гражданская), опыт 3-6 лет.

**Чем предстоит заниматься:**
- Разработка встраиваемого ПО на C/C++ для технологической аппаратуры РЛС
- Тестирование и отладка устройств
- Написание программной документации
- Работа с измерительной аппаратурой

**Хотелось бы, чтобы кандидат имел:**
- Опыт программирования на C/C++ не менее 3 лет (уровень не ниже middle)
- Владение скриптовыми языками (например, Python)
- **Опыт работы с unix-системами (обязательно)**
- Понимание работы микропроцессора/микроконтроллера, памяти
- Английский для чтения технической литературы
- Знание принципов работы интерфейсов (**UART, SPI, I2C, I2S, Ethernet, CAN**)
- Опыт работы с **АЦП, ЦАП, DMA** и другой периферией
- Опыт отладки и работы с контрольно-измерительным оборудованием

**Будет плюсом:** отладка параллельных интерфейсов/DDR-памяти, разработка драйверов, знание архитектуры вычислительных систем на ARM/PowerPC, чтение электрических схем, принципы радиолокации и ЦОС

---

**Хорошо бьётся:**
- C/C++ от 3 лет — с запасом
- Unix-системы (обязательно) — вероятно есть
- Понимание микропроцессора/микроконтроллера, памяти — сильная сторона
- **UART, SPI, I2C, CAN** — прямое совпадение с историческим embedded-опытом (терминалы защит)
- **АЦП, ЦАП, DMA** — прямое совпадение с работой над блоком измерения температур
- Python (базовый) — есть, соответствует уровню
- Отладка и работа с контрольно-измерительным оборудованием — базовая embedded-практика
- Разработка драйверов (плюсом) — концептуально знакома через работу с периферией
- ARM-архитектура (плюсом) — прямое совпадение (STM32)

**Разрыв:**
- I2S, Ethernet на аппаратном уровне — частично новые интерфейсы
- Отладка параллельных интерфейсов/DDR-памяти (плюсом) — новая, более сложная архитектура памяти
- PowerPC (плюсом) — новая архитектура
- Принципы радиолокации, ЦОС (плюсом) — специализированная DSP-область, отсутствует, но explicit только желательна

---

Это хороший embedded-матч: обязательные требования сформулированы достаточно широко (общий C/C++, unix-опыт, понимание МК/памяти, стандартные интерфейсы), а специализированная часть (принципы радиолокации, цифровая обработка сигналов, PowerPC) вынесена в раздел "будет плюсом", а не жёсткого условия. Это делает вход более достижимым, чем в других вакансиях радиолокационного профиля, где DSP-экспертиза была обязательной. Работа с АЦП/ЦАП/DMA и измерительным оборудованием хорошо резонирует с вашим историческим опытом.
