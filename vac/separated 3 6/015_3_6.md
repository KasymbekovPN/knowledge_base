### https://hh.ru/vacancy/136806673

Формат работы — **полностью удалённо**, оформление через договор ГПХ с ИП, место регистрации — Тамбов (не влияет на удалённый формат).

**Вакансия: 5/10** — Программист C, «Гросссофт», удалённо, от 180 000 до 250 000 ₽/мес, опыт 3-6 лет. Разработка встраиваемой ОС для сервисных процессоров, проект на стадии bring-up (поднятия железа) и создания базового платформенного ПО.

**Обязанности:**
- Разработка и поддержка низкоуровневого ПО на C для сетевых устройств/контроллеров/системного оборудования
- Проектирование и реализация драйверов (L2), работа с аппаратными интерфейсами и периферией МК
- Реализация и оптимизация стеков сетевых протоколов
- **Глубокая разработка IPv6 (адресация, NDP, SLAAC) и IPMI** (управление питанием, мониторинг сенсоров, Serial over LAN)
- Написание эффективного кода для ограниченных ресурсов (memory management, real-time constraints)
- Интеграция ПО с аппаратным обеспечением, анализ логов трафика (**tcpdump/wireshark**), диагностика на уровне пакетов
- Полный цикл разработки, модульное тестирование, документация

**Требования:**
- Уверенное владение C (указатели, memory alignment, volatile, битовые операции)
- Знание архитектуры RTOS или опыт с Linux kernel space
- Сетевые протоколы L2+ (Ethernet, VLAN 802.1Q, ARP/NDP, TCP/IP)
- **Глубокое знание IPv6**: структура заголовка, адресные области, SLAAC, NDP
- **Практический опыт с IPMI**: сообщения RMCP/LAN+, SEL, FRU, управление датчиками
- Инструменты отладки embedded-систем (JTAG/SWD, UART consoles)
- Чтение схемотехнической документации, работа с измерительным оборудованием (плюсом)
- Английский для чтения документации

---

**Хорошо бьётся:**
- Уверенное C (указатели, memory alignment, volatile, битовые операции) — сильная сторона
- Работа с аппаратными интерфейсами и периферией МК — прямое совпадение с историческим embedded-опытом
- JTAG/SWD, UART consoles — базовая embedded-практика (2013-2018)
- Написание эффективного кода для ограниченных ресурсов — прямая параллель с работой над терминалами защит
- Полный цикл разработки, модульное тестирование, документация — практический/управленческий опыт совпадает
- Сетевые протоколы (Ethernet, TCP/IP) — концептуально близко к NBI-модулю

**Разрыв:**
- **Глубокая IPv6-экспертиза (NDP, SLAAC)** — специфическая протокольная область, не встречалась
- **IPMI (RMCP/LAN+, SEL, FRU)** — та же категория BMC-протоколов управления серверным оборудованием, что и в вакансии «Крафтвэй» (6/10) — специализированная область, новая
- RTOS-архитектура или Linux kernel space — не подтверждено явно
- tcpdump/wireshark диагностика на уровне пакетов — не подтверждена явно

---

Базовая embedded/C-часть (работа с периферией, ограниченными ресурсами, отладочные инструменты) хорошо резонирует с вашим историческим опытом, но ядро роли — глубокая протокольная экспертиза в IPv6 (автоконфигурация, NDP) и IPMI (управление серверным оборудованием через BMC-подобные протоколы) — та же специализированная ниша, что уже встречалась как частичный барьер в вакансии «Крафтвэй» (BMC/UEFI). Полностью удалённый формат с гибким графиком — приятный практический плюс.
