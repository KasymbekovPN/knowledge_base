## 9) https://hh.ru/vacancy/135990393

**Вакансия 2/10:** Senior C++ Developer / Senior Security Engineer, РИОН, Москва (удалённо), опыт от 6 лет. Вендор ИБ, разработка системы перехвата и анализа сетевого трафика под Windows.

**Обязанности:**

- Разработка системы перехвата и анализа сетевого трафика под Windows
- Механизмы перехвата локальных соединений (Shared Memory, Named Pipes)
- Kernel-mode и user-mode компоненты системы мониторинга
- Оптимизация производительности и стабильности
- Техдокументация

**Требования к знаниям:**

- Глубокое понимание сетевых стеков Windows (WFP, NDIS, TDI)
- Разработка kernel-mode драйверов для Windows
- API hooking (Detours, EasyHook)
- Межпроцессное взаимодействие в Windows
- C/C++ и **Rust** на продвинутом уровне

**Требования к опыту:**

- Windows Filtering Platform (WFP)
- File system mini-filter драйверы
- DLL injection, перехват системных вызовов
- Отладка kernel-mode приложений (WinDbg)

**Требования к навыкам:**

- Работа с kernel-mode кодом, понимание рисков ошибок в драйверах
- Отладка BSOD
- Требования подписи драйверов Windows

**Стек:** C++, Rust, WDK, WinDbg, NDIS, WFP, File System Mini-Filter, Detours, EasyHook, windows-rs

---

Это узкоспециализированная роль — Windows kernel-mode разработка (драйверы, перехват трафика на уровне ОС), совершенно другой инженерный профиль, чем backend/архитектура высоконагруженных систем.

**Что есть в резюме:**

- **Rust** — указан в навыках (средний уровень) — Rust здесь требуется на продвинутом уровне, это частичное совпадение
- C++ на продвинутом уровне — совпадает
- Многопоточность, низкоуровневая работа с ресурсами (context switching, embedded-опыт с прерываниями/таймингами) — косвенно показывает системный склад мышления, но это далеко от специфики kernel-mode Windows

**Полный разрыв:**

- Kernel-mode драйверы, WDK — нет
- WFP, NDIS, TDI, mini-filter — нет
- WinDbg (уже поднимался вопрос в вакансии Kaspersky — этот инструмент нигде не подтверждён)
- API hooking (Detours/EasyHook), DLL injection — нет
- Подпись драйверов, отладка BSOD — нет

---

Это самая технически специфичная из всех разобранных вакансий — здесь нужна экспертиза именно в Windows-ядре и драйверостроении, которая принципиально отличается от вашего опыта (Linux-ориентированный high-load бэкенд + embedded на микроконтроллерах). Rust среднего уровня — единственная реальная точка пересечения, и то не дотягивает до заявленного "продвинутого".

Похоже, эта вакансия тоже далека от профиля — если нет непубличного опыта с Windows kernel-mode разработкой, это будет крайне сложный переход. Есть ли у вас такой опыт, который просто не попал в резюме, или вы целенаправленно расширяете поиск в новые для себя области?
