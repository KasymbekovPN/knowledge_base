**Чт 12.11, слот Б: Container With Most Water (Блок 2, 10 минут)**

Решай с нуля. Лимит 10 минут, компиляция с первого раза, без предупреждений. Шаблон лежит в файле `ContainerWithMostWater_task.cpp`.

**Условие.** Дан массив `height`: `height[i]` — высота вертикальной линии в позиции `i`. Выберите две линии так, чтобы вместе с осью X они образовали ёмкость, вмещающую больше всего воды. Верните эту наибольшую площадь: (расстояние между линиями) × (меньшая из двух высот). Ёмкость не наклоняется. Линий не меньше двух.

**Сигнатура:**

```cpp
int max_area(const std::vector<int>& height);
```

**Ограничения:** до 10^5 линий, высота от 0 до 10^4 (ответ влезает в `int`).

**Пример:** `{1, 8, 6, 2, 5, 4, 8, 3, 7}` даёт `49` (линии на позициях 1 и 8: расстояние 7, меньшая высота 7).

**Вопросы интервьюера:**

1. Какое решение первым приходит в голову и какая у него сложность? Почему оно не проходит по времени?
2. Как работает решение двумя указателями: какой указатель вы двигаете на каждом шаге и почему это безопасно (не пропускает оптимальную пару)?
3. Почему нельзя двигать указатель у более высокой линии?

**Цель:** O(n) по времени, O(1) по памяти.

Проверено: эталон проходит 29 из 29, заглушка ни одного. Решение перебором пар проходит 23 теста, шесть больших помечает «too slow». // height[i] is the height of a vertical line at position i. Choose two lines;
// together with the x axis they form a container. Return the largest area of water it can hold:
// (distance between the lines) * (the lower of the two heights). The container is not tilted.
// There are at least 2 lines.
int max_area(const std::vector<int>& height) {
    std::size_t lo{0};
    std::size_t hi{height.size() - 1};
    
    int best{0};
    while (lo < hi) {
	    const auto lo_val{height[lo]};
	    const auto hi_val{height[hi]};
	    
	    best = std::max(
		    best,
		    std:min(lo_val, hi_val));
		if (lo_val < hi_val) { ++lo; }
		else { --hi; }
    }
    
    return best;
}

// Reference: all pairs.
int brute_force(const std::vector<int>& h) {
    int best = 0;
    for (std::size_t i = 0; i < h.size(); ++i)
        for (std::size_t j = i + 1; j < h.size(); ++j)
            best = std::max(best, static_cast<int>(j - i) * std::min(h[i], h[j]));
    return best;
}

// Reference for big tests: two pointers, checked against brute_force on random inputs while writing the task.
int two_pointers(const std::vector<int>& h) {
    std::size_t lo = 0, hi = h.size() - 1;

}
