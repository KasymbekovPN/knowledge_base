Блок 2, повторение 3 из 6: **Container With Most Water** (LC 11). Пишем с нуля, без подсказок.

**Условие.** Дан массив `height` из `n` неотрицательных чисел: высоты вертикальных стенок, стенка `i` стоит в точке `x = i`. Выберите две стенки так, чтобы вода между ними вмещала как можно больше. Верните максимальную площадь `min(height[i], height[j]) * (j - i)` по всем парам `i < j`. Стенки наклонять нельзя, высота воды не больше меньшей из двух стенок.

**Сигнатура** (уже стоит в шаблоне как заглушка):

```cpp
int max_area(const std::vector<int>& height);
```

**Ограничения:** `2 <= height.size() <= 100000`, `0 <= height[i] <= 10000`. Ответ помещается в `int`.

**Вопросы интервьюера:**

1. Какая сложность по времени и по памяти?
2. Почему можно двигать именно меньшую стенку и не потерять оптимальную пару? Докажите словами.
3. Что происходит при равных высотах: нужно ли сдвигать обе стенки или достаточно любой?
4. Что изменится, если стенки могут быть разной толщины или между ними есть препятствия?

**Цель:** O(n) по времени, O(1) по памяти. O(n²) на больших тестах (n = 100 000) не уложится в 1 с. Если программа зависла, прервите её вручную, такой тест не прерывается сам.

	int expected_area(const std::vector<int>& height) {
		std::size_t lo{0};
		std::size_t hi{height.size() - 1};
