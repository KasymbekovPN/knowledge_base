**Задача 8 из 9 (блок 6): сколько дней до потепления** (LeetCode 739)

Дан массив температур по дням. Для каждого дня нужно найти, через сколько дней будет **строго более тёплый** день. Если такого дня нет, ответ для этого дня 0. Результат возвращается массивом той же длины.

```cpp
std::vector<int> daily_temperatures(const std::vector<int>& temperatures);
```

Например, для `{73, 74, 75, 71, 69, 72, 76, 73}` ответ `{1, 1, 4, 2, 1, 1, 0, 0}`.

**Ограничения**

- 1 ≤ n ≤ 1 000 000.
- Температуры лежат во всём диапазоне `int`, включая `INT_MIN` и `INT_MAX`, часто повторяются.
- Одинаковая температура не считается потеплением.

**Вопросы интервьюера**

1. Решите «в лоб» за два вложенных цикла. Какая сложность? На каких входах она будет худшей?
2. Какую структуру вы используете, чтобы свести задачу к O(n)? Что в ней хранится и в каком порядке лежат элементы (по возрастанию или по убыванию температуры)?
3. Что вы кладёте в стек: температуры или индексы? Почему именно это?
4. Когда вы заполняете ответ для дня из стека? Что должно быть в условии цикла: `<` или `<=`? Что изменится при другом выборе?
5. Что остаётся в стеке к концу прохода и какой ответ у этих дней?
6. Почему общая сложность O(n), хотя внутри есть вложенный цикл?

**Целевая сложность:** O(n) по времени, O(n) по памяти.

**Ориентир по времени:** 20 минут.

**Важно:** если решение квадратичное, большие тесты не завершатся за разумное время. Тест ограничивает время вызова двумя секундами, но прервать вашу функцию он не может. Если прогон завис на тесте `n = 1000000, decreasing`, остановите его и ищите O(n).

namespace {
	std::vector<int> daily_temperatures([[maybe_unused]] const std::vector<int>& temperatures) {
		return {};
	}

	// O(n) reference: for every day jumps along the already known answers to the next warmer day
	std::vector<int> expected_answer(const std::vector<int>& temperatures) {
		const std::size_t size{temperatures.size()};
		std::vector<int> answer(size, 0);
		for (std::size_t i{size}; i-- > 1;) {
			const std::size_t day{i - 1};
			std::size_t next{i};
			while (next < size && temperatures[next] <= temperatures[day]) {
				if (answer[next] == 0) {
					next = size;
					break;
				}
				next += static_cast<std::size_t>(answer[next]);
			}
			if (next < size) answer[day] = static_cast<int>(next - day);
		}
		return answer;
	}

	// the call must take less than two seconds
	void test_temperatures(const std::string& label, const std::vector<int>& temperatures) {
		const auto expected{expected_answer(temperatures)};

		const auto start{std::chrono::steady_clock::now()};
		const auto result{daily_temperatures(temperatures)};
		const auto elapsed{std::chrono::steady_clock::now() - start};

		std::cout << std::format("{}: {}\n",
			label,
			result == expected && elapsed < std::chrono::seconds(2) ? "OK" : "FAIL") << std::flush;
	}

	// size temperatures: pattern 0 grows, 1 decreases, 2 is constant, 3 is pseudo-random in the whole int range,
	// 4 is a saw with the period 1000, 5 decreases and ends with the maximum int, 6 is constant and ends with a bigger value,
	// 7 grows by steps of three equal values, 8 alternates the minimum and the maximum int
	std::vector<int> make_temperatures(int size, int pattern) {
		std::vector<int> values;
		values.reserve(static_cast<std::size_t>(size));
		unsigned state{12345u};
		for (int i{0}; i < size; ++i) {
			state = state * 1103515245u + 12345u;
			if (pattern == 0) values.push_back(i);
			else if (pattern == 1) values.push_back(size - i);
			else if (pattern == 2) values.push_back(7);
			else if (pattern == 3) values.push_back(static_cast<int>(state));
			else if (pattern == 4) values.push_back(i % 1000);
			else if (pattern == 5) values.push_back(i == size - 1 ? 2147483647 : 1000000000 - i);
			else if (pattern == 6) values.push_back(i == size - 1 ? 8 : 7);
			else if (pattern == 7) values.push_back(i / 3);
			else values.push_back(i % 2 == 0 ? -2147483647 - 1 : 2147483647);
		}
		return values;
	}
}

namespace {
	std::vector<int> daily_temperatures(const std::vector<int>& temperatures) {
		const std::size_t size{temperatures.size()};
		std::stack<int> st{};
		std::vector<int> answer(size, 0);
	
		for (int i{0}; i < static_cast<int>(size); ++i) {
			if (st.empty()) {
				st.push(i);
				continue;
			}
			
			while (!st.empty()) {
				const int prev_idx{st.top()};
				if (temperatures[i] > temperatures[prev_idx]) {
					answer[prev_idx] = i - prev_idx;
					st.pop();
				} else {
					break;
				}
			}
			st.push(i);
		}
	
		return answer;
	}
