Решай с нуля. Лимит 25 минут. Шаблон лежит в файле `RateLimiter_task.cpp`. Это новая версия файла: контейнер сменился, и старый файл не сохранился. Тесты те же, 27 штук.

**Условие.** Реализуйте ограничитель частоты запросов со скользящим окном.

- Пользователь может сделать не более `max_requests` **принятых** запросов в любом окне длиной `window`.
- В момент `now` окно — это `(now - window, now]`: запрос, сделанный ровно `window` единиц времени назад, уже считается устаревшим.
- `allow(user, timestamp)` возвращает `true`, если запрос принят, и `false`, если отклонён. Отклонённые запросы не запоминаются.
- Время передаётся параметром и не убывает между вызовами. Реальные часы использовать не нужно.

**Сигнатура:**

```cpp
class RateLimiter {
public:
    RateLimiter(int max_requests, int window);
    bool allow(int user, int timestamp);
};
```

**Ограничения:** до 10^6 вызовов, до 10^5 пользователей, `max_requests` до 2·10^4, `window` до 2·10^5, идентификаторы пользователей — любые `int`, включая отрицательные.

**Пример** (`max_requests = 3`, `window = 10`): `allow(1,1)`, `allow(1,2)`, `allow(1,3)` дают `true`, `allow(1,4)` даёт `false`, `allow(1,10)` даёт `false` (запрос в 1 ещё в окне `(0,10]`), `allow(1,11)` даёт `true` (запрос в 1 вышел из окна `(1,11]`).

**Вопросы интервьюера:**

1. Какую структуру вы храните на пользователя и почему именно такую (список, `deque`, очередь с вытеснением)?
2. Какая амортизированная сложность `allow` и сколько памяти занимает пользователь, который давно не делал запросов?
3. Чем отличается скользящее окно от фиксированного окна и счётчика-корзины (token bucket)?

**Цель:** `allow` за O(1) амортизированно, память O(число принятых запросов в окне).

// Sliding window log: a user may make at most `max_requests` ACCEPTED requests
// in any window of `window` time units. At time `now` the window is (now - window, now],
// so a request made exactly `window` units ago is already expired.
// Rejected requests are not recorded. Timestamps never decrease between calls.
class RateLimiter {
	int max_reqs_;
	int window_;
	std::unordered_map<int, std::deque<int>> windows_{};

public:
    RateLimiter(const int max_reqs, const int window):
	    max_reqs_{max_reqs},
	    window_{window} {}

    bool allow(const int user, const int timestamp) {
	    std::deque<int>& by_user{windows_[user]};
	    
	    while (!by_user.empty() && by_user.front() <= timestamp - window_) {
		    by_user.pop_front();
	    }
	    
	    if (by_user.size() >= static_cast<std::size_t>(max_reqs_)) {
		    return false;
	    }
    
	    by_user.push_back(timestamp);
    
		return true;
	}
};

// Independent reference: accepted timestamps per user, counted with a binary search.
class Model {
public:
    Model(int max_requests, int window) : max_requests_(max_requests), window_(window) {}

    bool allow(int user, int time) {
        std::vector<int>& accepted = log_[user];
        const auto first_alive = std::upper_bound(accepted.begin(), accepted.end(), time - window_);
        const auto alive = accepted.end() - first_alive;

        accepted.push_back(time);
        return true;

private:
    int max_requests_;
    int window_;
