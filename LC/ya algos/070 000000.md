**Условие.** Реализуйте хранилище «ключ → значения по времени».

- `set(key, value, timestamp)` сохраняет значение ключа на момент `timestamp`. Для одного ключа метки времени в вызовах `set` строго возрастают.
- `get(key, timestamp)` возвращает значение с наибольшей меткой времени, не превышающей `timestamp`. Если такой нет или ключа нет вовсе, возвращает пустую строку.

**Сигнатура:**

```cpp
class TimeMap {
public:
    void set(const std::string& key, const std::string& value, int timestamp);
    std::string get(const std::string& key, int timestamp);
};
```

**Ограничения:** до 4·10^5 операций суммарно, значения до 200 символов, метки времени — любые `int`, включая отрицательные.

**Пример:** `set("love","high",10)`, `get("love",10)` даёт `"high"`, `get("love",15)` даёт `"high"`, `set("love","low",20)`, `get("love",5)` даёт `""`, `get("love",15)` даёт `"high"`, `get("love",25)` даёт `"low"`.

**Вопросы интервьюера:**

1. Какую структуру вы храните для каждого ключа и почему именно такую (вектор или `map`)?
2. Как ищете нужное значение и какая сложность у `get`? Что делаете, чтобы не копировать значения при поиске?
3. Что изменится, если метки времени могут приходить не по возрастанию?

**Цель:** `set` за O(1) амортизированно, `get` за O(log n) от числа записей ключа.

// A time-based key-value store.
// set(key, value, timestamp) stores the value for the key at the given time.
//   For one key the timestamps of the set calls are strictly increasing.
// get(key, timestamp) returns the value stored for the key with the largest timestamp
//   that is <= the given one; if there is no such value (or no such key) it returns "".
class TimeMap {
	using tm_key_t = std::string;
	using tm_value_t = std::string;
	using tm_timestamp_t = int;
	
	std::unordered_map<tm_key_t, std::vector<std::pair<tm_value_t, tm_timestamp_t>>> storage_{};

public:
    void set(const tm_key_t& key, const tm_value_t& value, const tm_timestamp_t timestamp) {
	    storage_[key].emplace_back(value, timestamp);
    }

    tm_value_t get(const tm_key_t& key, const tm_timestamp_t timestamp) const {
	    const auto it{storage_.find(key)};
	    if (it == storage_.end()) return "";
	    
	    const auto& vec{it->second};
	    std::size_t lo{0};
	    std::size_t hi{vec.size()};
	    
	    while (lo < hi) {
		    const auto mi{lo + (hi - lo) / 2};
		    if (vec[mi].second <= timestamp) {
			    lo = mi + 1;
		    } else {
			    hi = mi;
		    }
	    }
	    
	    return lo > 0 ? vec[lo - 1].first : "";
	}
};

// Independent reference: for every key a map timestamp -> value.
class Model {
public:
    void set(const std::string& key, const std::string& value, int timestamp) {
        data_[key][timestamp] = value;
    }
    std::string get(const std::string& key, int timestamp) const {
        const auto it = data_.find(key);
        if (it == data_.end()) return "";
        const auto pos = it->second.upper_bound(timestamp);
        if (pos == it->second.begin()) return "";
        return std::prev(pos)->second;
    }

private:
    std::map<std::string, std::map<int, std::string>> data_;
};

    TimeMap tm;
    Model model;

        if (op.is_set) {
            tm.set(op.key, op.value, op.timestamp);

        } else {
            ok = ok && tm.get(op.key, op.timestamp) == model.get(op.key, op.timestamp);
        }
    }
    report(label, ok);
}
