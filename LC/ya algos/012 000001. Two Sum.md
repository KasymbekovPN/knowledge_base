## Задача: Two Sum (LeetCode 1, easy)

**Условие.** Дан массив целых чисел `nums` и целое число `target`. Нужно вернуть индексы двух **различных** элементов, сумма которых равна `target`. Гарантируется, что решение ровно одно. Один и тот же элемент использовать дважды нельзя. Порядок индексов в ответе не важен.

**Сигнатура:**

```cpp
std::vector<int> twoSum(std::vector<int>& nums, int target);
```

**Ограничения:**

- `2 <= nums.size() <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- существует ровно одна пара индексов, дающая `target`

**Что обычно спрашивает интервьюер:**

1. Решение в лоб и его сложность.
2. Как ускорить с помощью хеш-таблицы? Что в ней хранить, ключ или индекс, и в какой момент проверять и вставлять?
3. Почему важен порядок «сначала проверить, потом вставить»? Что будет с массивом `{3, 2, 4}` и `target = 6`?
4. Как поведёт себя решение на дубликатах (`{3, 3}`, `target = 6`)?
5. Переполнение: суммы двух элементов могут достигать `±2·10^9`. Помещается ли это в `int`? Что с разностью `target - nums[i]`?
6. Что выбрать: `std::unordered_map` или `std::map`, и чем отличаются по сложности и по памяти? Что делать, если массив отсортирован или память ограничена?

**Целевая сложность:** O(n) по времени и O(n) по памяти.

Что покрывают тесты:

- **ловушка с тем же элементом:** `{5, 1, 9, 2}` и `target = 10`. Решение, которое проверяет «есть ли в таблице `target - x`» до вставки текущего, обязано не взять `5 + 5`;
- **дубликаты:** `{3, 3}`, `{0, 4, 3, 0}` и `{4, 4, 4, 6, 10, 4}`. Подсказывают, что перезапись значения в таблице не должна потерять нужный индекс;
- **границы значений и переполнение:** `±10^9` в паре, а также пара `1000000000 + 1000000000` как соседний вариант, сумма которого доходит до `2·10^9` (всё ещё помещается в `int`, но не в 31 бит со знаком при лишнем сложении);
- **n = 10 000:** пара на самых последних позициях и на самых крайних (0 и 9999). Квадратичное решение проходит их (~5·10⁷ операций), но заметно медленнее.

#include <algorithm>
#include <vector>
#include <unordered_map>
#include <ranges>
#include <iostream>
#include <format>
#include <random>

namespace {
	using Nums = std::vector<int>;
	using Indices = std::vector<int>;

	Indices get_two_sum(const Nums& nums, int target) {
		const auto size{static_cast<int>(nums.size())};
		std::unordered_map<int, int> index_by_value;
		index_by_value.reserve(size);

		for (int i{0}; i < size; ++i) {
			if (const auto it{index_by_value.find(target - nums[i])};
				it != index_by_value.end()) {
				return {it->second, i};
			}

			index_by_value.emplace(nums[i], i);
		}
	
		return {};
	}

	void test_two_sum(const std::string& label,
					  const Nums& nums,
					  const int target,

}
