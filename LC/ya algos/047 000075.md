Блок 2, повторение 5 из 6: **Sort Colors** (LC 75). Пишем с нуля, без подсказок.

**Условие.** Дан массив `nums` из `n` чисел, каждое равно `0`, `1` или `2` (красный, белый, синий). Отсортируйте его **на месте** по возрастанию. Библиотечную сортировку (`std::sort` и подобные) использовать нельзя, подсчитывать количество каждого цвета и заполнять массив заново можно, но интервьюер попросит и вариант с одним проходом.

**Сигнатура** (уже стоит в шаблоне как заглушка):

```cpp
void sort_colors(std::vector<int>& nums);
```

**Ограничения:** `1 <= nums.size() <= 1000000`, `nums[i]` равно `0`, `1` или `2`.

**Вопросы интервьюера:**

1. Какая сложность по времени и по памяти?
2. Как сделать за **один проход** и O(1) дополнительной памяти? Какие инварианты держат три указателя?
3. Почему после обмена с правой границей указатель нельзя сразу сдвигать, а после обмена с левой можно?
4. Как обобщить на `k` цветов?

**Цель:** O(n) по времени, один проход, O(1) по памяти. Квадратичные сортировки на больших тестах (n = 1 000 000) не уложатся по времени. Если программа зависла, прервите её вручную, такой тест не прерывается сам.

**Время:** 15 минут. Критерий «выучено»: ≤25 минут, компиляция с первого раза, ни одного предупреждения.

namespace {
	void sort_colors(std::vector<int>& nums) {
		int lo{0};
		int mi{0};
		int hi{static_cast<int>(nums.size())};

		while (mi < hi) {
			if (nums[mi] == 0) {
				std::swap(nums[lo], nums[mi]);
				++lo;
				++mi;
			} else if (nums[mi] == 1) {
				++mi;
			} else  { // nums[mi] == 2
				--hi;
				std::swap(nums[hi], nums[mi]);
			}
		}
	}
