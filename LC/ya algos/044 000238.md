Блок 2, повторение 2 из 6: **Product of Array Except Self** (LC 238). Пишем с нуля, без подсказок.

**Условие.** Дан массив целых `nums`. Верните массив `answer`, где `answer[i]` равен произведению всех элементов `nums`, кроме `nums[i]`. Деление использовать **нельзя**.

**Сигнатура** (уже стоит в шаблоне как заглушка):

```cpp
std::vector<int> product_except_self(const std::vector<int>& nums);
```

**Ограничения:** `2 <= nums.size() <= 100000`, `-30 <= nums[i] <= 30`. Произведение любого префикса и любого суффикса массива помещается в 32-битный `int`.

**Вопросы интервьюера:**

1. Какая сложность по времени и по памяти (не считая возвращаемого массива)?
2. Почему нельзя взять общее произведение и поделить на `nums[i]`? Как себя ведут нули, и сколько их нужно учитывать в таком решении?
3. Как уложиться в O(1) дополнительной памяти, если выходной массив памятью не считается?
4. Что изменится, если ограничение на произведение убрать и значения будут большими?

**Цель:** O(n) по времени, O(1) дополнительной памяти кроме ответа. O(n²) на больших тестах (n = 100 000) не уложится в 1 с. Если программа зависла, прервите её вручную, такой тест не прерывается сам.

	void test_product(const std::string& label,
					  const std::vector<int>& nums,
					  const std::vector<int>& expected) {
		const auto result{product_except_self(nums)};
		std::cout << std::format("{}: {}\n",
			label,

	// expected answer by prefix and suffix products in 64 bits (the real answers fit in int)
	std::vector<int> expected_product(const std::vector<int>& nums) {
		const std::size_t n{nums.size()};
		std::vector<long long> prefix(n + 1, 1);
		std::vector<long long> suffix(n + 1, 1);
		for (std::size_t i{0}; i < n; ++i) {
			prefix[i + 1] = prefix[i] * nums[i];
		}
		for (std::size_t i{n}; i > 0; --i) {
			suffix[i - 1] = suffix[i] * nums[i - 1];
		}
		std::vector<int> result(n);
		for (std::size_t i{0}; i < n; ++i) {
			result[i] = static_cast<int>(prefix[i] * suffix[i + 1]);
		}
		return result;
	}

		}
		return nums;
	}
}
