**Условие.** Даны два отсортированных по возрастанию массива.

- В `nums1` ровно `m + n` элементов: первые `m` отсортированы, последние `n` — нули, это только место под результат.
- В `nums2` ровно `n` отсортированных элементов.
- Слейте `nums2` в `nums1` так, чтобы весь `nums1` стал отсортированным.
- Делайте это на месте, без дополнительного массива. `nums2` должен остаться без изменений.

**Сигнатура:**

```cpp
void merge(std::vector<int>& nums1, int m, const std::vector<int>& nums2, int n);
```

**Ограничения:** `m` и `n` до 10^6, значения — любые `int`, включая отрицательные и крайние.

**Пример:** `nums1 = {1, 2, 3, 0, 0, 0}`, `m = 3`, `nums2 = {2, 5, 6}`, `n = 3`. Результат `nums1 = {1, 2, 2, 3, 5, 6}`.

**Вопросы интервьюера:**

1. С какого конца вы идёте при слиянии и почему нельзя идти с начала?
2. Что делаете, когда один из массивов закончился раньше другого? Какой из двух случаев требует дописывать остаток, а какой нет?
3. Какая сложность по времени и памяти? Чем плохо решение «вставить `nums2` в конец и вызвать `std::sort`»?

**Цель:** O(m + n) по времени, O(1) дополнительной памяти.

std::size_t get_id(const int id) { return static_cast<std::size_t>(id); };

// nums1 has m + n elements: the first m are sorted, the last n are zeros that are only padding.
// nums2 has n sorted elements. Merge nums2 into nums1 so that the whole nums1 is sorted.
// Do it in place, nums2 must stay unchanged, no extra array.
void merge(std::vector<int>& nums1, int m, const std::vector<int>& nums2, int n) {
	int left{m - 1};
	int right{n - 1};
	int target{m + n - 1};

    while (right >= 0) {
	    if (left >= 0 && nums1[get_id(left)] > nums2[get_id(right)]) {
		    nums1[get_id(target--)] = nums1[get_id(left--)];
	    } else {
		    nums1[get_id(target--)] = nums2[get_id(right--)];
	    }
    }
}

void report(const std::string& label, bool ok) {
    std::cout << label << ": " << (ok ? "OK" : "FAIL") << '\n';

void test_merge(const std::string& label, std::vector<int> first, std::vector<int> second) {
    std::vector<int> expected = first;
    expected.insert(expected.end(), second.begin(), second.end());
    std::sort(expected.begin(), expected.end());
    std::vector<int> nums1 = first;
    nums1.resize(first.size() + second.size(), 0);
    const std::vector<int> nums2 = second;
    merge(nums1, static_cast<int>(first.size()), nums2, static_cast<int>(second.size()));
    report(label, nums1 == expected && nums2 == second);
}
