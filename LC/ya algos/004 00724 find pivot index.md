
# 724. Find Pivot Index (Easy)

Дан массив целых чисел `nums`. **Опорным индексом** (pivot index) называется индекс, для которого **сумма всех элементов строго слева** от него равна **сумме всех элементов строго справа**. Сам элемент на этой позиции ни в одну из сумм не входит.

Если индекс стоит у левого края, сумма слева считается равной `0`, и то же самое справа для правого края.

Нужно вернуть **самый левый** опорный индекс. Если такого индекса нет, нужно вернуть `-1`.

**Ограничения:** `1 ≤ nums.length ≤ 10⁴`, `-1000 ≤ nums[i] ≤ 1000`.

**Примеры:**

```
Вход:  nums = [1, 7, 3, 6, 5, 6]
Выход: 3
Пояснение: слева от индекса 3: 1 + 7 + 3 = 11, справа: 5 + 6 = 11.
```

```
Вход:  nums = [1, 2, 3]
Выход: -1
Пояснение: ни для одного индекса суммы слева и справа не совпадают.
```

```
Вход:  nums = [2, 1, -1]
Выход: 0
Пояснение: слева от индекса 0 элементов нет (сумма 0), справа: 1 + (-1) = 0.
```

Ориентир по времени: 20 минут. Начните с 2-3 своих примеров и крайних случаев: один элемент, отрицательные числа, ответ на левой или правой границе, несколько подходящих индексов (нужен самый  левый). Назовите подход и сложность вслух, затем код в блокноте с тестами. Пришлите код, разберу.

```cpp
#include <vector>
#include <iostream>
#include <format>
#include <string>
#include <numeric>

namespace {
	int find_pivot_index(const std::vector<int>& input) {		
		const auto total = std::accumulate(input.begin(), input.end(), 0);

		const auto size{static_cast<int>(input.size())};
		int left{0};
		for (int i{0}; i < size; ++i) {
			const auto right{total - left - input[i]};
			if (right == left) return i;
			
			left += input[i];
		}
	
		return -1;
	}
	
	void test_find_pivot_index(const std::string& label,
							   const std::vector<int>& input,
							   const int expected_index) {
		const auto result{find_pivot_index(input)};
		std::cout << std::format("{}: {}\n",
			label,
			result == expected_index ? "OK" : "FAIL") << std::flush;
	}
}

int main() {
	test_find_pivot_index("med pivot", {1, 7, 3, 6, 5, 6}, 3);
	test_find_pivot_index("no pivot", {1, 2, 3}, -1);
	test_find_pivot_index("left border pivot", {2, 1, -1}, 0);
	test_find_pivot_index("right border pivot", {-1, 1, 2}, 2);

	return 0;
}
```
