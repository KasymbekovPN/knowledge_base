## Задача: 3Sum (LeetCode 15, medium)

**Условие.** Дан массив целых чисел `nums`. Нужно вернуть все **уникальные** тройки `[nums[i], nums[j], nums[k]]`, где индексы `i`, `j`, `k` попарно различны, а сумма равна нулю. Два набора значений считаются одной тройкой, если отличаются только порядком. Порядок троек в ответе и порядок чисел внутри тройки не важны.

**Сигнатура:**

```cpp
std::vector<std::vector<int>> threeSum(std::vector<int>& nums);
```

**Формат ввода:** первая строка — `n`, вторая — `n` чисел через пробел.  
**Формат вывода:** по одной тройке на строку. Для сравнения с тестами ниже внутри тройки числа по возрастанию, а сами тройки по возрастанию лексикографически. Нормализуйте ответ в тестовой обвязке, иначе придётся угадывать порядок.

**Ограничения:**

- `3 <= n <= 3000`
- `-10^5 <= nums[i] <= 10^5`

**Что обычно спрашивает интервьюер:**

1. Решение в лоб и его сложность. Можно ли обойтись без `set` для дедупликации?
2. Как свести задачу к Two Sum II на отсортированном массиве?
3. Где и как пропускать дубликаты? Нужно ли это для всех трёх позиций?
4. Какие ранние выходы есть после сортировки?
5. Сколько памяти уходит на сортировку, что с доп. памятью и можно ли менять входной массив?

**Целевая сложность:** O(n²) по времени, O(1) дополнительной памяти без учёта ответа и сортировки.

#include <algorithm>
#include <format>
#include <iostream>
#include <string>
#include <vector>
#include <set>
#include <ranges>

namespace {
	using TripleItems = std::vector<int>;
	using Triplets = std::vector<TripleItems>;

	Triplets get_three_sum(const TripleItems& nums) {
		std::set<std::vector<int>> unique;
		const auto size{static_cast<int>(nums.size())};
		for (int i{}; i < size; ++i) {
			for (int j{i + 1}; j < size; ++j) {
				for (int k{j + 1}; k < size; ++k) {
					if (nums[i] + nums[j] + nums[k] != 0) continue;
					std::vector<int> buffer{nums[i], nums[j], nums[k]};
					std::ranges::sort(buffer);
					unique.insert(std::move(buffer));
				}
			}
		}
	
		return {unique.begin(), unique.end()};
	}
	
	Triplets get_three_sum_1(TripleItems nums) {
		std::ranges::sort(nums);
		
		Triplets result{};
		const auto size{static_cast<int>(nums.size())};
		for (int i{}; i < size - 2; ++i) {
			
			if (i > 0 && nums[i] == nums[i - 1]) continue;
		
			int left{i + 1};
			int right{size - 1};
			while (left < right) {
				const auto sum{nums[i] + nums[left] + nums[right]};
				if (sum == 0) {
					TripletsItems buffer{nums[i], nums[left], nums[right]};
					result.push_back(std::move(buffer));

					++left;
					--right;
					
					while (left < right && nums[left] == nums[left - 1]) {
						++left;
					}
					while (left < right && nums[right] == nums[right + 1]) {
						--right;
					}
				} else if (sum < 0) ++left;
				else --right;
			}
		}
		
		return result;
	}

	Triplets normalize(Triplets triplets) {
		// for (auto& t : triplets) std::ranges::sort(t);
		std::ranges::sort(triplets);
		return triplets;
	}

	void test_three_sum(const std::string& label,
						const TripleItems& nums,
						const Triplets& expected) {
		const auto result{normalize(get_three_sum_1(nums))};
		std::cout << std::format("{}: {}\n",
			label,
			result == normalize(expected) ? "OK" : "FAIL") << std::flush;
	}
}

int main() {
	test_three_sum("description example 1", {-1, 0, 1, 2, -1, -4}, {{-1, -1, 2}, {-1, 0, 1}});
	test_three_sum("description example 2", {0, 1, 1}, {});
	test_three_sum("description example 3", {0, 0, 0}, {{0, 0, 0}});

	test_three_sum("all positive", {1, 2, 3, 4, 5}, {});
	test_three_sum("all negative", {-5, -4, -3, -2, -1}, {});
	test_three_sum("min n, has triplet", {-2, 1, 1}, {{-2, 1, 1}});
	test_three_sum("min n, no triplet", {1, 2, 3}, {});
	test_three_sum("dups give one triplet", {-2, -2, 0, 0, 2, 2}, {{-2, 0, 2}});
	test_three_sum(
