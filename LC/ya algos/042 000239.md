
**Задача 9 из 9 (блок 6): максимум в скользящем окне** (LeetCode 239)

Дан массив `nums` и размер окна `k`. Окно сначала стоит в самом начале массива и сдвигается вправо на одну позицию за шаг до самого конца. Для каждого положения окна нужно записать максимум из `k` элементов, которые в нём лежат. Результат это массив из `n − k + 1` значений.

```cpp
std::vector<int> max_sliding_window(const std::vector<int>& nums, int k);
```

Например, для `{1, 3, -1, -3, 5, 3, 6, 7}` и `k = 3` ответ `{3, 3, 5, 5, 6, 7}`.

**Ограничения**

- 1 ≤ k ≤ n ≤ 1 000 000.
- Значения лежат во всём диапазоне `int`, включая `INT_MIN` и `INT_MAX`, часто повторяются.
- Дополнительная память O(n) допустима.

**Вопросы интервьюера**

1. Решите перебором: для каждого окна найти максимум заново. Какая сложность? На каких `k` она будет худшей?
2. Какую структуру вы выберете для O(n)? Что в ней хранится и в каком порядке: значения по убыванию или по возрастанию?
3. Что хранится в деке: индексы или значения? Зачем нужны индексы?
4. В каких двух местах вы убираете элементы из деки (с какого конца и по какому условию)?
5. Что вы делаете, когда в окно входит значение, равное максимуму в деке? Влияет ли выбор `<` или `<=` на корректность?
6. Почему общая сложность O(n)? Как это обосновать амортизированно?
7. А если вместо деки использовать `std::priority_queue`? Как удалять элементы, вышедшие из окна, и что с сложностью?

**Целевая сложность:** O(n) по времени, O(k) по памяти для деки.

**Ориентир по времени:** 25 минут.

**Важно:** если решение работает за O(n·k), большие тесты с `k = 500000` не завершатся за разумное время. Тест ограничивает время вызова двумя секундами, но прервать вашу функцию не может. Если прогон завис на таком тесте, остановите его и ищите O(n).

	// and from the end of the block to the left, the answer of a window is the maximum of two such values
	std::vector<int> expected_answer(const std::vector<int>& nums, int k) {
		const std::size_t size{nums.size()};
		const std::size_t block{static_cast<std::size_t>(k)};
		std::vector<int> from_start(size);
		std::vector<int> to_end(size);
		for (std::size_t i{0}; i < size; ++i) {
			from_start[i] = i % block == 0 ? nums[i] : std::max(from_start[i - 1], nums[i]);
		}
		for (std::size_t i{size}; i-- > 0;) {
			to_end[i] = i + 1 == size || (i + 1) % block == 0 ? nums[i] : std::max(to_end[i + 1], nums[i]);

		answer.reserve(size - block + 1);
		for (std::size_t i{0}; i + block <= size; ++i) {
			answer.push_back(std::max(to_end[i], from_start[i + block - 1]));
		}
		return answer;
	}

namespace {
	std::vector<int> max_sliding_window(const std::vector<int>& nums,
										int k) {
		const std::size_t size_n{nums.size()};
		const std::size_t size_k{static_cast<std::size_t>(k)};
	
		std::vector<int> answer;
		answer.reserve(size_n - size_k + 1);
		std::deque<std::size_t> indexes;
		for (std::size_t i{0}; i < size_n; ++i) {
			if (!indexes.empty() && indexes.front() + size_k <= i) {
				indexes.pop_front();
			}
			while (!indexes.empty() && nums[indexes.back()] <= nums[i]) {
				indexes.pop_back();
			}
			indexes.push_back(i);
	
			if (i + 1 >= size_k) {
				answer.push_back(nums[indexes.front()]);
			}
		}
	
		return answer;
	}
