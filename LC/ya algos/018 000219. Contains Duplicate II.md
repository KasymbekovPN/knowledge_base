## 219. Contains Duplicate II (Easy)

Дан целочисленный массив `nums` и целое число `k`. Нужно вернуть `true`, если в массиве есть два **разных индекса** `i` и `j`, для которых `nums[i] == nums[j]` и `abs(i - j) <= k`. Иначе вернуть `false`.

**Примеры**

- `nums = [1,2,3,1]`, `k = 3` → `true`
- `nums = [1,0,1,1]`, `k = 1` → `true`
- `nums = [1,2,3,1,2,3]`, `k = 2` → `false`

**Сигнатура**

```cpp
bool contains_nearby_duplicate(const std::vector<int>& nums, int k);
```

**Ограничения**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

namespace {
	bool contains_nearby_duplicate(const std::vector<int>& nums,
								   const int k) {
		if (k < 1) return false;
		
		const std::size_t size{nums.size()};
		
		std::unordered_map<int, std::size_t> idx_by_last_value;
		idx_by_last_value.reserve(size);

		for (std::size_t i{0}; i < size; ++i) {
			const auto [it, inserted] {idx_by_last_value.try_emplace(nums[i], i)};
			if (!inserted) {
				if (k >= static_cast<int>(i - it->second)) {
					return true;
				}
				
				it->second = i;
			}
		}
		
		return false;
	}
	
	bool contains_nearby_duplicate(const std::vector<int>& nums,
								   const int k) {
		if (k < 1) return false;
		
		const std::size_t size{nums.size()};
		const std::size_t window_size{std::min(k, size)};
		std::unordered_set<int> window;
		window.reserve(window_size);
		
		for (std::size_t i{0}; i < size; ++i) {
			if (!window.insert(nums[i]).second) {
				return true;
			}
			if (window.size() > window_size) {
				window.erase(nums[i - window_size]);
			}
		}
	}

	return false;
}
