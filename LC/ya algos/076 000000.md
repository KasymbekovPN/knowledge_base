**Условие.** Дан массив, в котором только числа 0, 1 и 2 (цвета). Отсортируйте его по возрастанию на месте.

- Библиотечную сортировку использовать нельзя.
- Дополнительная память O(1).

**Сигнатура:**

```cpp

```

**Ограничения:** до 10^6 элементов, значения только 0, 1, 2.

**Пример:** `{2, 0, 2, 1, 1, 0}` превращается в `{0, 0, 1, 1, 2, 2}`.

**Вопросы интервьюера:**

1. Как отсортировать за один проход? Какие три границы вы держите и какой инвариант между ними?
2. Почему при обмене с двойкой индекс середины не двигается, а при обмене с нулём двигается?
3. Чем решение за два прохода (подсчёт) хуже или лучше однопроходного?

**Цель:** O(n) по времени, один проход, O(1) память.

// Sorts an array that contains only 0, 1 and 2 in ascending order, in place.
// Extra memory O(1); do not use a library sort.
void sort_colors(std::vector<int>& nums) {
    std::size_t lo{0};
    std::size_t mi{0};
    std::size_t hi{nums.size()};
    
    while (mi < hi) {
	    if (nums[mi] == 0) {
		    std::swap(nums[mi++], nums[lo++]);
	    } else if (nums[mi] == 1) {
		    ++mi;
	    } else {
		    std::swap(nums[mi], nums[--hi]);
	    }
    }
}

}
