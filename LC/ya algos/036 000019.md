**Задача 3 из 9 (блок 6): удалить N-й узел с конца списка** (LeetCode 19)

Дана голова односвязного списка и число `n`. Нужно удалить `n`-й узел с конца (последний узел это `n = 1`) и вернуть голову получившегося списка. Узлы только перелинковываются: значения менять нельзя, новые узлы не создавать.

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* remove_nth_from_end(ListNode* head, int n);
```

**Ограничения**

- 1 ≤ размер списка ≤ 1 000 000, 1 ≤ n ≤ размер списка, `head != nullptr`.
- Значения лежат во всём диапазоне `int`, возможны повторы.
- Дополнительная память O(1).
- Узлы в тесте лежат в векторе, поэтому удаляемый узел освобождать не нужно. В реальной задаче вы бы его освободили, и на интервью об этом стоит сказать.

**Вопросы интервьюера**

1. Решите за два прохода: сначала посчитайте длину, потом дойдите до нужного узла. Какая сложность?
2. Теперь за один проход. Как вы используете два указателя и какое расстояние между ними держите?
3. Что происходит, если удаляется голова списка? Как вы это обрабатываете без отдельной ветки?
4. Что вернёт функция для списка из одного узла?
5. Можно ли решить рекурсивно? Какая цена рекурсии на списке из миллиона узлов?
6. Как изменится решение, если `n` может быть больше длины списка?

**Целевая сложность:** O(размер) по времени за один проход, O(1) по памяти.

**Ориентир по времени:** 20 минут. Один проход тесты проверить не могут, это вы показываете на словах. Двухпроходный вариант тоже пройдёт, но на интервью просят именно один проход.

Тестов 45. Эталон проходит все 45, в том числе под `-fsanitize=address,undefined`. Заглушка даёт 41 FAIL. Неправильные варианты ловятся:

- без фиктивного узла, когда удаляется голова, падает по null-указателю;
- лишний или недостающий шаг у быстрого указателя (off by one) тоже падает по null или даёт неверный список;
- «сдвиг значений вместо перелинковки» даёт 32 FAIL;
- возврат старой головы при удалении головы даёт 14 FAIL;
- рекурсивное решение падает по стеку на списке в миллион узлов.

Двухпроходное решение тесты пропускают, потому что проход один или два с точки зрения результата не отличаются. Показывайте мне один проход в самом коде.

	struct ListNode {
		int val;
		ListNode* next;
	};

	ListNode* remove_nth_from_end(ListNode* head,
								  int n) {
		if (head == nullptr) return nullptr;

		ListNode* fast{head};
		for (int i{0}; i < n; ++i) {
			if (fast == nullptr && i < n - 1) return nullptr;
			fast = fast->next;
		}
		if (fast == nullptr) return head->next;
		
		ListNode* slow{head};
		while (fast->next != nullptr) {
			slow = slow->next;
			fast = fast->next;
		}
		slow->next = slow->next->next;
		
		return head;
	}
