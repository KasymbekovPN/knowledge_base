**Задача 2 из 9 (блок 6): слить два отсортированных списка** (LeetCode 21)

Даны головы двух односвязных списков, каждый отсортирован по неубыванию. Нужно слить их в один отсортированный список и вернуть его голову. Список собирается из существующих узлов: новые не создавать, старые не удалять, значения не менять. При равных значениях узел из первого списка должен идти раньше узла из второго (устойчивость).

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* merge_two_lists(ListNode* list1, ListNode* list2);
```

**Ограничения**

- 0 ≤ m, n ≤ 1 000 000 узлов в каждом списке, пустой список передаётся как `nullptr`.
- Значения лежат во всём диапазоне `int`, включая `INT_MIN` и `INT_MAX`, возможны повторы.
- Дополнительная память O(1).

**Вопросы интервьюера**

1. Зачем в такой задаче нужен фиктивный узел (`dummy`)? Что без него придётся обрабатывать отдельно?
2. Что вы делаете, когда один из списков закончился раньше другого? Нужно ли копировать оставшиеся узлы?
3. Как реализовать устойчивость? Что изменится, если заменить `<` на `<=` в сравнении?
4. Можно ли сравнивать через разность `a->val - b->val`? Почему нет?
5. Решите рекурсивно. Что случится с рекурсивным решением на двух списках по 1 000 000 узлов?
6. Как этой задачей воспользоваться для сортировки списка за O(n log n) (merge sort)?

**Целевая сложность:** O(m + n) по времени, O(1) по памяти.

**Ориентир по времени:** 20 минут. Рекурсивный вариант писать не нужно, достаточно ответить на вопрос 5 словами.

	// links nodes one after another and returns the head (nullptr for an empty vector)
	ListNode* link(std::vector<ListNode>& nodes, const std::vector<int>& values) {
		for (std::size_t i{0}; i < values.size(); ++i) {
			nodes[i].val = values[i];
			nodes[i].next = i + 1 < values.size() ? &nodes[i + 1] : nullptr;
		}
		return values.empty() ? nullptr : &nodes[0];
	}

	// both lists live in vectors: the solution may only relink the nodes, never create or delete them;
	// on equal values a node of the first list must stay before a node of the second one
	void test_merge(const std::string& label,
					const std::vector<int>& first,
					const std::vector<int>& second) {
		std::vector<ListNode> nodes1(first.size());
		std::vector<ListNode> nodes2(second.size());
		ListNode* head1{link(nodes1, first)};
		ListNode* head2{link(nodes2, second)};

		std::vector<const ListNode*> expected;
		expected.reserve(first.size() + second.size());
		for (const ListNode& node : nodes1) expected.push_back(&node);
		const std::size_t middle{expected.size()};
		for (const ListNode& node : nodes2) expected.push_back(&node);
		std::inplace_merge(expected.begin(),
			expected.begin() + static_cast<std::ptrdiff_t>(middle),
			expected.end(),
			[](const ListNode* x, const ListNode* y) { return x->val < y->val; });

		const ListNode* current{merge_two_lists(head1, head2)};
		bool ok{true};
		for (std::size_t i{0}; ok && i < expected.size(); ++i) {
			ok = current == expected[i];
			if (ok) current = current->next;
		}
		ok = ok && current == nullptr;
		for (std::size_t i{0}; ok && i < first.size(); ++i) ok = nodes1[i].val == first[i];
		for (std::size_t i{0}; ok && i < second.size(); ++i) ok = nodes2[i].val == second[i];

			value += static_cast<int>((state >> 8) % static_cast<unsigned>(max_step + 1));
		}
		return values;
	}

namespace {
	struct ListNode {
		int val;
		ListNode* next;
	};

	ListNode* merge_two_lists(ListNode* list1,
							  ListNode* list2) {
		
		ListNode dummy{};
		auto current{&dummy};
		
		auto p1{list1};
		auto p2{list2};
		while (p1 != nullptr && p2 != nullptr) {
			if (p1->val <= p2->val) {
				current->next = p1;
				p1 = p1->next;
			} else {
				current->next = p2;
				p2 = p2->next;
			}
			current = current->next;
		}

		current->next = p1 != nullptr ? p1 : p2;

		return dummy.next;
	}
