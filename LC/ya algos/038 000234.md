**Задача 5 из 9 (блок 6): палиндром среди значений списка** (LeetCode 234)

Дана голова односвязного списка. Нужно проверить, читается ли список одинаково слева направо и справа налево по значениям `val`. После вызова список должен остаться ровно таким, каким пришёл: те же узлы в том же порядке, те же ссылки `next`. Внутри функции ссылки менять можно, но потом их надо вернуть.

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

bool is_palindrome(ListNode* head);
```

**Ограничения**

- 0 ≤ размер ≤ 1 000 000 узлов, пустой список (`nullptr`) считается палиндромом.
- Значения лежат во всём диапазоне `int`, часто повторяются.
- Дополнительная память O(1).

**Вопросы интервьюера**

1. Как проверить за O(размер) с памятью O(размер)? Какое простое решение у вас первым приходит в голову?
2. Как сделать то же с памятью O(1)? Из каких шагов будет состоять решение?
3. Как найти середину за один проход? Чем отличается положение медленного указателя для списка чётной и нечётной длины и что делать со средним узлом при нечётной?
4. Зачем возвращать список в исходное состояние? Что будет, если не вернуть, а им после вас кто-то пользуется?
5. Можно ли решить рекурсивно, не меняя список? Какая цена на списке из миллиона узлов?
6. Что вы вернёте, если вторая половина оказалась короче первой на один узел? Как вы убедитесь, что не выйдете за конец?

**Целевая сложность:** O(размер) по времени, O(1) по памяти.

**Ориентир по времени:** 25 минут. Здесь собираются сразу три приёма, которые вы уже делали: быстрый и медленный указатели, разворот списка и два указателя навстречу друг другу. Развернуть половину можно тем же циклом, что и в первой задаче блока.

	void test_palindrome(const std::string& label, const std::vector<int>& values) {
		std::vector<ListNode> nodes(values.size());
		for (std::size_t i{0}; i < values.size(); ++i) {
			nodes[i].val = values[i];
			nodes[i].next = i + 1 < values.size() ? &nodes[i + 1] : nullptr;

			if (values[i] != values[values.size() - 1 - i]) {
				expected = false;
				break;
			}
		}

		const bool result{is_palindrome(head)};

		bool ok{result == expected};
		for (std::size_t i{0}; ok && i < nodes.size(); ++i) {
			ok = nodes[i].val == before[i].val && nodes[i].next == before[i].next;
		}

			label,

		}

	}

namespace {
	struct ListNode {
		int val;
		ListNode* next;
	};

	bool is_palindrome(ListNode* head) {
		if (head == nullptr || head->next == nullptr) return false;
		
		ListNode* slow{head};
		ListNode* fast{head};
		
		const auto reverse = [](ListNode*& head, ListNode*& stop) {
			ListNode* current{head};
			ListNode* prev{stop};
			while (current != stop) {
				ListNode* next{current->next};
				current->next = prev;
				prev = current;
				current = next;
			}
			head = prev;
		};

		ListNode* start_right{nullptr};
		while (fast != nullptr && fast->next != nullptr) {
			slow = slow->next;
			fast = fast->next->next;

			start_right = fast != nullptr ? slow->next : slow;
		}
		
		reverse(head, slow);
		
		ListNode* start_left{head};
		bool result{true};
		while (start_right != nullptr) {
			if (start_left->val != start_right->val) {
				result = false;
				break;
			}
			start_left = start_left->next;
			start_right = start_right->next;
		}
		
		reverse(head, slow);
	
		return result;
	}
