**Задача 1 из 9 (блок 6): развернуть односвязный список** (LeetCode 206)

Дана голова односвязного списка. Нужно развернуть список и вернуть новую голову. Узлы только перелинковываются: значения менять нельзя, новые узлы не создавать и не удалять.

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* reverse_list(ListNode* head);
```

**Ограничения**

- 0 ≤ n ≤ 1 000 000 узлов, `head == nullptr` для пустого списка.
- Значения лежат во всём диапазоне `int`, часть значений в списке может повторяться.
- Дополнительная память O(1).

**Вопросы интервьюера**

1. Решите итеративно. Сколько указателей вам нужно держать, и в каком порядке вы их переставляете?
2. Что вернёт ваша функция для пустого списка и для списка из одного узла?
3. Теперь рекурсивно. Какая у решения сложность по времени и по памяти?
4. Что случится при n = 1 000 000 с рекурсивным решением и почему? Как бы вы ответили интервьюеру, если он спросит про стек вызовов?
5. Как развернуть только часть списка между позициями `left` и `right` (LC92)? Опишите идею словами, писать не надо.

**Целевая сложность:** O(n) по времени, O(1) по памяти.

	struct ListNode {
		int val;

	};

	ListNode* reverse_list([[maybe_unused]] ListNode* head) {

	// true if walking from head visits nodes[order[0]], nodes[order[1]], ... and then reaches nullptr
	bool has_order(const ListNode* head,
				   const std::vector<ListNode>& nodes,
				   bool reversed) {
		const std::size_t size{nodes.size()};
		const ListNode* current{head};
		for (std::size_t step{0}; step < size; ++step) {
			const ListNode* expected{reversed ? &nodes[size - 1 - step] : &nodes[step]};
			if (current != expected) return false;
			current = current->next;
		}
		return current == nullptr;
	}

	// the list lives in a vector: the solution may only relink the nodes, never create or delete them
	void test_reverse(const std::string& label, const std::vector<int>& values) {
		std::vector<ListNode> nodes(values.size());
		for (std::size_t i{0}; i < values.size(); ++i) {
			nodes[i].val = values[i];
			nodes[i].next = i + 1 < values.size() ? &nodes[i + 1] : nullptr;
		}
		ListNode* head{values.empty() ? nullptr : &nodes[0]};

		ListNode* reversed{reverse_list(head)};
		bool ok{has_order(reversed, nodes, true)};
		if (ok) {
			// reversing the result once more must give the original list back
			ListNode* restored{reverse_list(reversed)};
			ok = has_order(restored, nodes, false);
		}
		for (std::size_t i{0}; ok && i < values.size(); ++i) {
			ok = nodes[i].val == values[i];
		}

		std::cout << std::format("{}: {}\n",
			label,
			ok ? "OK" : "FAIL") << std::flush;
	}
