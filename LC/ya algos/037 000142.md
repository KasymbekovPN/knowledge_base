**Задача 4 из 9 (блок 6): начало цикла в связном списке** (LeetCode 142)

Дана голова односвязного списка, в котором, возможно, есть цикл: хвост указывает на один из предыдущих узлов. Нужно вернуть узел, с которого начинается цикл, а если цикла нет, то `nullptr`. Список менять нельзя: ни значения, ни ссылки `next`, ни временные пометки на узлах.

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* detect_cycle(ListNode* head);
```

**Ограничения**

- 0 ≤ размер ≤ 1 000 000 (число различных узлов), пустой список передаётся как `nullptr`.
- Значения лежат во всём диапазоне `int`, часто повторяются, поэтому сравнивать по значениям нельзя.
- Дополнительная память O(1).

**Вопросы интервьюера**

1. Как определить, что в списке есть цикл? Объясните, почему медленный и быстрый указатели обязательно встретятся.
2. Что делать после встречи, чтобы найти именно начало цикла? Докажите на формулах, почему второй проход из головы и от точки встречи сходится в начале цикла.
3. Какие условия в цикле гарантируют отсутствие разыменования `nullptr`? Что будет, если проверить только `fast->next`?
4. Как решить через `unordered_set` указателей? Чем это хуже по памяти?
5. Можно ли пометить посещённые узлы, изменив `val` или `next`? Почему интервьюер запрещает?
6. Как найти длину цикла, если у вас уже есть точка встречи?

**Целевая сложность:** O(размер) по времени, O(1) по памяти.

**Ориентир по времени:** 20 минут. Решение через `unordered_set` тесты пропустят, потому что память они не проверяют. Но на интервью нужен O(1), поэтому присылайте именно его.

**Важно:** при ошибке в логике на списке с циклом ваш цикл может не завершиться, тогда тесты просто зависнут. Это не баг шаблона. Остановите прогон и ищите ошибку в условиях выхода.

	void test_cycle(const std::string& label, const std::vector<int>& values, int cycle_start) {

	struct ListNode {
		int val;
		ListNode* next;
	};

	ListNode* detect_cycle(ListNode* head) {
		if (head == nullptr) return nullptr;
	
		ListNode* slow{head};
		ListNode* fast{head};
		while (fast != nullptr && fast->next != nullptr) {
			slow = slow->next;
			fast = fast->next->next;
			
			if (slow != fast) continue;
			
			ListNode* start{head};
			while (start != slow) {
				start = start->next;
				slow = slow->next;
			}
			return start;
		}

		return nullptr;
	}
